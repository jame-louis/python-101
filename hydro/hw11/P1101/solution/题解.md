# P1101 基础继承（基础·无输入）

## 思路

`class Dog(Animal)` 让子类自动继承父类的 `__init__`、`speak`、`move`。子类 `pass` 一个方法都不写，照样能调用——这就是继承的复用价值。

## 参考代码

```python
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        return f"{self.name} 发出叫声"
    def move(self):
        return f"{self.name} 在移动"

class Dog(Animal):
    pass

d = Dog("旺财")
print(d.speak())   # 旺财 发出叫声
print(d.move())    # 旺财 在移动
```

## 常见错误

- 忘了写括号 `class Dog:` → 变成普通类，与 Animal 无关，`speak` 未定义报错。
- 子类硬要重写全部方法 → 没有体现"复用"，且可能写错。
- `pass` 后仍缩进别的内容 → 缩进语义错误。
