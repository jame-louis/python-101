# 三维点 super 扩展（综合选做）

## 题目描述

读入三维坐标 `x y z`，用"写法B"构造 `Point3D` 对象打印 `(x, y, z)` 元组。

- `Point2D` 父类初始化 `x, y`；`Point3D(Point2D)` 子类重写 `__init__`，先 `super().__init__(x, y)` 补父类初始化，再 `self.z = z`。
- 这是"子类需要新增属性"时必须用的扩展写法。

> 综合选做题，用到 `super().__init__()` 构造器继承扩展。

## 输入格式

**一行**三个整数 `x y z`，用空格分隔。程序先显示提示语再读取：

```
请输入 x y z（空格分隔）：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。提示语必须与上面**完全一致**（含全角冒号），程序先打印提示语，再用裸 `input()` 读入整行。

## 输出格式

读取后输出一行元组：

```
请输入 x y z（空格分隔）：
(1, 2, 3)
```

## 样例 #1

```input1
1 2 3
```

```output1
请输入 x y z（空格分隔）：
(1, 2, 3)
```

## 样例 #2

```input2
3 1 4
```

```output2
请输入 x y z（空格分隔）：
(3, 1, 4)
```

## 提示

- 读入：`x, y, z = map(int, input().split())`。
- 构造：`q = Point3D(x, y, z)`。
- 打印：`print((q.x, q.y, q.z))`。

## 数据范围

$x, y, z$ 为整数，$|x|,|y|,|z| \le 10^9$。

| 测试点 | 说明 |
|--------|------|
| 1-4 | 含样例、正数 |
| 5-6 | 负数 / 零 |
| 7-10 | 随机（含大数） |
