# P1104 三维点 super 扩展（综合·输入+提示）

## 思路

重写子类 `__init__`，先 `super().__init__(x, y)` 等调用父类构造器初始化前两维，再 `self.z = z` 设置新增的第三维。带提示语读入三个整数后构造并打印元组。

## 参考代码

```python
class Point2D:
    def __init__(self, x, y):
        self.x = x
        self.y = y

class Point3D(Point2D):
    def __init__(self, x, y, z):
        super().__init__(x, y)
        self.z = z

print("请输入 x y z（空格分隔）：")
x, y, z = map(int, input().split())
q = Point3D(x, y, z)
print((q.x, q.y, q.z))
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1 | 样例（1 2 3） |
| 2 | 样例（3 1 4） |
| 3 | 全零 |
| 4 | 含负数 |
| 5 | 全负 |
| 6-7 | 小随机 |
| 8-9 | 中随机（±10⁶） |
| 10 | 大随机（±10⁹） |

## 常见错误

- 漏 `super().__init__(x, y)` → `q.x`/`q.y` 未初始化报 AttributeError。
- 用 `map(int, input().split())` 后不拆包 → x 是 map 对象。
- 打印写成 `print(q.x, q.y, q.z)`（带空格）→ 与所需元组格式 `(1, 2, 3)` 不符。
