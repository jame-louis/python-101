# P1105 多态动物叫（综合·输入+提示）

## 思路

继承 + 重写让 `Dog`/`Cat` 各自实现 `speak`。多态就是把它们装进一个列表，用 `for a in ...` 统一调用同一个方法名，各自给出不同实现。调用方只认接口、不认类型。

## 参考代码

```python
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        return f"{self.name} 发出叫声"

class Dog(Animal):
    def speak(self):
        return f"{self.name} 汪汪叫！"

class Cat(Animal):
    def speak(self):
        return f"{self.name} 喵喵叫~"

print("请输入狗狗名字：")
dog_nm = input()
print("请输入猫咪名字：")
cat_nm = input()
for a in [Dog(dog_nm), Cat(cat_nm)]:
    print(a.speak())
```

## 常见错误

- 用 `if a.__class__ == Dog:` 之类的类型判断 → 失去多态，且不沿用接口思想。
- 忘 `__init__` 或方法重写名拼错 → 子类用父类"发出叫声"。
- 漏 `for` 循环 / 直接打印列表 → 输出格式不对。
- 提示语写错（漏全角冒号）→ 逐字匹配不过。
