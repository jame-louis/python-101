# 多态动物叫（综合选做）

## 题目描述

读入**狗狗名字**与**猫咪名字**（各一行），创建 `Dog`、`Cat` 对象放入同一个列表，用 `for a in ...` **统一调用** `a.speak()`，打印两行。

- 定义 `Animal` 父类与重写 `speak` 的 `Dog`、`Cat` 子类。
- 调用方只认识"会 `speak()` 的东西"，不关心具体类型——这就是**多态**：同一接口、不同实现。

> 综合选做题，用到继承 + 方法重写 + 多态统一调用。

## 输入格式

**两行**：第一行狗狗名字，第二行猫咪名字。程序先分别显示提示语再读取：

```
请输入狗狗名字：
请输入猫咪名字：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。两行提示语必须与上面**完全一致**（含全角冒号），程序先打印提示语，再用裸 `input()` 读入。

## 输出格式

读取后输出两行（每个动物各一行）：

```
请输入狗狗名字：
请输入猫咪名字：
大黄 汪汪叫！
小白 喵喵叫~
```

## 样例 #1

```input1
大黄
小白
```

```output1
请输入狗狗名字：
请输入猫咪名字：
大黄 汪汪叫！
小白 喵喵叫~
```

## 提示

- 定义 `Animal`（`speak` 返回 "...发出叫声"）、`Dog`（"汪汪叫！"）、`Cat`（"喵喵叫~"）。
- 读入：`print("请输入狗狗名字：")` → `nm = input()`，同理猫名。
- 多态：`for a in [Dog(dog_nm), Cat(cat_nm)]: print(a.speak())`。

## 数据范围

名字由除换行外可见字符组成。

| 测试点 | 说明 |
|--------|------|
| 1-4 | 含样例、不同名字 |
| 5-10 | 随机名字 |
