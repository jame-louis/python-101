# P1102 方法重写（基础·无输入）

## 思路

子类用与父类**同名**的方法就把父类方法覆盖掉。构造父类实例和重写的子类实例，调用同一个 `speak()` 得到不同结果——`Dog` 汪汪、`Cat` 喵喵、`Animal` 发出叫声。

## 参考代码

```python
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        return f"{self.name} 发出叫声"

class Dog(Animal):
    def speak(self):
        return f"{self.name} 汪汪叫！"

class Cat(Animal):
    def speak(self):
        return f"{self.name} 喵喵叫~"

print(Dog("旺财").speak())      # 旺财 汪汪叫！
print(Cat("咪咪").speak())      # 咪咪 喵喵叫~
print(Animal("普通动物").speak())  # 普通动物 发出叫声
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1-5 | 全部相同（无输入、固定输出） |

## 常见错误

- 子类方法名写错（如 `spak`）→ 不是重写而是新增，调用时用的是父类"发出叫声"。
- 重写方法参数不匹配（漏 `self`）→ TypeError。
- 忘了父类实例也调用 `speak` → 缺一行输出。
