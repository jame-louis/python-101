# P1103 构造器继承 super（基础·无输入）

## 思路

写法B：子类重写 `__init__`，先 `super().__init__(x, y)` 调用父类构造器把 `x,y` 初始化，再 `self.z = z` 新增第三维。若不调 `super().__init__()`，父类属性 `x,y` 不会被初始化，访问即报错。

## 参考代码

```python
class Point2D:
    def __init__(self, x, y):
        self.x = x
        self.y = y

class Point3D(Point2D):
    def __init__(self, x, y, z):
        super().__init__(x, y)
        self.z = z

q = Point3D(1, 2, 3)
print((q.x, q.y, q.z))    # (1, 2, 3)
```

## 常见错误

- 写 `__init__` 却漏 `super().__init__(x, y)` → `q.x` 报 AttributeError。
- `super()` 调错参数 → 父类 x,y 初始化错。
- 忘了 `__init__` 之外的方法没问题，但构造器漏父类初始化是最典型坑。
