# hw11 —— 类的继承性与多态（Hydro 题目集）

对应课程第 11 讲实验任务卡 `src/assignments/hw11.md`，共 **5 道 Python 传统题**，每题一个自包含
Hydro 题目包（`problem.yaml` + `problem_zh.md` + `testdata/` + `std/` + `solution/`）。

## 知识点约束

本套题贴合**当前学生已学内容**：本讲学习继承（`class B(A)`）、方法重写、`super()` 构造器继承、
多态。题目将**刻意聚焦继承体系与接口多态**。

- **基础题（P1101–P1103）无输入，固定输出**：基础继承、方法重写、构造器继承 `super`。
- **综合题（P1104–P1105）有输入 + 带提示语**：三维点 `super` 扩展、多态动物叫。

> ⚠️ 严格逐字匹配：P1104–P1105 提示语（含全角冒号）与输出格式必须逐字复现。

## 题目一览

| PID | 题目 | 类型 | 考点 | 处理方式 |
|-----|------|------|------|----------|
| P1101 | 基础继承（基础） | 无输入 | `class B(A)`、继承父类属性/方法 | 固定输出 |
| P1102 | 方法重写（基础） | 无输入 | 同名方法覆盖、重写 | 固定输出 |
| P1103 | 构造器继承 super（基础） | 无输入 | `super().__init__()` 扩展 | 固定输出 |
| P1104 | 三维点 super 扩展（综合选做） | 输入+提示 | 构造器继承 + 输入坐标 | 严格逐字匹配 |
| P1105 | 多态动物叫（综合选做） | 输入+提示 | 继承 + 重写 + 统一接口多态 | 严格逐字匹配 |

## 使用

校验全部题目：

```bash
python3 hydro/hw11/validate.py
```

（数据生成/重放：`python3 gen.py N > testdata/N.in` + `python3 std/std.py.py3 < *.in > *.out`）

## 说明

- Hydro 评测为**传统题**，语言放开 Python 即可；`std` 后缀 `std.py.py3` 与 Hydro 的 Python3 语言键一致。
- 基础题为固定输出便于自查；综合题覆盖样例、负数/全零、随机/大数坐标、随机名字等，并保留较多随机测试点。
- P1104、P1105 恰好对应 hw11 任务卡的两个进阶任务（🔴 三维点 super、🔴 多态动物叫），
  与基础题一起完整覆盖了"基础继承、方法重写、构造器扩展、多态接口"四条主线。
