# P0602 成绩等级判定（基础·无输入）

## 思路

经典的 `if-elif-else` 多分支。关键在于依赖 `elif` 的**隐含条件**：写 `elif score >= 80` 时，已经隐含前面 `score < 90` 不成立，所以不必再写 `score >= 80 and score < 90`。`85` 命中 `>=80` 一档，得"良好"。

## 参考代码

```python
score = 85
if score >= 90:
    grade = "优秀"
elif score >= 80:
    grade = "良好"
elif score >= 70:
    grade = "中等"
elif score >= 60:
    grade = "及格"
else:
    grade = "不及格"
print(f"等级：{grade}")
```

## 常见错误

- 每个分支重复写前置条件（如 `elif score >= 80 and score < 90`）→ 冗余且易错。
- 用 `if` 并列而非 `elif` → 多个分支可能同时执行，结果不可控。
- 边界 `>=0` 与 `>90` 用混 → 恰好 90 判错。
- 用 `else if` → Python 报语法错，应写 `elif`。
