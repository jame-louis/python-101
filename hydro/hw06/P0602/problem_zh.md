# 成绩等级判定（基础）

## 题目描述

对固定成绩 `score = 85`，用 `if-elif-else` 的多分支判定成绩等级，并打印一行固定结果。

等级划分：

- `score >= 90` → **优秀**
- `score >= 80` → **良好**
- `score >= 70` → **中等**
- `score >= 60` → **及格**
- 其余 → **不及格**

> `elif` 链依次判断，命中第一个成立的分支即停止。相邻等级用 `elif` 一条条列，**不要**为每个分支重复写前置条件（隐含条件会自动覆盖）。
> **本题无输入**，输出固定。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

仅一行：

```
等级：良好
```

## 样例 #1

```input1
（本题无输入）
```

```output1
等级：良好
```

## 提示

- 用 `if-elif-else` 五档依次判断 `>=90 / >=80 / >=70 / >=60 / else`。
- 输出 `print(f"等级：{grade}")`（`grade` 为字符串，无需空格）。
- 验证：`85` 落在 `>=80` 一档，故为"良好"。

## 数据范围

无输入，使用题目给出的固定数据即可。
