# P0605 成绩等级自动判定（综合·输入+提示）

## 思路

读入一个百分制成绩，用 `if-elif-else` 五档依序判定。依赖 `elif` 的隐含条件，每个分支只写本层下限，不必叠加写上限。边界值刻意覆盖：恰好 `90`（优秀）、`60`（及格）等。

## 参考代码

```python
print("请输入成绩（0-100）：")
score = int(input())
if score >= 90:
    grade = "优秀"
elif score >= 80:
    grade = "良好"
elif score >= 70:
    grade = "中等"
elif score >= 60:
    grade = "及格"
else:
    grade = "不及格"
print(f"等级：{grade}")
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1 | 样例（85→良好） |
| 2 | 样例（59→不及格，边界） |
| 3 | 边界（90→优秀） |
| 4 | 边界（89→良好） |
| 5 | 边界（60→及格） |
| 6 | 满绩（100→优秀） |
| 7 | 最低（0→不及格） |
| 8-9 | 中高带随机 |
| 10 | 全带随机 |

## 常见错误

- 用并列 `if` 而非 `elif` → 每个分支都可能执行，多个等级同时输出。
- 分支重复写前置条件（如 `elif score >= 80 and score < 90`）→ 冗余易错，依赖隐含条件即可。
- 边界写混：`> 90` 会漏掉恰好 90；`>= 60` 与 `> 60` 决定 60 归哪档。
- 提示语写错（全角括号/冒号）→ 逐字匹配不过。
- 忘 `int()` ——把字符串拿去做比较会报错或结果错误。
