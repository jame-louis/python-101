# 成绩等级自动判定（综合选做）

## 题目描述

读入一个百分制整数成绩 `score`（0 到 100），判定并打印**等级**。

划分规则：

- `score >= 90` → **优秀**
- `score >= 80` → **良好**
- `score >= 70` → **中等**
- `score >= 60` → **及格**
- 其余 → **不及格**

> 综合选做题：把「实验2」做成在线评测版。用 `if-elif-else` 五档判定并输出。**设计测试用例验证两端取值**（恰好 90 / 89 / 60 / 59）。

## 输入格式

**一行**一个整数 `score`。程序先显示提示语再读取：

```
请输入成绩（0-100）：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。提示语必须与上面**完全一致**（含全角括号与全角冒号）。提示语后直接输出等级一行。

## 输出格式

读取后输出一行：

```
请输入成绩（0-100）：
等级：良好
```

## 样例 #1

```input1
85
```

```output1
请输入成绩（0-100）：
等级：良好
```

## 样例 #2

```input2
59
```

```output2
请输入成绩（0-100）：
等级：不及格
```

## 提示

- 先打印一行提示语：`print("请输入成绩（0-100）：")`，再读：`score = int(input())`。
- 判定：`if-elif-else` 依序判 `>=90 / >=80 / >=70 / >=60 / else`。
- 输出：`print(f"等级：{grade}")`，`grade` 为判定出的字符串。
- 边界验证：100→优秀，90→优秀，89→良好，60→及格，59→不及格，0→不及格。

## 数据范围

$0 \le \text{score} \le 100$（整数）。

| 测试点 | 说明 |
|--------|------|
| 1-7 | 覆盖五个等级与关键边界（90、89、60、59、0、100） |
| 8-10 | 随机（0~100） |
