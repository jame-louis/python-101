# P0604 比大小（综合·输入+提示）

## 思路

先各打印一行提示语，再用裸 `input()` 逐行读入两个整数，最后用 `if-elif-else` 三态覆盖"大于、等于、小于"。用 f-string 把两个数和关系符拼成一行输出。

## 参考代码

```python
print("请输入a：")
a = int(input())
print("请输入b：")
b = int(input())
if a > b:
    print(f"{a} > {b}")
elif a == b:
    print(f"{a} == {b}")
else:
    print(f"{a} < {b}")
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1 | 小样例（5 < 8） |
| 2 | 相等（8 == 8） |
| 3 | 大样例（9 > 2） |
| 4 | 负数 < 零 |
| 5 | 零 > 负数 |
| 6 | 相等（7 == 7） |
| 7-8 | 小随机 |
| 9 | 大随机（±10⁹） |
| 10 | 大随机且相等 |

## 常见错误

- 提示语写错（漏全角冒号、多空格）→ 逐字匹配不过。
- 用 `输入` 两次读到的不是整数 → 忘 `int()`。
- 把 `>`、`==`、`<` 写成 `>=`、`!=` → 边界重叠/漏三态之一。
- 用 `if a > b ... if b > a ...` 而漏了相等分支 → 相等时无输出。
- 输出用 `print(a, ">", b)` → 多余空格与样例不一致，应精确用 f-string。
