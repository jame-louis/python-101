# 比大小（综合选做）

## 题目描述

读入两个整数 `a` 与 `b`，判断并打印两者的大小关系：`a > b`、`a == b` 或 `a < b`。

- 用 `if-elif-else` 的三态分支覆盖：大于、等于、小于。
- 这是"比大小"实验的在线版：先用 `input()` 带提示语读入两个数，再判断关系。

> 综合选做题，用到带提示语的输入与 `if-elif-else`。**无需循环、无需 `max()`**。

## 输入格式

**两行**，每行一个整数 `a`、`b`。程序先分别显示提示语再读取：

```
请输入a：
请输入b：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。两行提示语必须与上面**完全一致**（含全角冒号）。提示语之后，再输出大小关系一行。

## 输出格式

读取两行后，输出一行三态结果：

```
请输入a：
请输入b：
a < b
```

关系写法：`{a} > {b}` / `{a} == {b}` / `{a} < {b}`（左右均有空格）。

## 样例 #1

```input1
5
8
```

```output1
请输入a：
请输入b：
5 < 8
```

## 样例 #2

```input2
8
8
```

```output2
请输入a：
请输入b：
8 == 8
```

## 样例 #3

```input3
9
2
```

```output3
请输入a：
请输入b：
9 > 2
```

## 提示

- 先各打印一行提示语：`print("请输入a：")`、`print("请输入b：")`，再读：`a = int(input())`、`b = int(input())`。
- 判断三态：`if a > b:` → `print(f"{a} > {b}")`；`elif a == b:` → `print(f"{a} == {b}")`；`else:` → `print(f"{a} < {b}")`。
- 测试三组：`(5,8)`、`(8,8)`、`(9,2)`，三种关系都应输出正确。

## 数据范围

$a, b$ 为整数，$|a|, |b| \le 10^9$。

| 测试点 | 说明 |
|--------|------|
| 1-6 | 含样例、相等、负数、零等边界 |
| 7-10 | 随机大整数（含相等） |
