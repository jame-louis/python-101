# P0603 三数比大小（基础·无输入）

## 思路

三数求最大。用 `and` 组合前两个条件：`a` 是最大当且仅当 `a >= b` 且 `a >= c`；否则在 `b`、`c` 里再比（隐含 `a` 已不是最大），所以只需 `b >= c` 即可判断。别用 `max()`，别用循环，纯条件题。

## 参考代码

```python
a, b, c = 9, 2, 5
if a >= b and a >= c:
    big = a
elif b >= c:
    big = b
else:
    big = c
print("最大的是：", big)
```

## 常见错误

- 想要 `a`、`b`、`c` 分别各成一个 `if` → 会漏掉被覆盖的情况或有重叠逻辑。
- 用 `boss` 逐个比较却没初始化、比较方向写反 → 结果错误。
- `elif` 里再塞 `a` 的条件 → 冗余；此时 `a` 已不是最大，直接比 `b`、`c` 即可。
- 直接 `print(a, b, c)` 排序输出 → 未按要求打印最大值标签。
