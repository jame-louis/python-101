# 三数比大小（基础）

## 题目描述

对固定的三个整数 `a=9, b=2, c=5`，用**条件判断**（逻辑运算符 `and`、`elif` 组合）找出并打印**最大值**。

> 三数找最大可以拆成：若 `a` 不小于 `b` 且不小于 `c`，则最大是 `a`；否则在另两个里再比。**不许**用 `max()` 和循环。
> **本题无输入**，输出固定。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

仅一行：

```
最大的是： 9
```

## 样例 #1

```input1
（本题无输入）
```

```output1
最大的是： 9
```

## 提示

- 思路一（合并）：`if a >= b and a >= c: 最大是 a`；`elif b >= c:` 最大是 `b`；`else:` 最大是 `c`。
- 思路二（逐个更新）：可先用比较把 `big` 依次与 `b`、`c` 比，谁大连谁。
- 输出 `print("最大的是：", big)`，注意此写法会在值与标签间打一个空格。

## 数据范围

无输入，使用题目给出的固定数据即可。
