# hw06 —— 条件结构（Hydro 题目集）

对应课程第 6 讲实验任务卡 `src/assignments/hw06.md`，共 **5 道 Python 传统题**，每题一个自包含
Hydro 题目包（`problem.yaml` + `problem_zh.md` + `testdata/` + `std/` + `solution/`）。

## 知识点约束（关键）

本套题贴合**当前学生已学内容**：本讲系统学习条件结构（`if`/`if-else`/`if-elif-else`、缩进即代码块、
嵌套分支、`elif` 隐含条件）。**循环（`for`/`while`）在下一讲才学**，因此：

- **整卷完全只使用条件结构与顺序结构，零循环。**
- **基础题（P0601–P0603）无输入，输出固定**：正负/奇偶（`if-elif-else` + `%`）、成绩等级（多分支）、
  三数取最大（`and` 逻辑、`elif`）。
- **综合题（P0604–P0605）有输入 + 带提示语**：比大小（三态 `> / == / <`）、成绩等级自动判定。两题
  恰对应本讲两个实验。

> ⚠️ 严格逐字匹配：P0604–P0605 的提示语（含全角冒号/括号）与输出格式必须逐字复现。

## 题目一览

| PID | 题目 | 类型 | 考点 | 处理方式 |
|-----|------|------|------|----------|
| P0601 | 正负与奇偶判断（基础） | 无输入 | `if-elif-else` 三态、`%` 取模奇偶、负数取模 | 固定输出 |
| P0602 | 成绩等级判定（基础） | 无输入 | `if-elif-else` 多分支、`elif` 隐含条件 | 固定输出 |
| P0603 | 三数比大小（基础） | 无输入 | `and` 逻辑运算、`elif`、比较求最大 | 固定输出 |
| P0604 | 比大小（综合选做） | 输入+提示 | 三态比较（`> / == / <`）、f-string 输出 | 严格逐字匹配 |
| P0605 | 成绩等级自动判定（综合选做） | 输入+提示 | `if-elif-else` 五档判定、边界值验证 | 严格逐字匹配 |

## 输入与严格匹配说明

- **P0601–P0603（基础）**：无输入，`.in` 放占位 `no-input`；每套 5 个相同测试点。
- **P0604–P0605（综合选做）**：有输入。标程以 `print(提示语)` 先输出一行提示语，再用裸 `input()`
  读入。学生必须复现**完全一致**的提示语与输出格式（题面已在「提示」中明确标注）。每套 10 个测试点。

> P0604 逐行读两个整数（提示语 `请输入a：`、`请输入b：`）；P0605 读一个 0–100 的整数成绩
> （提示语 `请输入成绩（0-100）：`），覆盖五档等级与 90/89/60/59/0/100 等边界。

## 目录约定

```
P06xx/
├── problem.yaml          # 标题、标签、PID、难度
├── problem_zh.md         # 中文题面
├── testdata/
│   ├── config.yaml       # 时限/内存 + 测试点
│   ├── 1..N.in           # 输入（1 号即样例；P0601-03 为 5 个，P0604-05 为 10 个）
│   └── 1..N.out          # 标准输出（由标程生成）
├── std/std.py.py3        # Python 标程
├── gen.py                # 数据生成器（固定种子、可复现）
└── solution/题解.md       # 思路 + 参考代码
```

## 使用

生成/重放数据（每个题目包内）：

```bash
cd P0604
for i in $(seq 1 10); do python3 gen.py $i > testdata/$i.in; done
for i in $(seq 1 10); do python3 std/std.py.py3 < testdata/$i.in > testdata/$i.out; done
```

校验全部题目（校验会按各题 `config.yaml` 的测试点数逐一回归标程）：

```bash
python3 hydro/hw06/validate.py
```

## 说明

- Hydro 评测为**传统题**，语言放开 Python 即可；`std` 后缀 `std.py.py3` 与 Hydro 的 Python3 语言键一致。
- 基础题为固定输出，方便自查对三种分支与逻辑运算的掌握；综合题覆盖三态、相等、负数/零、五档等级、
  边界值（90/89/60/59/0/100）等，并保留大数据（±10⁹）测试点。
- P0604、P0605 恰好对应 hw06 任务卡的两个实验（🔵 比大小、🔵 成绩等级判定），
  与基础题一起完整覆盖了"三态判断、多分支、逻辑运算、边界验证"四条主线。
