# 正负与奇偶判断（基础）

## 题目描述

对固定整数 `n = -5`，写出两段判断并输出两行固定结果：

1. 用 `if-elif-else` 判断它是**正数、负数还是零**，打印对应结果。
2. 用 `if-else` 判断它是**偶数还是奇数**，打印对应结果。

> 正负是用 `if-elif-else` 的三态判断，奇偶是用 `%` 取模的 `if-else` 判断。这是把条件结构用到两条常用判断上。
> **本题无输入**，输出固定。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

共两行：

- 第一行：`负数`
- 第二行：`奇数`

## 样例 #1

```input1
（本题无输入）
```

```output1
负数
奇数
```

## 提示

- 三态正负：`if n > 0: 正数`；`elif n < 0: 负数`；`else: 零`。
- 奇偶：`if n % 2 == 0: 偶数`；`else: 奇数`（`-5 % 2 == 1`，不是 0，所以是奇数）。
- 两段判断各自 `if` 开头，结果各占一行。

## 数据范围

无输入，使用题目给出的固定数据即可。
