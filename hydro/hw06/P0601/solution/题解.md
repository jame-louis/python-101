# P0601 正负与奇偶判断（基础·无输入）

## 思路

两段独立判断：正负用 `if-elif-else`（三态），奇偶用 `if-else`（两态、`%` 取模）。注意 `-5 % 2` 在 Python 中结果是 `1`（向负无穷取余），不等于 0，因此被判定为"奇数"。

## 参考代码

```python
n = -5
if n > 0:
    print("正数")
elif n < 0:
    print("负数")
else:
    print("零")

if n % 2 == 0:
    print("偶数")
else:
    print("奇数")
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1-5 | 全部相同（无输入、固定输出） |

## 常见错误

- 把三个判定写成并列 `if` 而非 `if-elif-else` → 正负与零的判断重复执行，逻辑冗余。
- 用 `else if` 而非 `elif` → 语法错误。
- 认为 `-5` 是偶数 → 忘了 Python 负数的取模规则。
- 两段判断缩进错乱 → 结果串行或逻辑错位。
