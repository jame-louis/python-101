# P0702 break/continue 控制流程（基础·无输入）

## 思路

用 `end=" "` 让 `print` 不换行，数字间以空格相连。两段分别演示：

- `continue`：当 `i == 3` 时跳过本次，只剩 1,2,4,5,6。
- `break`：当 `i == 5` 时跳出整个循环，只剩 1,2,3,4。

注意输出行首标签用 `print("标签：", end="")`，整段结束后补一个 `print()` 换行，使两行各自独立。

## 参考代码

```python
print("continue跳过3：", end="")
for i in range(1, 7):
    if i == 3:
        continue
    print(i, end=" ")
print()
print("break遇到5停止：", end="")
for i in range(1, 7):
    if i == 5:
        break
    print(i, end=" ")
print()
```

## 测试点设计

|--------|------|
| 1-5 | 全部相同（无输入、固定输出） |

## 常见错误

- 把 `continue`/`break` 放错缩进块（放在 `if` 外），导致逻辑错误。
- 忘记末尾 `print()` 换行，两行叠在一起。
- 混淆二者：`continue` 仍会继续下一圈，`break` 是整个循环停掉。
