# hw07 —— 循环结构（Hydro 题目集）

对应课程第 7 讲实验任务卡 `src/assignments/hw07.md`，共 **5 道 Python 传统题**，每题一个自包含
Hydro 题目包（`problem.yaml` + `problem_zh.md` + `testdata/` + `std/` + `solution/`）。

## 知识点约束（关键）

本套题贴合**当前学生已学内容**：本讲系统学习循环结构（`for`+`range()`、`while`、`break`/`continue`、
嵌套循环与前缀/变量追踪），且第 6 讲已学条件结构（`if`/`elif`/`else`）。因此题目**可自由使用
`if`/`for`/`while`/`break`/`continue`**：

- **基础题（P0701–P0703）无输入，输出固定**，覆盖 `for`+`range` 累加、`break`/`continue` 控制流程、
  嵌套循环数字图案三块基础能力。
- **综合题（P0704–P0705）有输入 + 带提示语**：P0704 用 `while True + break` 读到结束标记统计；
  P0705 用两层循环 + 条件判断素数（挑战综合）。

> ⚠️ 死循环风险：P0704 若不写 `break` 就是死循环、评测超时。请用"初值、条件、更新"三要素自查。

## 题目一览

| PID | 题目 | 类型 | 考点 | 处理方式 |
|-----|------|------|------|----------|
| P0701 | for+range() 累加求和（基础） | 无输入 | `range(1,n+1)` 累加、偶数和、`+=` | 固定输出 |
| P0702 | break/continue 控制流程（基础） | 无输入 | `break` 跳出 / `continue` 跳过、`end=" "` | 固定输出 |
| P0703 | 嵌套循环数字图案（基础） | 无输入 | 嵌套循环下三角、变量追踪、`end=""` | 固定输出 |
| P0704 | while 读入统计（综合选做） | 输入+提示 | `while True`+`break`、标记值 -1、计数累加 | 严格逐字匹配 |
| P0705 | 质数判断（综合选做） | 输入+提示 | 两层循环+条件判素数、`int(x**0.5)` 剪枝、`break` | 严格逐字匹配 |

## 输入与严格匹配说明

- **P0701–P0703（基础）**：无输入，`.in` 放占位 `no-input`；每套 5 个相同测试点。
- **P0704–P0705（综合选做）**：有输入。按课程习惯带提示语读取，评测为**严格逐字匹配**：
  标程以 `print(提示语)` 先输出一行提示语，再读入，学生必须复现**完全一致**的提示语与输出格式
  （题面已在「提示」中明确标注）。每套 10 个测试点。

> P0704 的提示语 `请输入整数（输入-1结束）：` 会随每次读取各出现一次（每行一个整数）；
> P0705 的提示语 `请输入一个正整数：` 出现一次，随后一个 `print()` 空行，再输出素数行与个数行。

## 使用

生成/重放数据（每个题目包内）：

```bash
cd P0704
for i in $(seq 1 10); do python3 gen.py $i > testdata/$i.in; done
for i in $(seq 1 10); do python3 std/std.py.py3 < testdata/$i.in > testdata/$i.out; done
```

校验全部题目（校验会按各题 `config.yaml` 的测试点数逐一回归标程）：

```bash
python3 hydro/hw07/validate.py
```

## 说明

- Hydro 评测为**传统题**，语言放开 Python 即可；`std` 后缀 `std.py.py3` 与 Hydro 的 Python3 语言键一致。
- 基础题为固定输出，方便学生自查对三种循环基础的掌握；综合题覆盖样例、单个数/直接结束、全相同、
  含负数/0、最小素数（2）、无数（1）、边界混合等边界，并保留大数据（P0705 ≤10⁵）测试点。
- P0704、P0705 恰好对应 hw07 任务卡的两个进阶任务（🔴 while 读入统计、🔴 质数判断），
  与基础题一起完整覆盖了"遍历求和、流程控制、嵌套图案、标记值循环、循环+条件综合"五条主线。
