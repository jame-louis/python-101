# while 读入统计（综合选做）

## 题目描述

请你不断读入整数，直到读到**标记值 `-1` 结束**，统计并输出所有数字的**有效个数**与**总和**（`-1` 本身不参与统计）。

- 用 `while True:` 建立无限循环，逐行用 `input()` 读入一个整数。
- 若该数为 `-1`，用 `break` 跳出循环（结束读取）；否则累加并计数。
- 这是"读数据直到结束标记"的标准写法——条件是否满足要在**运行中**才知道，所以用 `while` 而非 `for`。

> 综合选做题，需要用到 `while True + break`。**若忘记 `break` 就是一个死循环**，请务必检查。

## 输入格式

逐行读入若干整数，每行一个，以 `-1` 结束。程序每读一个数前，须先输出一行固定提示语：

```
请输入整数（输入-1结束）：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。提示语必须与上面**完全一致**（含全角括号与全角冒号）。每读入一行数字，就对应一行提示语，最后再输出统计结果。

## 输出格式

读取结束时（读到 `-1`），输出两行：

- 第一行：`个数： K`（有效数字个数，不含 -1）
- 第二行：`总和： S`（所有有效数字之和）

## 样例 #1

```input1
5
10
-1
```

```output1
请输入整数（输入-1结束）：
请输入整数（输入-1结束）：
请输入整数（输入-1结束）：
个数： 2
总和： 15
```

## 样例 #2

```input2
7
-1
```

```output2
请输入整数（输入-1结束）：
请输入整数（输入-1结束）：
个数： 1
总和： 7
```

## 提示

- 先打印一行提示语：`print("请输入整数（输入-1结束）：")`，再读一行：`x = int(input())`。
- 用 `count` 记录个数、`total` 记录总和，初始都为 0。
- 判断 `x == -1` 就 `break`；否则 `total += x; count += 1`。
- 请对照"初值、条件、更新"三要素自查，确认循环一定能以 `-1` 终止。

## 数据范围

| 测试点 | 数字个数 | 数值范围 |
|--------|----------|----------|
| 1-4 | 含样例、单个数、直接结束、全相同等边界 | $-10^6 \le x \le 10^6$ |
| 5-7 | $\le 5$（含负数/0） | $-10^6 \le x \le 10^6$ |
| 8-9 | $\le 50$ | $-10^6 \le x \le 10^6$ |
| 10 | $\le 200$ | $0 \le x \le 10^6$ |

保证输入以 `-1` 结束，且 `-1` 只作为结束标记出现。
