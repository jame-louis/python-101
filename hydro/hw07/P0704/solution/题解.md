# P0704 while 读入统计（综合·输入+提示）

## 思路

读入数量未知、以标记值结束了告诉程序——正是 `while True + break` 的标准场景。每次 `input()` 读一行，是 `-1` 就 `break`，否则累加进 `total`、计数加一。

对照三要素：`count=0; total=0` 是**初值**；`while True` 配 `break`（读到 `-1`）是**结束条件**；`total += x; count += 1` 是**更新**。

## 参考代码

```python
count = 0
total = 0
while True:
    print("请输入整数（输入-1结束）：")
    x = int(input())
    if x == -1:
        break
    total += x
    count += 1
print("个数：", count)
print("总和：", total)
```

## 常见错误

- 忘写 `break` → 读不到 -1，死循环超时。务必检查"初值、条件、更新"。
- 提示语写错（全角括号/冒号少一个、多空格）→ 逐字匹配不过。
- 把 `-1` 也算进总和/个数 → 结果多 1。应在 `break` 前停止累加。
- 用 `split()` 一次读完再循环 → 失去"读到标记结束"的本意（每行一个数时逐行 `int(input())` 即可）。
