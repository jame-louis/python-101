# P0703 嵌套循环数字图案（基础·无输入）

## 思路

嵌套循环的经典：外层变量 `i` 是行号，内层变量 `j` 从 1 跑到 `i`。因为内层 `range(1, i+1)` 的终点由外层 `i` 决定，所以"每行几个数 = 当前行号"，构成下三角。行内用 `end=""` 让数字直接相连、不换行，一行结束再 `print()` 换行。

## 参考代码

```python
for i in range(1, 6):
    for j in range(1, i + 1):
        print(j, end="")
    print()
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1-5 | 全部相同（无输入、固定输出） |

## 常见错误

- 内层误用 `range(1, 6)` → 每行都打满 5 个数，不成三角形。应写 `range(1, i + 1)`。
- 忘记行末 `print()` → 所有数字挤成一行。
- 先不画变量追踪表就硬写列边界 → `+1` 忘写导致少一列。
