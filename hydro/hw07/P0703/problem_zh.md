# 嵌套循环数字图案（基础）

## 题目描述

请用**嵌套循环**打印一个"数字下三角"图案，共 5 行：

- 第 1 行打印 `1`（1 个数）
- 第 2 行打印 `12`（2 个数）
- 第 3 行打印 `123`（3 个数）
- ……
- 第 5 行打印 `12345`（5 个数）

> 外层控制"行"，内层控制"每行打印几个数"，**列数 = 当前行号**。这就是"外层一次、内层一轮"。
> **本题无输入**，输出固定。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

共 5 行，每行是该行的数字串（不换行的数字直接相连，行末换行）：

```
1
12
123
1234
12345
```

## 样例 #1

```input1
（本题无输入）
```

```output1
1
12
123
1234
12345
```

## 提示

- 外层：`for i in range(1, 6):`，`i` 是行号。
- 内层：`for j in range(1, i + 1):`，`j` 从 1 到当前行号 `i`。
- 内层里 `print(j, end="")` 不换行、不加空格符；外层每行结束后 `print()` 换行。
- 先画**变量追踪表**：外 `i` 换一次，内 `j` 完整走一遍，列数正好等于行号。

## 数据范围

无输入，使用题目给出的固定数据即可。
