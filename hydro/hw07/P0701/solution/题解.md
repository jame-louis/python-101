# P0701 for+range() 累加求和（基础·无输入）

## 思路

`for` 循环配合 `range()` 逐个累加。`range(1, 201)` 生成 1 到 200（前闭后开，故终点写 201）。
用一个 `total` 变量累加所有整数，另用一个 `even` 累加偶数（`i % 2 == 0`）。

## 参考代码

```python
total = 0
even = 0
for i in range(1, 201):
    total += i
    if i % 2 == 0:
        even += i
print("1到200的和：", total)
print("其中偶数的和：", even)
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1-5 | 全部相同（无输入、固定输出） |

## 常见错误

- `range(1, 200)` → 差 1 缺尾，漏掉 200。应写 `range(1, 201)`。
- 忘记 `+=` 是累加赋值，直接用 `total = i` 覆盖 → 结果错误。
- 偶数和误用 `sum(range(0, 201, 2))` 也能做（但本讲重点是 `for` 累加），思路一致即可。
