# for+range() 累加求和（基础）

## 题目描述

请用 `for` 循环配合 `range()` 计算并输出两行固定结果：

1. **1 到 200 的所有整数之和**。
2. 其中**所有偶数之和**。

> 累加求和是"循环派上用场"的经典场景：不用一条条手写加法，一个 `for` 循环自动把每一项累进 `total`。
> **本题无输入**，输出固定。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

共两行：

- 第一行：`1到200的和： 20100`
- 第二行：`其中偶数的和： 10100`

## 样例 #1

```input1
（本题无输入）
```

```output1
1到200的和： 20100
其中偶数的和： 10100
```

## 提示

- 用 `for i in range(1, 201)` 遍历 1 到 200（`range` 差 1 缺尾，第二个参数要写 201）。
- 用变量 `total` 反复累加：`total += i` 等价于 `total = total + i`。
- 判断偶数：`if i % 2 == 0:` 再用另一个变量累加偶数之和。
- `print("前缀：", 表达式)` 中间会输出**空格**，请保持输出格式与样例一致。

## 数据范围

无输入，使用题目给出的固定数据即可。
