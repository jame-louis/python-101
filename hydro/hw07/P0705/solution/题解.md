# P0705 质数判断（综合·输入+提示）

## 思路

"循环 + 条件"的综合题。外层遍历 2 到 n，内层做素性检查。判断 `x` 是否素数只需试除到 `int(x**0.5)`：若中途找到约数就用 `break` 跳出内层、把 `is_prime` 置为 `False`。最后把素数收集成一个字符串，用单个空格相连（`strip` 去掉尾部空格），再输出个数。

边界：`1` 不是素数；`2` 的最小素，内层 `range(2, int(2**0.5)+1) = range(2, 2)` 为空，自动判为素数。

## 参考代码

```python
n = int(input("请输入一个正整数："))
primes = []
for x in range(2, n + 1):
    is_prime = True
    for d in range(2, int(x ** 0.5) + 1):
        if x % d == 0:
            is_prime = False
            break
    if is_prime:
        primes.append(x)
print()

line = ""
for p in primes:
    line += str(p) + " "
print(line.strip())
print("共", len(primes), "个素数")
```

## 常见错误

- 忘记 `+2` 从 2 开始、把 `1` 当素数 → 需从 `range(2, n+1)` 遍历且素性判定只对 `x>1`。
- 内层终点写成 `n` 而非 `int(x**0.5)` → 会超时（大数据）。
- `break` 写在外层 → 提前终止整个外层循环，丢素数。应写在内层找到约数处。
- 输出末尾多个空格 → 用 `strip()` 去尾部空格，保证单空格分隔。
- 提示语后忘了 `print()` 换行 → 输出与样例对不上。
