# 质数判断（综合选做）

## 题目描述

读入一个正整数 `n`，输出 **`n` 以内（含）的所有素数**，以及它们的**个数**。

- **素数（质数）**：大于 1，且只有 `1` 和它本身两个约数的整数。如 `2, 3, 5, 7, 11, …`。
- 判断一个数 `x` 是否为素数：用内层循环检查从 `2` 到 `int(x**0.5)` 有没有约数，找到就 `break` 判定为合数。
- 外层 `for` 一个个检查 `2` 到 `n`，素数就收集起来。

> 综合（挑战）选做题：需要**两层循环 + 条件 + break**，是本讲"循环与条件综合"的代表题。

## 输入格式

一行一个正整数 `n`。程序须先显示提示语再读取：

```
请输入一个正整数：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。提示语必须与上面**完全一致**（含全角冒号），程序在读取后用一行 `print()` 换行，再输出结果。

## 输出格式

读取并换行后，共两行：

- 第一行：`n` 以内所有素数，用**单个空格**分隔（无行尾空格）。
- 第二行：`共 K 个素数`（`K` 为素数个数）。

## 样例 #1

```input1
7
```

```output1
请输入一个正整数：

2 3 5 7
共 4 个素数
```

## 样例 #2

```input2
10
```

```output2
请输入一个正整数：

2 3 5 7
共 4 个素数
```

## 样例 #3

```input3
1
```

```output3
请输入一个正整数：

共 0 个素数
```

## 提示

- 读入：`n = int(input("请输入一个正整数："))`，随后 `print()` 换行。
- 判素数：对每个 `x`，置 `is_prime = True`，再 `for d in range(2, int(x**0.5) + 1)` 找约数，命中取约数则 `is_prime = False` 并 `break`。
- 收集：把素数拼成一个字符串或列表，输出时用单个空格相连、**末尾不要有多余空格**。
- 边界：`1` 不是素数；`2` 是最小素数（内层循环为空，直接判为素数）。

## 数据范围

$1 \le n \le 10^5$。

| 测试点 | n 范围 |
|--------|--------|
| 1-5 | 含样例与边界（1、2、10、20 等） |
| 6-7 | $\le 100$ |
| 8-9 | $\le 2000$ |
| 10 | $\le 10^5$ |
