# P0903 map 与 filter（基础·无输入）

## 思路

`map` 把函数作用到每个元素得到"变换结果"，`filter` 只保留下"函数返回 True"的元素。两者返回迭代器，用 `list()` 转成列表再打印。

## 参考代码

```python
nums = [1, 2, 3, 4]
print(list(map(lambda x: x * x, nums)))      # [1, 4, 9, 16]

a = [22, 18, 30, 16, 25]
print(list(filter(lambda x: x >= 18, a)))    # [22, 18, 30, 25]
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1-5 | 全部相同（无输入、固定输出） |

## 常见错误

- 把 `filter` 用成 `map`（用 `x*x` 那种变换句来筛选）→ filter 需要布尔判定。
- 忘 `list()` → 打印出 `<map object ...>` 迭代器地址。
- 边界 `>=` 写成 `>` → 恰好 18 被漏掉。
