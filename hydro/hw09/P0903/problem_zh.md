# map 与 filter（基础）

## 题目描述

用内置函数 `map` 与 `filter` 处理两组数据，打印两行固定结果：

1. 对 `nums = [1, 2, 3, 4]`，用 `map(lambda x: x * x, nums)` 求每个数的**平方**，转成列表打印。
2. 对 `a = [22, 18, 30, 16, 25]`，用 `filter(lambda x: x >= 18, a)` 保留**成年（≥18）**，转成列表打印。

> `map(函数, 可迭代对象)` 逐个变换返回迭代器；`filter(函数, 可迭代对象)` 保留使函数为真的元素。两者都要 `list()` 才能直接打印。
> **本题无输入**，输出固定。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

共两行：

```
[1, 4, 9, 16]
[22, 18, 30, 25]
```

## 样例 #1

```input1
（本题无输入）
```

```output1
[1, 4, 9, 16]
[22, 18, 30, 25]
```

## 提示

- 平方：`list(map(lambda x: x * x, nums))`。
- 保留成年：`list(filter(lambda x: x >= 18, a))`（16 不足 18 被过滤）。
- 别忘 `list()`：map/filter 返回的是迭代器，直接打印对象地址而非内容。

## 数据范围

无输入，使用题目给出的固定数据即可。
