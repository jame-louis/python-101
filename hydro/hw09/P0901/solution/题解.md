# P0901 lambda 改写 def（基础·无输入）

## 思路

`lambda` 是单表达式的匿名函数。这里用 `add = lambda a, b: a + b` 实现两数相加，等价于 `def` 版，只是不用起名、自动返回表达式结果。

## 参考代码

```python
add = lambda a, b: a + b
print(add(3, 4))      # 7
print(add(10, 20))    # 30
print(add(-1, 1))     # 0
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1-5 | 全部相同（无输入、固定输出） |

## 常见错误

- 在 `lambda` 里写 `return` 或多条语句 → 语法错误（它只能是单表达式）。
- 把 `lambda a, b:` 写成 `lambda a, b`（漏冒号）→ 语法错误。
- 三处调用数值抄错 → 求和结果不对。
