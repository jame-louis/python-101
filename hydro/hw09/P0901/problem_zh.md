# lambda 改写 def（基础）

## 题目描述

用**匿名函数** `lambda` 实现一个两数相加的函数，并调用三次打印三行固定结果。

- `add = lambda a, b: a + b`，等价于 `def add(a, b): return a + b`。
- 三次调用：`add(3, 4)`、`add(10, 20)`、`add(-1, 1)`。

> `lambda 参数: 表达式` 只含一个表达式、自动返回结果，不用起名、不用 `return`、不用 `def`。
> **本题无输入**，输出固定。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

共三行：

```
7
30
0
```

## 样例 #1

```input1
（本题无输入）
```

```output1
7
30
0
```

## 提示

- 构造：`add = lambda a, b: a + b`。
- 调用并打印：`print(add(3, 4))`、`print(add(10, 20))`、`print(add(-1, 1))`。
- 核对：`3+4=7`、`10+20=30`、`-1+1=0`。

## 数据范围

无输入，使用题目给出的固定数据即可。
