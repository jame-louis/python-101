# P0905 预测结果 + 置信度（综合·输入+提示）

## 思路

`return pred, conf` 实际返回一个元组 `(pred, conf)`，调用处用 `result, confidence = predict(s)` 一行解包。用条件表达式算结果、用置信度公式给把握，最后格式化输出。

## 参考代码

```python
def predict(score):
    pred = "通过" if score >= 60 else "不通过"
    conf = min(score / 100, 0.99) + 0.01
    return pred, conf

print("请输入成绩：")
s = int(input())
result, confidence = predict(s)
print(f"预测: {result}, 置信度: {confidence:.2f}")
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1 | 样例（85 → 通过 0.86） |
| 2 | 样例（59 → 不通过 0.60） |
| 3 | 边界（60 → 通过 0.61） |
| 4 | 90 |
| 5 | 100 |
| 6 | 0 |
| 7-8 | 全带随机 |
| 9-10 | 中高带随机 |

## 常见错误

- 只用 `return pred` 忘返回置信度 → 解包时少一个值报错。
- 置信度公式抄错（如忘 `+0.01` 或 `min` 写反）→ 数值不对。
- 格式化漏 `.2f` → 小数位数不对。
- 提示语写错（漏全角冒号）→ 逐字匹配不过。
