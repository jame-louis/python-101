# 预测结果 + 置信度（综合选做）

## 题目描述

定义一个**多返回值**函数 `predict(score)`，读入一个成绩，输出"预测结果 + 置信度"。

- `predict(score)`：结果 `"通过"`（score ≥ 60）或 `"不通过"`；置信度用简化公式 `min(score/100, 0.99) + 0.01`。
- 用 `return 结果, 置信度` 一次性返回**元组**，调用时**一行解包**成两个变量。
- 这正是模型推理的常见画风：不只给结论，还给把握多大。

> 综合选做题，用到多返回值、条件表达式与两位小数格式化。

## 输入格式

**一行**一个整数 `score`（0 到 100）。程序先显示提示语再读取：

```
请输入成绩：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。提示语必须与上面**完全一致**（含全角冒号），程序先打印提示语，再用裸 `input()` 读入。

## 输出格式

读取后输出一行：

```
请输入成绩：
预测: 通过, 置信度: 0.86
```

## 样例 #1

```input1
85
```

```output1
请输入成绩：
预测: 通过, 置信度: 0.86
```

## 样例 #2

```input2
59
```

```output2
请输入成绩：
预测: 不通过, 置信度: 0.60
```

## 提示

- 定义：`def predict(score):`，体内 `pred = "通过" if score >= 60 else "不通过"`、`conf = min(score / 100, 0.99) + 0.01`，最后 `return pred, conf`。
- 调用解包：`result, confidence = predict(s)`。
- 输出：`print(f"预测: {result}, 置信度: {confidence:.2f}")`。
- 核对：`85` → `0.85 + 0.01 = 0.86`；`59` → `0.59 + 0.01 = 0.60`。

## 数据范围

$0 \le \text{score} \le 100$（整数）。

| 测试点 | 说明 |
|--------|------|
| 1-4 | 含样例、通过、不通过、边界 60 |
| 5-6 | 边界（100、0） |
| 7-10 | 随机 |
