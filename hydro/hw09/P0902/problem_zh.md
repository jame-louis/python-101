# sorted 按 key 排序（基础）

## 题目描述

对元组列表 `pairs = [("b", 2), ("a", 4), ("c", 1)]`，用内置函数 `sorted` 配合 `key=lambda t: t[1]` 按**第二个元素**排序，打印两行固定结果：

1. **升序**：`sorted(pairs, key=lambda t: t[1])`
2. **降序**：`sorted(pairs, key=lambda t: t[1], reverse=True)`

> `sorted(iterable, key=函数, reverse=布尔)` 返回**新列表**，不动原列表；`key` 这个函数会被作用到每个元素、用返回值为排序依据。
> **本题无输入**，输出固定。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

共两行：

```
[('c', 1), ('b', 2), ('a', 4)]
[('a', 4), ('b', 2), ('c', 1)]
```

## 样例 #1

```input1
（本题无输入）
```

```output1
[('c', 1), ('b', 2), ('a', 4)]
[('a', 4), ('b', 2), ('c', 1)]
```

## 提示

- 元组 `("b", 2)` 的第二个元素是 `t[1]`。
- 升序按 1,2,4 → `c, b, a`；降序按 4,2,1 → `a, b, c`。
- 直接用 `print(sorted(...))`，让 Python 负责元组列表的格式化。

## 数据范围

无输入，使用题目给出的固定数据即可。
