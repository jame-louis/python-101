# P0902 sorted 按 key 排序（基础·无输入）

## 思路

`sorted` 的 `key` 参数接收一个函数，作用到每个元素、取返回值作为排序依据。对元组列表按第二元素排，就写 `key=lambda t: t[1]`。`reverse=True` 变降序。它返回**新列表**，原 `pairs` 不变。

## 参考代码

```python
pairs = [("b", 2), ("a", 4), ("c", 1)]
print(sorted(pairs, key=lambda t: t[1]))
print(sorted(pairs, key=lambda t: t[1], reverse=True))
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1-5 | 全部相同（无输入、固定输出） |

## 常见错误

- `key=lambda t: t[0]` 按第一个元素排了 → 结果不对，应 `t[1]`。
- 用 `pairs.sort(...)` → 虽能排，但本例期望直接 `print(sorted(...))` 输出新列表（二者结果文本相同也可）。
- 忘 reverse → 第二行没有按要求降序。
