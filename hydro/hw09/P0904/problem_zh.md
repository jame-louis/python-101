# 安全除法（综合选做）

## 题目描述

读入两个整数**被除数**与**除数**，做除法并保留两位小数输出；当除数为 0 时，用 `try/except` 捕获异常，输出 `除数不能为 0` 而**不让程序崩溃**。

- 用 `try: 商 = a / b`；`except ZeroDivisionError:` 时输出 `除数不能为 0`。
- 这正是"预判可能出错，判定并接收异常"的严谨工程写法。

> 综合选做题，用到 `try/except` 与两位小数格式化。

## 输入格式

**一行**两个整数 `a`、`b`，用空格分隔。程序先显示提示语再读取：

```
请输入 被除数 除数（空格分隔）：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。提示语必须与上面**完全一致**（含全角冒号），程序先打印提示语，再用裸 `input()` 读入整行。

## 输出格式

读取后输出一行。成功时商保留 **2 位小数**；除数为 0 时输出固定文案：

```
请输入 被除数 除数（空格分隔）：
商 = 2.00
```

或（除数为 0）：

```
请输入 被除数 除数（空格分隔）：
除数不能为 0
```

## 样例 #1

```input1
10 5
```

```output1
请输入 被除数 除数（空格分隔）：
商 = 2.00
```

## 样例 #2

```input2
5 0
```

```output2
请输入 被除数 除数（空格分隔）：
除数不能为 0
```

## 提示

- 读入并拆分：`a, b = map(int, input().split())`。
- 输出成功：`print(f"商 = {a / b:.2f}")`。
- 捕获：`except ZeroDivisionError: print("除数不能为 0")`。
- 验证：`10 5` → `2.00`；`7 3` → `2.33`；`5 0` → `除数不能为 0`。

## 数据范围

$a$、$b$ 为整数，$|a|, |b| \le 10^9$，$b$ 可为 0。

| 测试点 | 说明 |
|--------|------|
| 1-2 | 样例（正常 / 除零） |
| 3-4 | 整除 / 非整除 |
| 5 | 负被除数 |
| 6-10 | 随机（含除零、含负数、大数） |
