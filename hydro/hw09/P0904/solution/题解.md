# P0904 安全除法（综合·输入+提示）

## 思路

把可能出错的 `a / b` 放进 `try`，除数为 0 时的 `ZeroDivisionError` 交给 `except` 接住，返回固定文案而不是让程序崩溃。这正是"预判错误 + 接收异常"的严谨写法。

## 参考代码

```python
print("请输入 被除数 除数（空格分隔）：")
a, b = map(int, input().split())
try:
    print(f"商 = {a / b:.2f}")
except ZeroDivisionError:
    print("除数不能为 0")
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1 | 样例（10 5 → 2.00） |
| 2 | 样例（5 0 → 除数不能为 0） |
| 3 | 非整除（7 3 → 2.33） |
| 4 | 整除 |
| 5 | 负被除数 |
| 6 | 被除数为 0 |
| 7-8 | 小随机（偶发除零） |
| 9-10 | 大随机（±10⁹，含除零） |

## 常见错误

- 忘加 `try/except` → 除数为 0 直接 `ZeroDivisionError` 崩溃，评测判非零退出。
- 输出成功时没 `:.2f` → 小数位数不对。
- 提示语写错（漏全角冒号/空格）→ 逐字匹配不过。
- 捕获写 `except:` 裸捕获 → 虽能接住但对高级错误太粗暴（本讲强调精准捕获子类）。
