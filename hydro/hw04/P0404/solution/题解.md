# P0404 成绩统计（综合选做）—— 题解

## 思路

用「一整行读取 → `split` → `map`」把数据一次装进列表，再综合运用 `sorted` / 下标 / `sum` / `len` 统计。中位数用 `(s[(n-1)//2] + s[n//2]) / 2` 一次算好，**无需分支**。

> ⚠️ 本题选严格匹配，提示语必须与题面完全一致（含全角冒号），读取后用一个 `print()` 换行，再输出结果。

## 参考代码

```python
scores = list(map(int, input("请输入成绩（空格分隔）：").split()))
print()

s = sorted(scores)
n = len(s)

print("升序排序：", " ".join(map(str, s)))
print("最高分：", s[-1])
print("最低分：", s[0])
print("总分：", sum(scores))
print("平均分：", f"{sum(scores) / n:.2f}")
print("中位数：", f"{(s[(n - 1) // 2] + s[n // 2]) / 2:.2f}")
```

## 关键点

- `list(map(int, input().split()))`：一行字符串 → 拆词 → 逐项转 int → 装箱成列表。
- 中位数公式对奇偶都成立：奇数时 `(n-1)//2 == n//2`，两个下标相同；偶数时取中间两个的平均。
- 平均分/中位数用 f-string 保留两位小数，保证与预期逐字一致。
