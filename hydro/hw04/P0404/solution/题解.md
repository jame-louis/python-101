# P0404 文本转小写清洗 —— 题解

## 思路

练习"遍历原列表 + `append` 组装新列表"的批量清洗范式，这也是 NLP 预处理最常见写法之一：

1. 把原始单词读入 `words` 列表。
2. 对每个词调用 `w.lower()` 得到全小写，`append` 进 `cleaned`。
3. 逐行输出 `cleaned`。

若不需要留原词，也可以直接原地改写，但按题意要求构造新列表。

## 参考代码

```python
n = int(input())
words = [input() for _ in range(n)]

cleaned = []
for w in words:
    cleaned.append(w.lower())

for c in cleaned:
    print(c)
```

## 复杂度

$O(\text{总字符数})$，可轻松处理 $10^5$ 个单词。
