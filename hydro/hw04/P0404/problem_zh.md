# 成绩统计（综合选做）

## 题目描述

把若干实验成绩读入一个列表，然后统计并输出：升序排序结果、最高分、最低分、总分、平均分、中位数。

- **中位数**：元素个数为奇数时取正中间一个；为偶数时取中间两个的平均。
  用表达式 `(s[(n-1)//2] + s[n//2]) / 2` 一次算好，**不需用 `if` 判断奇偶**。
- 一句话综合运用：**读入 → sorted 排序 → 下标/切片取元素 → sum/len 统计**，全程可不用循环。

> 综合选做题，可结合前面学的 `input()`、`split()`、`map()` 一次性把一整行数据变成整数列表。

## 输入格式

**一行**若干个整数成绩，用空格分隔。程序须先显示提示语再读取：

```
请输入成绩（空格分隔）：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。提示语必须与上面**完全一致**（含全角冒号），程序在读取后用一行 `print()` 换行，再输出统计结果。

## 输出格式

读取并换行后，共 6 行：

```
升序排序： 66 78 88 90 95
最高分： 95
最低分： 66
总分： 417
平均分： 83.40
中位数： 88.00
```

- 平均分、中位数保留 **2 位小数**。
- 升序排序元素用空格分隔、在同一行。

## 样例 #1

```input1
78 88 95 66 90
```

```output1
请输入成绩（空格分隔）：
升序排序： 66 78 88 90 95
最高分： 95
最低分： 66
总分： 417
平均分： 83.40
中位数： 88.00
```

## 样例 #2

```input2
78 88 95 66
```

```output2
请输入成绩（空格分隔）：
升序排序： 66 78 88 95
最高分： 95
最低分： 66
总分： 327
平均分： 81.75
中位数： 83.00
```

## 提示

- 读入整行并一次转成整数列表：`scores = list(map(int, input("请输入成绩（空格分隔）：").split()))`
- 排序：`sorted(scores)` 返回新列表，不用改原列表；或 `scores.sort()` 原地。
- 平均值：`sum(scores) / len(scores)`，用 f-string 保留两位：`f"{...:.2f}"`。
- 中位数：排序后取 `(s[(n-1)//2] + s[n//2]) / 2` 并保留两位小数。

## 数据范围

| 测试点 | 成绩个数 |
|--------|----------|
| 1-5 | 含样例、偶数个、全相同、单元素、大量重复等边界 |
| 6-7 | $\le 300$ |
| 8-10 | $\le 10^5$ |

单个成绩范围 $0 \le$ 成绩 $\le 1000$。
