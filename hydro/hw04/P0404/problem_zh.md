# 文本转小写清洗

## 题目描述

在自然语言处理（NLP）中，**文本清洗**是常见预处理步骤。现有一批英文单词，请把每个单词统一转为**全小写**后输出。

要求：用列表保存原始单词，用 **for 循环 + `append`** 构造一个清洗后的新列表，再逐行输出清洗结果。

## 输入格式

第一行一个整数 $n$，表示单词个数。

接下来 $n$ 行，每行一个由大小写英文字母组成的单词。

## 输出格式

共 $n$ 行，第 $i$ 行输出第 $i$ 个单词转全小写后的结果。

## 样例 #1

```input1
3
Hello
WORLD
python
```

```output1
hello
world
python
```

## 提示

- 小写转换可调用字符串方法 `str.lower()`。
- 可参考练习"逐条 append 组装新列表"的批量处理思路。

## 数据范围

| 测试点 | $n$ | 单词最大长度 |
|--------|-----|--------------|
| 1-3 | $\le 12$ | $\le 8$ |
| 4-7 | $\le 1000$ | $\le 20$ |
| 8-10 | $\le 10^5$ | $\le 30$ |

单词仅由 `a-z` / `A-Z` 组成。
