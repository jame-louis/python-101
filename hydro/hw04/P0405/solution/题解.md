# P0405 训练损失分析（综合选做）—— 题解

## 思路

读入一轮的损失值列表，用内置函数做统计，再用**元组**打包「轮次, 损失」。结合了列表统计与元组使用，贴近 AI 训练日志分析场景。

> ⚠️ 本题选严格匹配，提示语必须与题面完全一致（含全角冒号），读取后用一个 `print()` 换行，再输出结果。

## 参考代码

```python
losses = list(map(float, input("请输入各轮损失（空格分隔）：").split()))
print()

best = min(losses)
epoch = losses.index(best) + 1
record = (epoch, best)

print("最低损失：", best)
print("最优轮次：", epoch)
desc = sorted(losses, reverse=True)
print("从高到低：", " ".join(map(str, desc)))
print("最优记录（轮次, 损失）：", record)
```

## 关键点

- `list.index(x)` 返回 `x` **第一次**出现的下标；下标从 0 起，所以轮次 = 下标 + 1。
- `min()`、`sorted(reverse=True)` 都是不写循环的统计/排序写法。
- 损失取一位小数，`map(str, float)` 打印干净（如 `0.2`），保证严格匹配稳定。
