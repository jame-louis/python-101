# P0405 成绩统计与中位数 —— 题解

## 思路

先排序，再用下标取中位数：

- 排序：`scores.sort()` 原地升序，或 `sorted(scores)` 返回新列表。
- 最高/最低：`max()` / `min()`。
- 中位数：
  - $n$ 为奇数：`scores[n // 2]`（如 $n=5$，中间下标为 `2`）。
  - $n$ 为偶数：`scores[n//2 - 1]` 和 `scores[n//2]`（如 $n=4$，取下标 `1` 和 `2`）。

## 参考代码

```python
n = int(input())
scores = list(map(int, input().split()))
scores.sort()
print(' '.join(map(str, scores)))
print(max(scores))
print(min(scores))
if n % 2 == 1:
    print(scores[n // 2])
else:
    print(scores[n // 2 - 1], scores[n // 2])
```

## 复杂度

排序 $O(n\log n)$。

## 易错点

- 偶数元素时不要只输出其中一个，要输出中间两个。
- 先把输入读成整数再排序，避免比较数组元素被当成字符串。
