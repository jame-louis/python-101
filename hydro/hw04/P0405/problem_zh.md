# 训练损失分析（综合选做）

## 题目描述

训练神经网络时，我们记录每一轮的损失值（loss）。请把若干轮损失读入一个列表，分析并输出：

1. **最低损失**（用 `min()`）。
2. **最优轮次**：最低损失第一次出现的**位置 + 1**（用 `list.index()`，下标从 0 开始）。
3. **从高到低**排列的损失（用 `sorted(reverse=True)`）。
4. 用**元组**保存「最优轮次, 最低损失」并打印（例如 `(5, 0.2)`）。

> 综合选做题，锻炼「列表统计 + 元组打包」在真实 AI 训练日志分析里的应用。可结合 `input()`、`split()`、`map()` 一次性把一整行损失变成浮点列表，全程可不用循环。

## 输入格式

**一行**若干个损失值（一位小数的浮点数），用空格分隔。程序须先显示提示语再读取：

```
请输入各轮损失（空格分隔）：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。提示语必须与上面**完全一致**（含全角冒号），程序在读取后用一行 `print()` 换行，再输出结果。

## 输出格式

读取并换行后，共 4 行：

```
最低损失： 0.2
最优轮次： 5
从高到低： 1.2 0.8 0.6 0.3 0.2
最优记录（轮次, 损失）： (5, 0.2)
```

- 损失按 Python 打印普通浮点即可（如 `0.2`、`1.2`）；从高到低用空格分隔、在同一行。
- 元组直接用 `print(元组)` 打印（如 `(5, 0.2)`）。

## 样例 #1

```input1
1.2 0.8 0.6 0.3 0.2
```

```output1
请输入各轮损失（空格分隔）：
最低损失： 0.2
最优轮次： 5
从高到低： 1.2 0.8 0.6 0.3 0.2
最优记录（轮次, 损失）： (5, 0.2)
```

## 提示

- 读入整行并一次转成浮点列表：`losses = list(map(float, input("请输入各轮损失（空格分隔）：").split()))`
- 最低损失：`best = min(losses)`；最优轮次：`losses.index(best) + 1`。
- 降序排列：`sorted(losses, reverse=True)`。
- 打包元组并打印：`record = (epoch, best)`，`print("最优记录（轮次, 损失）：", record)`。

## 数据范围

| 测试点 | 损失个数 |
|--------|----------|
| 1-5 | 含样例、全相同、单元素、最小值在首位且重复等边界 |
| 6-7 | $\le 300$ |
| 8-10 | $\le 10^5$ |

损失取一位小数（如 `0.1`、`25.7`），范围 $0.1 \le$ 损失 $\le 50.0$。
