# 成绩统计与中位数

## 题目描述

老师想统计班上一批学生的实验成绩。给定 $n$ 个成绩，请：

1. 把成绩存入列表并**升序排序**，输出排序后的结果。
2. 输出最高分。
3. 输出最低分。
4. 输出**中位数**：$n$ 为奇数时是正中间一个数；$n$ 为偶数时是中间两个数（用空格分隔）。

## 输入格式

第一行一个整数 $n$，表示成绩个数。

第二行 $n$ 个整数，用空格分隔，表示成绩。

## 输出格式

共四行：

- 第一行：排序后的全部成绩，用空格分隔。
- 第二行：最高分。
- 第三行：最低分。
- 第四行：中位数（偶数时为两个数，空格分隔）。

## 样例 #1

```input1
5
78 88 95 66 90
```

```output1
66 78 88 90 95
95
66
88
```

## 样例 #2

```input2
4
78 88 95 66
```

```output2
66 78 88 95
95
66
78 88
```

## 提示

- 原地排序用 `list.sort()`，返回新列表用 `sorted()`。
- 排序后中位数就是最中间的下标；偶数时要拿 `n//2-1` 和 `n//2` 两个下标。
- 最值可直接用 `max()` / `min()`。

## 数据范围

| 测试点 | $n$ |
|--------|-----|
| 1-3 | 单个或较小（含全相同、单元素边界） |
| 4-7 | $\le 1000$ |
| 8-10 | $\le 10^5$ |

成绩范围 $0 \le $ 成绩 $\le 10^6$。
