# P0401 列表的增删改查（基础）—— 题解

## 思路

按题意逐步操作列表并打印即可，全程只用到**本讲之前学过的列表操作**，不需要循环与分支：

1. 索引访问与长度：`scores[0]`、`scores[-1]`、`len(scores)`。
2. 修改元素 `scores[1] = 99`，追加 `scores.append(100)`。
3. 插入 `scores.insert(0, 50)`，删除 `scores.remove(95)`。

## 参考代码

```python
scores = [78, 88, 95, 66]
print(scores[0], scores[-1], len(scores))

scores[1] = 99
scores.append(100)
print(scores)

scores.insert(0, 50)
scores.remove(95)
print(scores)
```

## 输出

```
78 66 4
[78, 99, 95, 66, 100]
[50, 78, 99, 66, 100]
```

## 注意

- `print(列表)` 按 `[78, 99, 95, 66, 100]` 形式打印，元素间有一个空格。
- `insert(0, 50)` 在位置 0 插到开头；`remove(95)` 删除**第一个** 95。
