# 列表的增删改查（基础）

## 题目描述

小 A 维护一份实验成绩列表，请按下面**给定步骤**操作名单： `[78, 88, 95, 66]`，并用 `print` 依次打印，理解列表的**增、删、改、查**。

请在程序中依次完成：

1. 打印**第一个元素、最后一个元素、列表长度**（一行，用空格分隔）。
2. 把**第 2 个元素改成 `99`**；用 `append` 在末尾追加 `100`；打印此时的列表。
3. 用 `insert` 在开头插入 `50`；用 `remove` 删除 `95`；打印最终列表。

> 本题是基础理解题，**无输入**，输出是固定的。请按步骤操作，不要使用 `if`/`for`（本讲尚未学习）。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

共三行：

- 第一行：第一个元素、最后一个元素、列表长度（空格分隔）。
- 第二行：第 2 个元素改为 99 并追加 100 之后的列表。
- 第三行：继续在开头插入 50、删除 95 之后的最终列表。

## 样例 #1

```input1
（本题无输入）
```

```output1
78 66 4
[78, 99, 95, 66, 100]
[50, 78, 99, 66, 100]
```

## 提示

- 用到的操作：`scores[0]` / `scores[-1]` / `len(scores)`；修改 `scores[i] = v`；`append` / `insert` / `remove`。
- `print(列表)` 会按 Python 惯例打印，如 `[78, 99, 95, 66, 100]`，注意元素间有一个空格。
- 回忆：下标从 0 开始，`len()` 是元素个数。

## 数据范围

无输入，使用题目给出的固定数据即可。
