# 分数表增删改查

## 题目描述

小 A 手头有一份学生的实验成绩列表，需要动态维护它。请按给定的操作序列，对一个整数列表依次执行三种操作，并在最后输出：

- **append x**：在列表末尾追加一个元素 `x`
- **insert i x**：在位置 `i`（下标从 0 开始）之前插入元素 `x`
- **remove x**：删除列表中第一个值为 `x` 的元素（题目保证该值必然存在）

操作全部完成后，输出最终的列表，以及列表中的最大值和最小值。

## 输入格式

第一行一个整数 $n$，表示初始分数的个数。

第二行 $n$ 个整数，用空格分隔，表示初始分数列表。

第三行一个整数 $k$，表示操作次数。

接下来 $k$ 行，每行描述一个操作，格式如：`append x`、`insert i x` 或 `remove x`。

## 输出格式

共三行：

- 第一行：操作完成后列表的所有元素，用空格分隔。
- 第二行：列表中的最大值。
- 第三行：列表中的最小值。

## 样例 #1

```input1
4
78 88 95 66
3
append 100
insert 1 99
remove 95
```

```output1
78 99 88 66 100
100
66
```

## 提示

- 例：`append` 在末尾追加，`insert` 插入到指定位置，`remove` 按值删除第一个匹配项。
- 建议熟练使用 `list.append()`、`list.insert(i, x)`、`list.remove(x)`。
- 用内置 `max()` / `min()` 求最值最简洁。

## 数据范围

| 测试点 | $n$ | $k$ |
|--------|-----|-----|
| 1（样例） | 4 | 3 |
| 2-3 | $\le 10$ | $\le 8$ |
| 4-6 | $\le 200$ | $\le 150$ |
| 7-10 | $\le 10^5$ | $\le 5\times 10^4$ |

分数与元素值范围均为 $0 \le x \le 1000$（样例除外）。保证 `insert` 的位置 $0 \le i \le$ 当前列表长度，`remove` 的目标值必然存在于当前列表。
