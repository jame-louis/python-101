# P0402 三种插入方法的区别（基础）—— 题解

## 思路

四组操作分别打印，直观对比 `append` / `extend` / `insert`。重点是第 2 组与第 4 组的差别：`extend` 把元素**展开**，`append` 把传入对象**整体**当作一个元素追加。

## 参考代码

```python
lst = [1, 2, 3]
lst.append(4)
print(lst)

lst2 = [1, 2, 3]
lst2.extend([4, 5])
print(lst2)

lst3 = [1, 2, 3]
lst3.insert(1, 99)
print(lst3)

lst5 = [1, 2, 3]
lst5.append([4, 5])
print(lst5)
```

## 输出

```
[1, 2, 3, 4]
[1, 2, 3, 4, 5]
[1, 99, 2, 3]
[1, 2, 3, [4, 5]]
```

## 小结（本讲难点）

| 方法 | 作用 | 结果示意 |
|------|------|----------|
| `append(x)` | 追加**单个**元素 | `[1,2,3,4]` |
| `extend(it)` | **展开**拼接多个 | `[1,2,3,4,5]` |
| `insert(i,x)` | 在**位置 i** 前插入 | `[1,99,2,3]` |
| `append([..])` | 把列表**整体**追加 | `[1,2,3,[4,5]]`（易错） |
