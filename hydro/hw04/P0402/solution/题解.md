# P0402 三种插入方法 —— 题解

## 思路

此题专门考察 `append` / `extend` / `insert` 三者区别：

- `append(x)`：把 `x` 作为**一个元素**追加。
- `extend(it)`：把可迭代对象 `it` 中的元素**逐个展开**追加。
- `insert(i, x)`：把 `x` 插到下标 `i` 之前。

`extend` 后跟多个数时，用 `map(int, parts[1:])` 或生成器展开逐个加入。

## 参考代码

```python
lst = [int(x) for x in input().split()]
k = int(input())
for _ in range(k):
    parts = input().split()
    op = parts[0]
    if op == 'append':
        lst.append(int(parts[1]))
    elif op == 'extend':
        lst.extend(int(x) for x in parts[1:])
    elif op == 'insert':
        lst.insert(int(parts[1]), int(parts[2]))
print(' '.join(map(str, lst)))
```

## 对比

- `lst.append([4,5])` → `[..., [4,5]]`（列表被当作一个元素）
- `lst.extend([4,5])` → `[..., 4, 5]`（被展开）
- `lst.insert(1, 99)` → 在第二个位置插入 `99`

## 复杂度

`append`/`extend` 均摊 $O(1)$；`insert` 最坏 $O(n)$。
