# 三种插入方法

## 题目描述

列表有三种常用的"加入元素"方法，它们的差别常常让初学者混淆：

- **append x**：把单个元素 `x` 追加到列表末尾。
- **extend a b c ...**：把后面给出的一个或多个元素逐个展开、依次追加到末尾（相当于把多个元素批量拼上去）。
- **insert i x**：把元素 `x` 插入到位置 `i`（下标从 0 开始）之前。

给定一个初始整数列表，按顺序执行若干条命令，输出最终列表。

## 输入格式

第一行若干个整数，用空格分隔，表示初始列表（元素个数小于 $10^5$）。

第二行一个整数 $k$，表示命令条数。

接下来 $k$ 行，每行一条命令：

- `append x`：末尾追加单个元素 `x`
- `extend a b c ...`：把后面的元素逐个追加到末尾
- `insert i x`：在下标 `i` 处插入元素 `x`

## 输出格式

一行，最终列表的所有元素，用空格分隔。

## 样例 #1

```input1
1 2 3
4
append 4
append 5
insert 1 99
extend 7 8
```

```output1
1 99 2 3 4 5 7 8
```

## 提示

- 对比思考：`lst.append([4,5])` 会把整个 `[4,5]` **作为一个元素**追加（得到 `[..., [4,5]]`），而 `lst.extend([4,5])` 才把它展开逐个加入。本题里的 `extend a b c ...` 就对应后者。
- 请使用 `list.append()`、`list.extend()`、`list.insert(i, x)`。

## 数据范围

| 测试点 | 初始元素 | 命令数 $k$ | 单次 extend 个数 |
|--------|----------|------------|------------------|
| 1-3 | $\le 12$ | $\le 12$ | $\le 5$ |
| 4-7 | $\le 200$ | $\le 300$ | $\le 5$ |
| 8-10 | $\le 10^5$ | $\le 5\times 10^4$ | $\le 5$ |

元素值范围 $0 \le x \le 1000$。保证 `insert` 的位置 $0 \le i \le$ 当前列表长度。
