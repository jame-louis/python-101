# 三种插入方法的区别（基础）

## 题目描述

列表有三种「加入元素」的方法，初学者常把它们搞混：

- **append(x)**：把 `x` 作为**一个元素**追加到末尾。
- **extend(it)**：把可迭代对象 `it` 中的元素**逐个展开**拼接进末尾。
- **insert(i, x)**：把 `x` 插入到**位置 i（下标从 0 开始）**之前。

请在程序中完成下面 4 组操作，并**逐行打印**每一步结果，直观感受三者的差别（包括一个容易犯的错）：

1. `lst = [1, 2, 3]`，`lst.append(4)`，打印 `lst`。
2. `lst2 = [1, 2, 3]`，`lst2.extend([4, 5])`，打印 `lst2`。
3. `lst3 = [1, 2, 3]`，`lst3.insert(1, 99)`，打印 `lst3`。
4. `lst5 = [1, 2, 3]`，`lst5.append([4, 5])`，打印 `lst5`（想一想和 `extend` 的区别）。

> 本题是基础理解题，**无输入**，输出固定。不要求使用 `if`/`for`。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

共四行，每行对应上面一组操作的打印结果。

## 样例 #1

```input1
（本题无输入）
```

```output1
[1, 2, 3, 4]
[1, 2, 3, 4, 5]
[1, 99, 2, 3]
[1, 2, 3, [4, 5]]
```

## 提示

- 对比第 2 组与第 4 组：`extend([4,5])` 得到 `[..., 4, 5]`，而 `append([4,5])` 得到 `[..., [4,5]]`——列表被**整体**当作一个元素追加进去了。
- 用 `print(列表)` 直接打印即可。
