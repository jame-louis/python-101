# hw04 —— 列表与元组（Hydro 题目集）

对应课程第 4 讲实验任务卡 `src/assignments/hw04.md`，共 **5 道 Python 传统题**，每题一个自包含
Hydro 题目包（`problem.yaml` + `problem_zh.md` + `testdata/` + `std/` + `solution/`）。

## 知识点约束（关键）

本套题严格贴合**当前学生已学内容**：尚未学习分支（`if`）与循环（`for`/`while`）。
因此**所有标准做法都不用循环、不用分支**，只用已学的列表/元组/字符串操作与内建函数：

- 基础题无输入，输出固定，靠下标的「一步式」操作完成。
- 综合题用 `input()` + `input().split()` + `map()` **一整行**读入（第 3 讲「一次输入多个数」的做法），
  再用 `sorted` / `min` / `max` / `sum` / `len` / `list.index` / 切片等完成，无 `if`/`for`。

## 题目一览

| PID | 题目 | 类型 | 考点 | 处理方式 |
|-----|------|------|------|----------|
| P0401 | 列表的增删改查（基础） | 无输入 | 索引/负下标/`len`、改、`append`/`insert`/`remove` | 固定输出 |
| P0402 | 三种插入方法的区别（基础） | 无输入 | `append` vs `extend` vs `insert`（含 `append([..])` 易错点） | 固定输出 |
| P0403 | 元组的创建与解包（基础） | 无输入 | 元组下标、解包、单元素元组 | 固定输出 |
| P0404 | 成绩统计（综合选做） | 输入+提示 | 排序/最值/总分/平均/中位数 | 严格逐字匹配 |
| P0405 | 训练损失分析（综合选做） | 输入+提示 | `min`/`index`/降序/元组打包（AI 场景） | 严格逐字匹配 |

## 输入与严格匹配说明

- **P0401–P0403（基础）**：无输入，`.in` 放占位 `no-input`；每套 5 个相同测试点。
- **P0404–P0405（综合选做）**：有输入。按课程习惯带提示语读取，评测为**严格逐字匹配**：
  标程同样用 `input("固定提示：")` 输出提示语并换行，学生必须复现**完全一致**的提示语与输出格式
  （题面已在「提示」中明确标注）。每套 10 个测试点。

## 目录约定

```
P04xx/
├── problem.yaml          # 标题、标签、PID、难度
├── problem_zh.md         # 中文题面
├── testdata/
│   ├── config.yaml       # 时限/内存 + 测试点
│   ├── 1..N.in           # 输入（1 号即样例；P0401-03 为 5 个，P0404-05 为 10 个）
│   └── 1..N.out          # 标准输出（由标程生成）
├── std/std.py.py3        # Python 标程
├── gen.py                # 数据生成器（固定种子、可复现）
└── solution/题解.md       # 思路 + 参考代码
```

## 使用

生成/重放数据（每个题目包内）：

```bash
cd P0404
for i in $(seq 1 10); do python3 gen.py $i > testdata/$i.in; done
for i in $(seq 1 10); do python3 std/std.py.py3 < testdata/$i.in > testdata/$i.out; done
```

校验全部题目（校验会按各题 `config.yaml` 的测试点数逐一回归标程）：

```bash
python3 hydro/hw04/validate.py
```

## 说明

- Hydro 评测为**传统题**，语言放开 Python 即可；`std` 后缀 `std.py.py3` 与 Hydro 的 Python3 语言键一致。
- 基础题为固定输出，方便学生自查对列表/元组操作的掌握；综合题覆盖样例、偶数个、全相同、单元素、
  大量重复、最小值在首位等边界，并保留大数据（$10^5$）测试点。
