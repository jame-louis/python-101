# 元组的创建与解包（基础）

## 题目描述

元组（tuple）与列表的最大区别是**不可变**。请按下列步骤完成元组的创建、下标访问与**解包**，并逐行打印：

1. 创建 `t = (10, 20, 30)`，打印 `t[0]`、`t[-1]`、`len(t)`（一行，空格分隔）。
2. 用 `a, b, c = t` **解包**，打印 `a b c`。
3. 创建坐标对 `point = (3, 5)`，用 `x, y = point` 解包，打印 `(x, y)` 和 `x + y`（一行，空格分隔）。
4. 创建一个**单元素**元组 `t2 = (7,)`，打印 `t2` 和 `len(t2)`（一行，空格分隔）。

> 本题是基础理解题，**无输入**，输出固定。不要求使用 `if`/`for`。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

共四行，每行对应一组操作的打印结果。

## 样例 #1

```input1
（本题无输入）
```

```output1
10 30 3
10 20 30
(3, 5) 8
(7,) 1
```

## 提示

- **解包**：`a, b, c = t` 一次性把元组三个元素分别赋给三个变量。
- 单元素元组一定要写逗号：`(7,)`，否则 `(7)` 只是整数 7 外面加个括号。
- `print((3, 5))` 会显示 `(3, 5)`；`print((7,))` 会显示 `(7,)`。
- 可以试试 `t[0] = 99`，会报错 `TypeError`——这就是元组「不可变」。

## 数据范围

无输入，使用题目给出的固定数据即可。
