# 元组解包与坐标统计

## 题目描述

平面直角坐标系上有 $m$ 个点，每个点用一个坐标对 $(x, y)$ 表示。请把每个点以元组形式存入列表，遍历列表并用**元组解包**取出每个点的横、纵坐标：

1. 对每个点，输出一行 `x + y = 和`（和可能为负数）。
2. 最后输出所有点横坐标之和 `sum_x = ...`，以及所有点纵坐标之和 `sum_y = ...`。

## 输入格式

第一行一个整数 $m$，表示点的个数。

接下来 $m$ 行，每行两个整数 $x$ 和 $y$，用一个空格分隔。

## 输出格式

- 前 $m$ 行：每行一个 `x + y = 和`。
- 第 $m+1$ 行：`sum_x = 横坐标之和`
- 第 $m+2$ 行：`sum_y = 纵坐标之和`

## 样例 #1

```input1
3
3 5
1 2
10 20
```

```output1
3 + 5 = 8
1 + 2 = 3
10 + 20 = 30
sum_x = 14
sum_y = 27
```

## 提示

- 元组用圆括号 `()` 创建，如 `point = (3, 5)`。
- 解包：`x, y = point` 可以一次性把元组的两个元素分别赋给 `x` 和 `y`。
- 可先把点存入 `points` 元组列表，再用 `for point in points:` 遍历并按需解包。

## 数据范围

| 测试点 | $m$ |
|--------|-----|
| 1-3 | $\le 10$ |
| 4-7 | $\le 1000$ |
| 8-10 | $\le 10^5$ |

坐标范围 $0 \le x, y \le 10^9$（测试点 4 及以后允许负数 $-10^9 \le x, y \le 10^9$）。坐标之和对 64 位整数可表示，Python 整数无需担心溢出。
