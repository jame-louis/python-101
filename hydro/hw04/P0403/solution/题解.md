# P0403 元组解包与坐标统计 —— 题解

## 思路

元组适合保存一组固定的、互相关联的值。本题每一步都在练习元组与解包：

1. 读入时 `x, y = map(int, input().split())`，把 `(x, y)` 存入 `points` 列表。
2. 遍历时用 `for point in points:`，再 `x, y = point` 解包取出横纵坐标。
3. 边累加、边输出每点之和。

## 参考代码

```python
m = int(input())
points = []
for _ in range(m):
    x, y = map(int, input().split())
    points.append((x, y))

sum_x = 0
sum_y = 0
for point in points:
    x, y = point                  # 元组解包
    sum_x += x
    sum_y += y
    print(f"{x} + {y} = {x + y}")
print(f"sum_x = {sum_x}")
print(f"sum_y = {sum_y}")
```

## 注意

- 单元素元组要写 `(5,)`；有多个元素时逗号是关键。解包变量个数需与元组长度一致。
- 坐标可能为负，输出 `x + y = 和` 时负号自然保留。

## 复杂度

$O(m)$。
