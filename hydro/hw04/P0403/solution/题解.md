# P0403 元组的创建与解包（基础）—— 题解

## 思路

练习元组的建立、下标访问与**解包**，并注意单元素元组必须带逗号。

## 参考代码

```python
t = (10, 20, 30)
print(t[0], t[-1], len(t))

a, b, c = t
print(a, b, c)

point = (3, 5)
x, y = point
print(f"({x}, {y})", x + y)

t2 = (7,)
print(t2, len(t2))
```

## 输出

```
10 30 3
10 20 30
(3, 5) 8
(7,) 1
```

## 注意

- 解包要求变量个数与元组长度一致。
- 单元素元组写 `(7,)`；`(7)` 只是整数。`print((7,))` 显示 `(7,)`。
- 元组**不可变**：`t[0] = 99` 会报 `TypeError`。适合保存不打算被修改的数据，如坐标对。
