# P0504 NLP 词频统计（综合·输入+提示）

## 思路

用字典把"单词 → 次数"存起来。核心一行：

```python
freq[w] = freq.get(w, 0) + 1
```

- `freq.get(w, 0)`：键存在返回次数，不存在返回 0（不抛 `KeyError`）。
- `+1` 后重新赋值给 `freq[w]`，完成累加。

输出前用 `sorted(freq)` 按键排序，保证字典无序下的确定性输出。这是 NLP 词频统计最经典的写法。

## 参考代码

```python
words = input("请输入一串英文单词（空格分隔）：").split()
freq = {}
for w in words:
    freq[w] = freq.get(w, 0) + 1
print()

for w in sorted(freq):
    print(w, freq[w])
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1 | 样例（含重复） |
| 2 | 单元素 |
| 3 | 全相同（词频集中在同一单词） |
| 4 | 全不重复（每个词 1 次） |
| 5-6 | 小数据随机 |
| 7-8 | 中数据随机覆盖多个词 |
| 9-10 | 大数据（≤10⁴）验证性能 |

## 常见错误

- 用 `freq[w] = freq[w] + 1` 直接改 → 首次出现 `KeyError`。应改用 `get`。
- 不排序直接遍历字典 → 顺序不定被判错。一定要 `sorted(freq)`。
- 提示语写错（漏全角冒号、多空格）→ 逐字匹配不过。
- 一行 `print()` 换行遗漏 → 输出与样例不一致。
