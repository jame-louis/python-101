# NLP 词频统计（综合选做）

## 题目描述

给定一串英文单词，请你统计每个单词**出现的次数**（词频），并按键排序输出。

- 用字典 `freq = {}` 存储"单词 → 次数"的映射。
- 每次遇到单词 `w`，用 `freq[w] = freq.get(w, 0) + 1` 累加：`get(w, 0)` 保证首次出现从 0 开始、不报 `KeyError`。
- 这是 NLP（自然语言处理）里**词频统计**的基础做法。

> 综合选做题，需要用到一个**极简 `for` 循环**遍历单词列表（循环将在后续课程系统学习，此处先会用即可）。

## 输入格式

**一行**若干个英文单词，用空格分隔。程序须先显示提示语再读取：

```
请输入一串英文单词（空格分隔）：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。提示语必须与上面**完全一致**（含全角冒号），程序在读取后用一行 `print()` 换行，再输出词频。

## 输出格式

读取并换行后，**每个不同的单词一行**，按**字母序**（字典序）排序，格式为 `单词 次数`：

```
请输入一串英文单词（空格分隔）：
apple 2
banana 1
the 3
```

## 样例 #1

```input1
the apple the banana the apple
```

```output1
请输入一串英文单词（空格分隔）：
apple 2
banana 1
the 3
```

## 样例 #2

```input2
cat
```

```output2
请输入一串英文单词（空格分隔）：
cat 1
```

## 提示

- 读入：`words = input("请输入一串英文单词（空格分隔）：").split()` 得到单词列表。
- 统计：`freq = {}` 循环里 `freq[w] = freq.get(w, 0) + 1`。
- 排序输出：`for w in sorted(freq): print(w, freq[w])`。
- 保证输出顺序确定：**必须按键排序**，因为字典内部无序。

## 数据范围

| 测试点 | 单词个数 |
|--------|----------|
| 1-4 | 含样例、单元素、全相同、全不重复等边界 |
| 6-7 | $\le 100$ |
| 8-10 | $\le 10^4$ |

每个单词由小写字母组成，长度 $\le 20$。
