# 集合去重清洗（基础）

## 题目描述

小 A 手里有一段"用户点击日志"，里面有很多重复项：

```
raw = ["手机", "手机", "耳机", "平板", "耳机", "手机"]
```

请用**集合（set）**把它去重清洗，并输出两行固定结果：

1. 集合化之后唯一种类的**数量**。
2. 用 `sorted()` 排好序的**唯一物品列表**。

> 集合天然不保存重复元素，一行 `set(raw)` 即可完成去重。**本题无输入**，输出固定。
> 注意：不要直接打印 `set(raw)`——集合**无序**，输出顺序不确定，请用 `sorted(set(raw))` 保证结果是确定的。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

共两行：

- 第一行：`去重后数量： 3`
- 第二行：`排序后的唯一物品列表： ['平板', '手机', '耳机']`

## 样例 #1

```input1
（本题无输入）
```

```output1
去重后数量： 3
排序后的唯一物品列表： ['平板', '手机', '耳机']
```

## 提示

- 用到的操作：`set(列表)` 转成集合自动去重；`len(集合)` 取元素个数；`sorted(集合)` 得到排序后的唯一列表。
- `print("前缀：", 表达式)` 中间会输出**空格**，请保持输出格式与样例一致。
- 回忆：集合元素不可重复、无序，所以打印结果要 `sorted()` 稳定化。

## 数据范围

无输入，使用题目给出的固定数据即可。
