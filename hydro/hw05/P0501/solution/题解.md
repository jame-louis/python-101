# P0501 集合去重清洗（基础·无输入）

## 思路

集合（set）**天生不允许重复元素**，把一个含重复项的列表 `set()` 化就能自动去重。
但集合**无序**，直接打印集合顺序不确定，因此用 `sorted()` 得到确定的排序结果。

本题无输入，只需对题目给定的 `raw` 列表完成"去重 → 计数 → 排序"三步。

## 参考代码

```python
raw = ["手机", "手机", "耳机", "平板", "耳机", "手机"]

s = set(raw)          # 列表 → 集合，去重
print("去重后数量：", len(s))
print("排序后的唯一物品列表：", sorted(s))
```

## 常见错误

- 直接 `print(set(raw))` → 集合无序，输出顺序不定，被判错。应加 `sorted()`。
- 混淆 `{}` 与 `set()`：`{}` 是**空字典**，不是空集合；本题不涉及。
- 元素用列表会报 `unhashable`（不可哈希），但本题用了字符串，无忧。
