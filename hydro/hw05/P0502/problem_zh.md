# 集合的交、并、差（基础）

## 题目描述

两位用户的兴趣标签分别存在两个集合里：

```
userA = {"电子", "游戏", "运动"}
userB = {"运动", "摄影", "电子"}
```

请用集合运算符找出三组结果并输出：

1. **共同兴趣**（交集 `&`）。
2. **全部兴趣**（并集 `|`）。
3. **用户 A 独有**（差集 `-`）。

每组都打印**排序后的列表**（`sorted(...)`）、**个数**。

> 集合**无序**，直接打印集合顺序不定，请一律用 `sorted(...)` 稳定输出。**本题无输入**，输出固定。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

共三行，每行末尾是 `，共 N 个`：

```
共同兴趣： ['电子', '运动'] ，共 2 个
全部兴趣： ['摄影', '游戏', '电子', '运动'] ，共 4 个
用户A独有： ['游戏'] ，共 1 个
```

## 提示

- 运算符：`A & B` 交集、`A | B` 并集、`A - B` 差集；都有对应方法 `intersection()` / `union()` / `difference()`。
- `sorted(集合)` 返回排序后的列表，保证输出顺序确定。
- `len(集合)` 取元素个数。
- 思考：这里 `&` 为什么不属于 `|`？——交集只含两集合**共有**元素，并集则把两集合**所有**元素合并，通常更大。
