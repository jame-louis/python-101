# hw05 —— 集合与字典（Hydro 题目集）

对应课程第 5 讲实验任务卡 `src/assignments/hw05.md`，共 **5 道 Python 传统题**，每题一个自包含
Hydro 题目包（`problem.yaml` + `problem_zh.md` + `testdata/` + `std/` + `solution/`）。

## 知识点约束（关键）

本套题贴合**当前学生已学内容**：本节学习集合与字典，尚未系统学习分支（`if`）与循环（`while`）。
因此：

- **基础题（P0501–P0503）无输入，输出固定**，只靠集合运算符与字典增删改查的"一步式"操作完成，
  **完全不用 `if`/`for`**。
- **综合题（P0504–P0505）有输入 + 带提示语**：P0504 词频统计用到一个**极简 `for` 循环**（进阶知识点，
  在后续"循环"讲系统学习，此处先会用）；P0505 配置映射表**无循环**，仅用字典键读取 + `get` 安全取值。

> ⚠️ 输出稳定化：集合/字典内部**无序**，所有涉及打印集合/字典遍历的地方**必须 `sorted()`** 后再输出，
> 否则顺序不定会被判错。本题集严格遵循这一点。

## 题目一览

| PID | 题目 | 类型 | 考点 | 处理方式 |
|-----|------|------|------|----------|
| P0501 | 集合去重清洗（基础） | 无输入 | `set()` 去重、`len`、`sorted` 稳定化 | 固定输出 |
| P0502 | 集合的交、并、差（基础） | 无输入 | `&`/`\|`/`-` 与 `len` | 固定输出 |
| P0503 | 字典的增删改查（基础） | 无输入 | 键查改增、`keys/values/items`、`get` 默认值 | 固定输出 |
| P0504 | NLP 词频统计（综合选做） | 输入+提示 | `freq[w]=freq.get(w,0)+1`、极简 `for`、按 key 排序 | 严格逐字匹配 |
| P0505 | AI 模型配置参数映射表（综合选做） | 输入+提示 | 字典构造、键名读取、类型转换、`get("scheduler","未配置")` | 严格逐字匹配 |

## 输入与严格匹配说明

- **P0501–P0503（基础）**：无输入，`.in` 放占位 `no-input`；每套 5 个相同测试点。
- **P0504–P0505（综合选做）**：有输入。按课程习惯带提示语读取，评测为**严格逐字匹配**：
  标程同样用 `input("固定提示：")` 输出提示语并换行，学生必须复现**完全一致**的提示语与输出格式
  （题面已在「提示」中明确标注）。每套 10 个测试点。

## 目录约定

```
P05xx/
├── problem.yaml          # 标题、标签、PID、难度
├── problem_zh.md         # 中文题面
├── testdata/
│   ├── config.yaml       # 时限/内存 + 测试点
│   ├── 1..N.in           # 输入（1 号即样例；P0501-03 为 5 个，P0504-05 为 10 个）
│   └── 1..N.out          # 标准输出（由标程生成）
├── std/std.py.py3        # Python 标程
├── gen.py                # 数据生成器（固定种子、可复现）
└── solution/题解.md       # 思路 + 参考代码
```

## 使用

生成/重放数据（每个题目包内）：

```bash
cd P0504
for i in $(seq 1 10); do python3 gen.py $i > testdata/$i.in; done
for i in $(seq 1 10); do python3 std/std.py.py3 < testdata/$i.in > testdata/$i.out; done
```

校验全部题目（校验会按各题 `config.yaml` 的测试点数逐一回归标程）：

```bash
python3 hydro/hw05/validate.py
```

## 说明

- Hydro 评测为**传统题**，语言放开 Python 即可；`std` 后缀 `std.py.py3` 与 Hydro 的 Python3 语言键一致。
- 基础题为固定输出，方便学生自查对集合/字典操作的掌握；综合题覆盖样例、单元素、全相同、全不重复、
  边界值（轮数 1、学习率 1.0）等边界，并保留大数据（词频 ≤10⁴）测试点。
- P0504、P0505 恰好对应 hw05 任务卡的两个进阶任务（🔴 NLP 词频统计、🔴 AI 模型配置映射表），
  与基础题一起完整覆盖了"去重清洗、词频统计、AI 配置"三条主线场景。
