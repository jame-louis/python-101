# AI 模型配置参数映射表（综合选做）

## 题目描述

深度学习训练常常把超参数放在一个**字典**里，用**键名**（语义化名称）读取配置，比用带下标的列表清晰、可扩展。请把用户输入的 4 个配置项存入字典并按要求输出。

- 从一行输入读取四项：`学习率、训练轮数、优化器、设备`。
- 构造字典 `config`，键为 `learning_rate`(小数)、`epochs`(整数)、`optimizer`(字符串)、`device`(字符串)。
- 按键名输出 `learning_rate`、`epochs`、`optimizer`、`device`；再用 `get` 安全读取不存在的键 `scheduler`，返回默认值 `"未配置"`。

> 综合选做题，用 `input().split()` 一次读入多个值，再对第 1、2 项做 `float()` / `int()` 转换。

## 输入格式

**一行**四个值，空格分隔，依次为：学习率（小数）、训练轮数（整数）、优化器（英文小写）、设备（英文小写）。程序须先显示提示语再读取：

```
请输入 学习率 轮数 优化器 设备（空格分隔）：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。提示语必须与上面**完全一致**（含全角冒号），程序在读取后用一行 `print()` 换行，再输出结果。

## 输出格式

读取并换行后，共 5 行：

```
学习率： 0.01
轮数： 50
优化器： adam
设备： cuda
调度器： 未配置
```

- `学习率`、`轮数`、`优化器`、`设备` 用**键名**从字典读取。
- `调度器` 用 `config.get("scheduler", "未配置")` 读取不存在的键，返回默认值 `未配置`。
- 学习率按 Python 浮点默认显示（如 `0.01`、`0.001`），不要手动格式化成固定位数。

## 提示

- 读入：`lr, epochs, opt, dev = input("请输入 学习率 轮数 优化器 设备（空格分隔）：").split()`。
- 字典：`config = {"learning_rate": float(lr), "epochs": int(epochs), "optimizer": opt, "device": dev}`。
- 读取：`config["optimizer"]`；安全读取缺键用 `config.get("scheduler", "未配置")`。
- 思考：用字典存配置相比列表，好处是按**名称**取、顺序无关、键语义化、易扩展。

## 数据范围

| 测试点 | 说明 |
|--------|------|
| 1-4 | 样例、学习率含前导 0、不同优化器/设备 |
| 5-10 | 随机学习率 $10^{-4}..1$、轮数 $1..10^3$、优化器与设备的取值组合 |

优化器 ∈ {adam, sgd, rmsprop, adagrad}；设备 ∈ {cpu, cuda, mps}；均为小写英文、不含空格。
