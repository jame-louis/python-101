# P0505 AI 模型配置参数映射表（综合·输入+提示）

## 思路

这是字典最典型的工程用法：**"名称 → 数值"的映射表**。把一行输入拆成四个值，用 `float()/int()` 做类型转换后放进字典，再用**键名**读取配置，比用带下标的列表可读性高、易扩展。`scheduler` 键并不存在，用 `get` 给默认值 `"未配置"` 即安全取值。

## 参考代码

```python
lr, epochs, opt, dev = input("请输入 学习率 轮数 优化器 设备（空格分隔）：").split()
config = {
    "learning_rate": float(lr),
    "epochs": int(epochs),
    "optimizer": opt,
    "device": dev,
}
print()

print("学习率：", config["learning_rate"])
print("轮数：", config["epochs"])
print("优化器：", config["optimizer"])
print("设备：", config["device"])
print("调度器：", config.get("scheduler", "未配置"))
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1 | 样例（学习率 0.01） |
| 2 | 样例2（小学习率 0.0001、cpu） |
| 3 | 边界：轮数 1 |
| 4 | 边界：学习率 1.0 |
| 5-10 | 随机组合，覆盖 4 种优化器 × 3 种设备 |

## 常见错误

- 整行 `split()` 得到的是字符串，若不对 `learning_rate`/`epochs` 做 `float()/int()` 转换，后续输出会是字符串（或报类型错误）。
- 直接 `config["scheduler"]` 取值 → 键不存在抛 `KeyError`，应改用 `get` 并给默认值。
- 提示语写错（漏全角冒号、多空格）→ 逐字匹配不过。
- 把 `optimizer`/`device` 误用 `int()` → 报 `ValueError`，它们是字符串，无需转换。
