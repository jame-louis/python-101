# P0503 字典的增删改查（基础·无输入）

## 思路

字典以"键→值"存储。本题演示它的完整生命周期：

- **查**：`d["name"]` 用键取值。
- **改**：`d["age"] = 21`（键已存在则覆盖）。
- **增**：`d["city"] = "Xiamen"`（键不存在则新增）。
- **遍历**：`keys()` / `values()` / `items()` 三个视图，用 `list()` 转成列表打印。
- **安全取值**：`get(key, 默认)` 找不到返回默认值，不抛 `KeyError`。

字典在 Python 中保持插入顺序，所以输出是确定的。

## 参考代码

```python
user = {"name": "Alice", "age": 20}

print(user["name"])          # 查
user["age"] = 21             # 改
user["city"] = "Xiamen"      # 增
print(user)

print(list(user.keys()))
print(list(user.values()))
print(list(user.items()))
print(user.get("email", "无邮箱"))   # 安全取值（不存在 → 默认值）
```

## 常见错误

- 用 `d["email"]` 直接取值 → 键不存在抛 `KeyError`，应改用 `get` 并给默认值。
- 把 `dict` 当集合 / 把 `set()` 当空字典混淆：`{}` 是空字典。
- 以为字典有序/无序判断错误：Python 3.7+ 字典保持**插入顺序**，这是确定性的。
- 用列表当键 → `unhashable` 报错；本题用字符串键。
