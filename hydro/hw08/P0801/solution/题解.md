# P0801 圆的面积函数（基础·无输入）

## 思路

定义一个返回圆面积的函数，把半径传进去，返回 `3.14159*r*r`。黑盒子的思想：定义一次、调用多次，每次只换输入。

## 参考代码

```python
PI = 3.14159

def area(r):
    return PI * r * r

print(area(2))   # 12.56636
print(area(5))   # 78.53975
print(area(10))  # 314.159
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1-5 | 全部相同（无输入、固定输出） |

## 常见错误

- 函数体里用 `print` 而非 `return` → 调用后拿到 None，无法再参与计算。
- 忘写冒号 `:` 或缩进 → `SyntaxError` / `IndentationError`。
- 半径算错（如 `r*r` 写成 `2*r`）→ 面积不对。
