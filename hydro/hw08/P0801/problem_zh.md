# 圆的面积函数（基础）

## 题目描述

定义一个函数 `area(r)`，用公式 `3.14159 * r * r` 计算**圆的面积**并 `return` 返回，然后**调用三次**——`area(2)`、`area(5)`、`area(10)`——各打印一行固定结果。

> 函数是"黑盒子"：定义一次，调用三次，每次只需换一个半径。这就是封装复用。
> **本题无输入**，输出固定。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

共三行：

```
12.56636
78.53975
314.159
```

## 样例 #1

```input1
（本题无输入）
```

```output1
12.56636
78.53975
314.159
```

## 提示

- 定义：`def area(r): return 3.14159 * r * r`。
- 调用：`print(area(2))`、`print(area(5))`、`print(area(10))`。
- 核对：`area(2) = 3.14159 * 4 = 12.56636`；`area(10) = 3.14159 * 100 = 314.159`。

## 数据范围

无输入，使用题目给出的固定数据即可。
