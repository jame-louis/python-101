# hw08 —— 函数（定义与调用）（Hydro 题目集）

对应课程第 8 讲实验任务卡 `src/assignments/hw08.md`，共 **5 道 Python 传统题**，每题一个自包含
Hydro 题目包（`problem.yaml` + `problem_zh.md` + `testdata/` + `std/` + `solution/`）。

## 知识点约束

本套题贴合**当前学生已学内容**：本讲学习函数（`def`/`return`、位置/关键字/默认/`*args`/`**kwargs`
四种参数、`global` 作用域、可变 vs 不可变）。学生已具备前 7 讲的顺序/条件/循环/组合类型基础，因此题目
可使用函数 + 分支 + 循环，但**刻意聚焦函数封装**。

- **基础题（P0801–P0803）无输入，固定输出**：圆的面积函数（`def`+`return`）、默认参数、`global` 作用域。
- **综合题（P0804–P0805）有输入 + 带提示语**：圆面积计算器（函数封装 + 两位小数）、可变参数求和（`*args`）。

> ⚠️ 严格逐字匹配：P0804–P0805 提示语（含全角冒号）与输出格式必须逐字复现。

## 题目一览

| PID | 题目 | 类型 | 考点 | 处理方式 |
|-----|------|------|------|----------|
| P0801 | 圆的面积函数（基础） | 无输入 | `def`/`return`、封装复用 | 固定输出 |
| P0802 | 默认参数（基础） | 无输入 | 默认值 + 位置/关键字覆盖 | 固定输出 |
| P0803 | global 作用域（基础） | 无输入 | 局部 vs 全局、`global` 声明 | 固定输出 |
| P0804 | 圆面积计算器（综合选做） | 输入+提示 | 函数封装、`float` 读入、两位小数 | 严格逐字匹配 |
| P0805 | 可变参数求和（综合选做） | 输入+提示 | `*args`、列表解包、循环求和 | 严格逐字匹配 |

## 输入与严格匹配说明

- **P0801–P0803（基础）**：无输入，`.in` 放占位 `no-input`；每套 5 个相同测试点。
- **P0804–P0805（综合选做）**：有输入。标程以 `print(提示语)` 先输出一行提示语，再用裸 `input()`
  读入。学生必须复现**完全一致**的提示语与输出格式。每套 10 个测试点。

## 使用

校验全部题目：

```bash
python3 hydro/hw08/validate.py
```

（数据生成/重放方式同前几套：`python3 gen.py N > testdata/N.in` + `python3 std/std.py.py3 < *.in > *.out`）

## 说明

- Hydro 评测为**传统题**，语言放开 Python 即可；`std` 后缀 `std.py.py3` 与 Hydro 的 Python3 语言键一致。
- 基础题为固定输出，方便自查函数定义/默认参数/作用域；综合题覆盖样例、单数、负数/0、小数/大半径等边界，
  并保留较多随机测试点。
- P0804、P0805 恰好对应 hw08 任务卡的两个进阶任务（🔴 圆面积计算器、🔴 可变参数求和），
  与基础题一起完整覆盖了"定义调用、默认参数、作用域、可变参数、封装"五条主线。
