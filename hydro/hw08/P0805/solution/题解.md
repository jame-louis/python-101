# P0805 可变参数求和（综合·输入+提示）

## 思路

用 `*args` 让函数接受任意多个位置实参并收成一个元组，循环累加。读入时把一行整数先存成列表，调用时用 `*nums` 解包成一个个实参。

## 参考代码

```python
def sum_all(*args):
    total = 0
    for x in args:
        total += x
    return total

print("请输入若干整数（空格分隔）：")
nums = []
for x in input().split():
    nums.append(int(x))
print("和 =", sum_all(*nums))
print("共", len(nums), "个")
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1 | 样例（3 5 8 → 16, 3） |
| 2 | 单数（7） |
| 3 | 全相同 |
| 4 | 负数与 0 |
| 5-6 | 小随机 |
| 7-8 | 中随机（±10⁶） |
| 9-10 | 大随机（±10⁹，个数≤200） |

## 常见错误

- 调用时漏写 `*`（写 `sum_all(nums)`）→ 被当成一个整体参数而非解包，求和对象是列表本身。
- `*args` 又名 `*args` 后跟普通参数 → 语法不允许；可变长放在最后。
- 忘 `int()` → 字符串做加法是拼接而非求和。
- 提示语写错（漏全角冒号）→ 逐字匹配不过。
