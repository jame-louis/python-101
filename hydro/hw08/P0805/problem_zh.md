# 可变参数求和（综合选做）

## 题目描述

读入一行空格分隔的若干整数，用一个带**可变位置参数 `*args`** 的函数 `sum_all(*args)` 收集所有数并求和，然后输出**总和**与**个数**。

- 定义：`def sum_all(*args):` 把多出来的位置实参收成一个元组，循环累加求和。
- 调用时用 `sum_all(*nums)` 把列表 `nums` **解包**成一个个实参传进去。

> 综合选做题，用到 `*args` 与序号解包。

## 输入格式

**一行**若干个整数，用空格分隔。程序先显示提示语再读取：

```
请输入若干整数（空格分隔）：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。提示语必须与上面**完全一致**（含全角冒号），程序先打印提示语，再用裸 `input()` 读入整行。

## 输出格式

读取后输出两行：

```
请输入若干整数（空格分隔）：
和 = 16
共 3 个
```

## 样例 #1

```input1
3 5 8
```

```output1
请输入若干整数（空格分隔）：
和 = 16
共 3 个
```

## 样例 #2

```input2
7
```

```output2
请输入若干整数（空格分隔）：
和 = 7
共 1 个
```

## 提示

- 读入并转整数：用循环把 `input().split()` 里每个字符串 `int(...)` 后 `append` 进 `nums`。
- 定义：`def sum_all(*args):` 循环 `total += x` 后 `return total`。
- 调用：`sum_all(*nums)`（带星号 = 把列表解包成多个实参）。
- 个数：`len(nums)`。
- 输出：`print("和 =", s)`、`print("共", len(nums), "个")`。

## 数据范围

整数的个数 ≥ 1，每个数 $|x| \le 10^9$。

| 测试点 | 说明 |
|--------|------|
| 1-4 | 含样例、单数、全相同、负数和 0 |
| 5-7 | 小随机 |
| 8-10 | 大随机（个数、数值均增大） |
