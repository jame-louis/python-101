# P0803 global 作用域（基础·无输入）

## 思路

一个函数用 `global` 改全局（结果 99），另一个只做局部赋值（结果仍是 10）。两者对照，直观展示"函数体内是否声明 global"的差别。

## 参考代码

```python
g = 10

def change():
    global g
    g = 99
change()
print("全局修改后 g =", g)          # 99

g = 10
def no_change():
    g = 5                          # 局部变量
no_change()
print("局部赋值不影响全局 g =", g)   # 10
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1-5 | 全部相同（无输入、固定输出） |

## 常见错误

- 想在函数里改全局却不写 `global` → 报 `UnboundLocalError` 或只改了局部。
- 全局、局部名字混淆，分不清 `g=99` 改的是哪一份。
- 只写一个函数就把两种情况混在一起 → 对照关系讲不清。
