# global 作用域（基础）

## 题目描述

写一个用**全局变量** `g` 演示作用域的小程序，输出两行固定结果：

1. 全局变量 `g = 10`；定义一个函数，函数体里用 `global g` 声明后把 `g` 改成 `99`，调用函数并打印 `print("全局修改后 g =", g)`。
2. 重设 `g = 10`；再定义一个函数，函数体里**不写 `global`**，只赋值 `g = 5`（这是局部变量），调用后打印 `print("局部赋值不影响全局 g =", g)`。

> 作用域判定口诀：声明在函数体外 → 全局；函数体内 → 局部（除非 `global`）。
> **本题无输入**，输出固定。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

共两行：

```
全局修改后 g = 99
局部赋值不影响全局 g = 10
```

## 样例 #1

```input1
（本题无输入）
```

```output1
全局修改后 g = 99
局部赋值不影响全局 g = 10
```

## 提示

- 两个函数都要**先定义、后调用**。
- 第一个用 `global g` 再改 → 全局变成 99。
- 第二个不写 `global`，`g = 5` 只生成局部变量 → 全局仍是 10。
- 打印用的 `print("...g =", g)` 会在标签与值之间输出一个空格。

## 数据范围

无输入，使用题目给出的固定数据即可。
