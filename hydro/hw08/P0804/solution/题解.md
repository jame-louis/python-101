# P0804 圆面积计算器（综合·输入+提示）

## 思路

把面积逻辑封成函数 `area(r)`，带提示语读入半径，调用函数并格式化保留两位小数输出。

## 参考代码

```python
PI = 3.14159

def area(r):
    return PI * r * r

print("请输入半径 r：")
r = float(input())
print(f"面积 = {area(r):.2f}")
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1 | 样例（r=2 → 12.57） |
| 2 | 样例（r=5 → 78.54） |
| 3 | 小数半径 |
| 4 | 整数半径 |
| 5 | 小半径边界（0.1） |
| 6-7 | 小随机 |
| 8-9 | 中随机 |
| 10 | 大随机（≤10⁵） |

## 常见错误

- 忘 `float()`，把字符串当数相乘 → 报错或类型错误。
- 格式化写成 `:.2f` 之外的形式 → 小数位数不对。
- 提示语写错（漏全角冒号）→ 逐字匹配不过。
- 忘 `print()` 提示语 → 输出对不上样例。
