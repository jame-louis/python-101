# 圆面积计算器（综合选做）

## 题目描述

读入一个半径 `r`（可为小数），用一个函数 `area(r)` 计算圆的面积并 `return`，然后输出**保留两位小数**的结果。

- 公式：`3.14159 * r * r`。
- 这是"函数封装"的应用版：同一段面积逻辑封装成函数，换取不同输入反复调用。

> 综合选做题，用到函数、`float` 读入与两位小数格式化。

## 输入格式

一行一个数 `r`（可为小数）。程序先显示提示语再读取：

```
请输入半径 r：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。提示语必须与上面**完全一致**（含全角冒号），程序先打印提示语，再用裸 `input()` 读入。

## 输出格式

读取后输出一行，面积保留 **2 位小数**：

```
请输入半径 r：
面积 = 12.57
```

## 样例 #1

```input1
2
```

```output1
请输入半径 r：
面积 = 12.57
```

## 样例 #2

```input2
5
```

```output2
请输入半径 r：
面积 = 78.54
```

## 提示

- 定义：`def area(r): return 3.14159 * r * r`。
- 读入：`print("请输入半径 r：")` 后用 `r = float(input())`。
- 输出：`print(f"面积 = {area(r):.2f}")`。
- 验证：`r=2` → `12.56636` ≈ `12.57`；`r=5` → `78.53975` ≈ `78.54`。

## 数据范围

$0 < r \le 10^5$。

| 测试点 | 说明 |
|--------|------|
| 1-4 | 含样例、整数、小数 |
| 5-6 | 边界（小半径、大半径） |
| 7-10 | 随机小数 |
