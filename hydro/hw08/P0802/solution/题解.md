# P0802 默认参数（基础·无输入）

## 思路

定义函数时为 `city` 给默认值 `"厦门"`。三次调用分别演示：默认值生效、位置参数覆盖、关键字参数覆盖。

## 参考代码

```python
def brief(name, city="厦门"):
    return name + "-" + city

print(brief("小明"))             # 小明-厦门
print(brief("小红", "福州"))      # 小红-福州
print(brief("小刚", city="泉州"))  # 小刚-泉州
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1-5 | 全部相同（无输入、固定输出） |

## 常见错误

- 默认参数写在必选参数前面 → `SyntaxError: non-default argument follows default argument`。
- 把默认写成一个可变对象（如 `def f(city=[])`）→ 会"记住"上次修改（本讲不涉及，但要知道它是个坑）。
- 忘了默认参数的用途，三次调用都重复传 `city` → 没有体现默认值。
