# 默认参数（基础）

## 题目描述

定义一个函数 `brief(name, city="厦门")`，把 `name` 与 `city` 拼成一个字符串 `"姓名-城市"` 返回，然后用**三种方式**调用并各打印一行：

1. 只传 `name`——`city` 用默认值 `"厦门"`。
2. 传两个位置参数——覆盖 `city`。
3. 用**关键字参数** `city="泉州"` 覆盖。

> 默认参数让调用更省心：不传就用默认，需要时可显式覆盖。
> **本题无输入**，输出固定。

## 输入格式

本题**无输入**，程序不读取任何内容。

## 输出格式

共三行：

```
小明-厦门
小红-福州
小刚-泉州
```

## 样例 #1

```input1
（本题无输入）
```

```output1
小明-厦门
小红-福州
小刚-泉州
```

## 提示

- 定义：`def brief(name, city="厦门")`，函数内 `return name + "-" + city`。
- 三次调用：`brief("小明")`、`brief("小红", "福州")`、`brief("小刚", city="泉州")`。
- 验证：第一次 `city` 未传 → 用默认 `"厦门"`；后两次分别用位置/关键字覆盖。

## 数据范围

无输入，使用题目给出的固定数据即可。
