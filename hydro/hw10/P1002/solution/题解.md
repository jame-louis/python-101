# P1002 类属性 vs 实例属性（基础·无输入）

## 思路

类属性写在类体内、所有实例共享一份；实例属性在 `__init__` 里 `self.x=`、各实例独立一份。三步演示：共享的 `school` 一样 → 改 `s1.name` 只影响 s1 → 改 `Student.school` 影响所有。

## 参考代码

```python
class Student:
    school = "嘉庚学院"
    def __init__(self, name):
        self.name = name

s1 = Student("小明")
s2 = Student("小红")
print(s1.school, s2.school)     # 嘉庚学院 嘉庚学院
s1.name = "阿明"
print(s1.name, s2.name)         # 阿明 小红
Student.school = "新学院"
print(s1.school, s2.school)     # 新学院 新学院
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1-5 | 全部相同（无输入、固定输出） |

## 常见错误

- 把实例属性误写成类属性（类体内 `name = None`）→ 所有实例共享一份 name，失去各自独立。
- 用 `s1.school = "新学院"` 去改 → 实际上是给 s1 新建了一个实例属性、掩盖了类属性，其它实例不受影响，与预期不同。
- 混淆"改实例属性"与"改类属性"的影响范围。
