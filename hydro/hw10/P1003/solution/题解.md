# P1003 私有属性与 getter（基础·无输入）

## 思路

`self.__sid` 会被 Python 名称修饰为 `_Student__sid`，从而"看起来私有"。但它是**约定而非铁锁**：外层本应通过公开的 `get_sid()` 读。本题用名称修饰写法 `s._Student__sid` 证明"仍能访问，但不该这么用"。

## 参考代码

```python
class Student:
    def __init__(self, name, sid):
        self.name = name
        self.__sid = sid
    def get_sid(self):
        return self.__sid

s = Student("小明", "2025001")
print(s.name)             # 小明
print(s.get_sid())        # 2025001
print(s._Student__sid)    # 2025001（名称修饰，能访问但不该用）
```

| 1-5 | 全部相同（无输入、固定输出） |

## 常见错误

- 直接 `print(s.__sid)` → AttributeError：名已被改成 `_Student__sid`。
- 想存取私有却不提供 getter → 外部无从安全读取。
- 误以为 `__x` 是绝对私有 → 实际上仍可通过名称修饰访问，理解成"约定"更准确。
