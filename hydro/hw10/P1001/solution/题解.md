# P1001 定义类并调用（基础·无输入）

## 思路

`class` 定义一个 `Student` 模板：类属性 `school`（共享）、`__init__` 初始化实例属性、方法 `say_hello` 读 self 的数据。实例化 `s1`/`s2` 两个对象，各自调用 `say_hello()`。

## 参考代码

```python
class Student:
    school = "xx学院"
    def __init__(self, name, age):
        self.name = name
        self.age = age
    def say_hello(self):
        return f"我是{self.name}，{self.age}岁，来自{self.school}"

s1 = Student("小明", 20)
s2 = Student("小红", 21)
print(s1.say_hello())
print(s2.say_hello())
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1-5 | 全部相同（无输入、固定输出） |

## 常见错误

- 方法忘了写 `self` → 调用时报参数个数不匹配。
- 调用方法漏 `()`（写 `s1.say_hello`）→ 打印的是方法对象而非结果。
- `__init__` 拼写错误 ≥ 而没被自动调用 → 实例没有 name/age 属性。
