# 银行账户存取（综合选做）

## 题目描述

定义 `BankAccount` 类，用**私有余额**配合受控方法存取款，保证数据安全。读入三个整数：初始余额、存入金额、取出金额，输出**取款是否成功**与**最终余额**。

```python
class BankAccount:
    def __init__(self, initial):
        self.__balance = initial       # 私有余额
    def deposit(self, amount):
        self.__balance += amount
    def withdraw(self, amount):
        if self.__balance >= amount:
            self.__balance -= amount
            return "成功"
        return "失败"
    def balance(self):
        return self.__balance
```

- 余额是私有属性，只能通过 `deposit`/`withdraw`/`balance` 这些**公开接口**操作 → 外面不能随手把余额改坏。
- 取款超过余额时给出"失败"且余额不变，这正是受控方法的"安全"价值。

> 综合选做题，用到类的封装与私有属性 + getter。

## 输入格式

**三行**：初始余额、存入金额、取出金额（均为整数）。程序先分别显示提示语再读取：

```
请输入初始余额：
请输入存入金额：
请输入取出金额：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。三行提示语必须与上面**完全一致**（含全角冒号），程序先打印提示语，再用裸 `input()` 读入。

## 输出格式

读取后输出两行：

```
请输入初始余额：
请输入存入金额：
请输入取出金额：
取款结果： 成功
当前余额： 120
```

或（取款失败）：

```
取款结果： 失败
当前余额： 100
```

## 样例 #1

```input1
100
50
30
```

```output1
请输入初始余额：
请输入存入金额：
请输入取出金额：
取款结果： 成功
当前余额： 120
```

## 样例 #2

```input2
100
0
200
```

```output2
请输入初始余额：
请输入存入金额：
请输入取出金额：
取款结果： 失败
当前余额： 100
```

## 提示

- 读入：`init = int(input())` 依序存余额、存、取三数。
- 创建：`acc = BankAccount(init)`；`acc.deposit(存入)`；`acc.withdraw(取出)`。
- 输出：`print("取款结果：", acc.withdraw(取出))`、`print("当前余额：", acc.balance())`。
- 核对样例1：`100 + 50 - 30 = 120`；样例2取款超余额 → 失败、余额不变 `100`。

## 数据范围

初始/存入/取出为非负整数，$\le 10^6$。

| 测试点 | 说明 |
|--------|------|
| 1-2 | 样例（成功 / 失败） |
| 3-4 | 余额恰好等于取款额 |
| 5-6 | 多次正负（含 0） |
| 7-10 | 随机 |
