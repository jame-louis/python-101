# P1005 银行账户存取（综合·输入+提示）

## 思路

余额做成 `__balance` 私有属性，外部只能通过 `deposit`/`withdraw`/`balance` 这些公开方法操作。`withdraw` 内先判断余额是否足够，够才扣减并返回"成功"，否则返回"失败"——受控方法防止外面把余额改坏。

## 参考代码

```python
class BankAccount:
    def __init__(self, initial):
        self.__balance = initial
    def deposit(self, amount):
        self.__balance += amount
    def withdraw(self, amount):
        if self.__balance >= amount:
            self.__balance -= amount
            return "成功"
        return "失败"
    def balance(self):
        return self.__balance

print("请输入初始余额：")
init = int(input())
acc = BankAccount(init)
print("请输入存入金额：")
acc.deposit(int(input()))
print("请输入取出金额：")
w = int(input())
print("取款结果：", acc.withdraw(w))
print("当前余额：", acc.balance())
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1 | 样例（成功：100+50-30=120） |
| 2 | 样例（失败：取200>100） |
| 3 | 恰好相等 → 成功（≥ 判据） |
| 4 | 失败 |
| 5 | 0 起步 |
| 6 | 恰好取完 |
| 7-8 | 小随机（含失败） |
| 9-10 | 大随机（≤10⁶） |

## 常见错误

- 把余额做成公有属性，直接 `acc.__balance` 随手改 → 失去封装与安全（且可能改坏）。
- `withdraw` 用 `>` 而非 `>=` → 恰好相等被误判失败。
- 失败时仍扣减余额 → 数值错；应在判断体外的分支做"失败不扣"。
- 提示语/顺序写错 → 逐字匹配不过。
