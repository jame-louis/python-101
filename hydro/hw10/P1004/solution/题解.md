# P1004 学生自我介绍（综合·输入+提示）

## 思路

定义一个 `Student` 类，`__init__` 存姓名年龄，`say_hello` 读 `self` 的数据返回自我介绍。带提示语分别读入姓名与年龄，实例化后调用方法。

## 参考代码

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    def say_hello(self):
        return f"我是{self.name}，{self.age}岁"

print("请输入姓名：")
name = input()
print("请输入年龄：")
age = int(input())
s = Student(name, age)
print(s.say_hello())
```

## 测试点设计

| 测试点 | 说明 |
|--------|------|
| 1 | 样例（小明 20） |
| 2 | 样例（小红 21） |
| 3 | 边界小年龄（18） |
| 4 | 边界大年龄（30） |
| 5-10 | 随机姓名与年龄 |

## 常见错误

- 忘 `int(age)`，把年龄当字符串 → `f"{age}岁"` 也显示但类型不当；本判题目测同名串，仍应规范化。
- 提示语写错（漏全角冒号）→ 逐字匹配不过。
- 方法忘 `self` 或在 `say_hello` 里 hardcode 姓名 → 不能随输入变化。
