# 学生自我介绍（综合选做）

## 题目描述

读入一个学生的**姓名**与**年龄**（各一行），创建 `Student` 对象并调用 `say_hello()` 方法，输出该生的自我介绍。

- 定义 `class Student`：`__init__` 存 `name`、`age`；`say_hello()` 返回 `f"我是{self.name}，{self.age}岁"`。
- "一个模板，套用到每个学生"——同一类方法，为不同输入输出不同自我介绍。

> 综合选做题，用到类的实例化与对象方法调用。

## 输入格式

**两行**：第一行姓名（字符串），第二行年龄（整数）。程序先分别显示提示语再读取：

```
请输入姓名：
请输入年龄：
```

> ⚠️ **严格匹配**：本评测为逐字节比较。两行提示语必须与上面**完全一致**（含全角冒号），程序先打印提示语，再用裸 `input()` 读入。

## 输出格式

读取后输出一行：

```
请输入姓名：
请输入年龄：
我是小明，20岁
```

## 样例 #1

```input1
小明
20
```

```output1
请输入姓名：
请输入年龄：
我是小明，20岁
```

## 样例 #2

```input2
小红
21
```

```output2
请输入姓名：
请输入年龄：
我是小红，21岁
```

## 提示

- 定义：`def __init__(self, name, age):` 里 `self.name = name; self.age = age`；`say_hello` 返回 `f"我是{self.name}，{self.age}岁"`。
- 读入：`print("请输入姓名：")` → `name = input()`；`print("请输入年龄：")` → `age = int(input())`。
- 实例化并调用：`s = Student(name, age)` → `print(s.say_hello())`。

## 数据范围

姓名由除换行外任意可见字符组成，$18 \le \text{age} \le 30$。

| 测试点 | 说明 |
|--------|------|
| 1-4 | 含样例、不同姓名/年龄 |
| 5-10 | 随机姓名与年龄 |
