# hw10 —— 类与面向对象（Hydro 题目集）

对应课程第 10 讲实验任务卡 `src/assignments/hw10.md`，共 **5 道 Python 传统题**，每题一个自包含
Hydro 题目包（`problem.yaml` + `problem_zh.md` + `testdata/` + `std/` + `solution/`）。

## 知识点约束

本套题贴合**当前学生已学内容**：本讲学习面向对象（`class`/`__init__`/`self`、实例化调用、
实例 vs 类属性、公有/"私有"+ getter）。题目将**刻意聚焦类的定义、实例化与封装**。

- **基础题（P1001–P1003）无输入，固定输出**：定义类并实例化调用、类属性 vs 实例属性、
  私有属性与 getter。
- **综合题（P1004–P1005）有输入 + 带提示语**：学生自我介绍（实例化 + 方法）、
  银行账户存取（私有余额 + 受控方法）。

> ⚠️ 严格逐字匹配：P1004–P1005 提示语（含全角冒号）与输出格式必须逐字复现。

## 题目一览

| PID | 题目 | 类型 | 考点 | 处理方式 |
|-----|------|------|------|----------|
| P1001 | 定义类并调用（基础） | 无输入 | `class`/`__init__`/`self`、实例化、`对象.方法()` | 固定输出 |
| P1002 | 类属性 vs 实例属性（基础） | 无输入 | 共享 vs 独立、改类/实例属性 | 固定输出 |
| P1003 | 私有属性与 getter（基础） | 无输入 | `__x` 名称修饰、getter | 固定输出 |
| P1004 | 学生自我介绍（综合选做） | 输入+提示 | 实例化 + 方法调用 | 严格逐字匹配 |
| P1005 | 银行账户存取（综合选做） | 输入+提示 | 私有余额 + 受控方法、加密 | 严格逐字匹配 |

## 使用

校验全部题目：

```bash
python3 hydro/hw10/validate.py
```

（数据生成/重放：`python3 gen.py N > testdata/N.in` + `python3 std/std.py.py3 < *.in > *.out`）

## 说明

- Hydro 评测为**传统题**，语言放开 Python 即可；`std` 后缀 `std.py.py3` 与 Hydro 的 Python3 语言键一致。
- 基础题为固定输出便于自查；综合题覆盖样例、恰等取款、失败取款、0 起步、随机等，并保留较多随机测试点。
- P1004、P1005 恰好对应 hw10 任务卡的两个进阶任务（🔴 学生自我介绍、🔴 银行账户存取），
  与基础题一起完整覆盖了"定义与调用、类/实例属性、公有/私有与封装"三条主线。
