## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| 函数 | 用 `def` 定义、`return` 返回的一段可复用的逻辑 | 代码界的黑盒子 |
| 封装复用 | 一处写逻辑、到处调用，改内部不影响调用方 | 电饭煲按键→米饭 |
| 位置参数 | 调用时按形参顺序一一对应 | 排队站位 |
| 关键字参数 | `f(a=1)` 指名道姓，顺序可乱 | 点菜报菜名 |
| 默认参数 | `def f(a, b=0)` 不传就用默认值 | 默认选项 |
| `*args` / `**kwargs` | 收集多余的位置/关键字实参 → 元组/字典 | 横锅/竖锅 |
| 局部 vs 全局 | 函数体内赋值默认是局部，改全局需 `global` | 房间 vs 楼 |
| 可变 vs 不可变 | list/dict/set 是原件，int/str/tuple 是复印件 | 原件 vs 复印件 |

### 关键语法速查

```python
def 函数名(参数):        # 定义
    函数体
    return 返回值        # 不写默认返回 None

def area(r):            # 圆的面积
    return 3.14159 * r * r

def register(name, age, city="厦门", *hobbies, **extra):
    print(name, age, city)

register("小明", 20)              # 位置 + 默认
register("小红", city="泉州")      # 关键字
register("小刚", 22, "厦门", "篮球")  # *args

g = 10
def f():
    global g          # 声明后才能改全局
    g = 99
```

> 默认参数不要写可变对象（`def f(lst=[])` 是坑），用 `lst=None`。
