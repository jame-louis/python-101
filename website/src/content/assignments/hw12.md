## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| 监督学习 | 数据带标签，学"输入→标签"的映射 | 有答案的作业 |
| 无监督学习 | 数据无标签，自己找结构 | 自己分堆 |
| 分类问题 | 判断输入属于哪个类别（标签） | 分级归类 |
| 特征 / 标签 | 判断依据的输入维度 / 要预测的答案 | 线索 / 结论 |
| 决策树 | 每步问一个特征做判断，层层分裂到叶子 | 连续做判断题 |
| KNN | 找离新点最近的 K 个已知样本，多数表决 | 人以群分 |
| 训练/测试划分 | 留一部分未见数据检验，防"背答案" | 平时卷 vs 期末考 |

### 关键代码速查

```bash
# 安装
pip3 install scikit-learn
```

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score

iris = load_iris()
X, y = iris.data, iris.target                      # 150×4 特征, 3 类
X_train, X_test, y_train, y_test = \
    train_test_split(X, y, test_size=0.3, random_state=42, stratify=y)

dt = DecisionTreeClassifier(max_depth=3, random_state=42)
dt.fit(X_train, y_train)                           # 训练
print("决策树:", accuracy_score(y_test, dt.predict(X_test)))

knn = KNeighborsClassifier(n_neighbors=5)
knn.fit(X_train, y_train)
print("KNN:", accuracy_score(y_test, knn.predict(X_test)))

# 调 K
for k in [1, 3, 5, 10, 20]:
    m = KNeighborsClassifier(n_neighbors=k).fit(X_train, y_train)
    print(f"k={k} 准确率={accuracy_score(y_test, m.predict(X_test)):.3f}")

# 降维到两特征（花瓣长/宽）
X2 = X[:, 2:]
print(X2.shape)    # (150, 2)
```
