## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| 无监督学习 | 数据无标签，自己找结构/分组 | 自己分堆 |
| 聚类 | 把相似样本自动归到同一簇 | 人以群分 |
| 惯性 inertia | 所有点到所属簇中心的距离平方和 | 越小越紧凑 |
| k-means 四步 | 选中心→分配→更新→迭代 | 反复漂移收敛 |
| 初始中心点 | 迭代起点，选法影响局部最优 | 从哪出发 |
| k-means++ | 让离已选中心远的点更可能当选 | 更稳的起点 |
| 肘部法则 | 用"K–惯性"曲线拐点选 K | 找胳膊肘 |

### 关键代码速查

```python
import numpy as np
from sklearn.cluster import KMeans

X = np.array([[1, 1], [1.5, 2], [2, 1.5], [2.5, 2], [2, 3],
              [8, 8], [8.5, 8.5], [9, 8], [8.5, 9], [8, 9.5]])

km = KMeans(n_clusters=2, n_init=10, random_state=42)   # 10 个初始点取最优
km.fit(X)
print(km.labels_)              # 每点属于哪簇
print(km.cluster_centers_)     # 簇中心
print(km.inertia_)             # 惯性
print(km.predict([[9, 8.5]]))  # 新点分到哪簇

# 肘部法则：循环 K 看惯性
K = range(1, 8)
inertias = [KMeans(n_clusters=k, n_init=10, random_state=42).fit(X).inertia_ for k in K]
```

> 聚类前若各特征量纲差异大，先 `StandardScaler` 标准化，避免量纲大的特征主导距离。
