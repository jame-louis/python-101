## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| 监督学习 | 数据带标签，学"输入→输出"映射 | 有答案的作业 |
| 回归 | 预测一个**连续数值** | 价格、温度 |
| 线性回归 | 用一条直线贴合散点大趋势 | y = kx + b |
| 斜率 k | x 每变 1，y 平均变化多少 | 上升坡度 |
| 截距 b | x=0 时的 y 值 | 起跑点高度 |
| 残差 | 每个点到直线的垂直误差 y−ŷ | 偏差 |
| 最小二乘 | 找 (k,b) 使残差平方和最小 | 把误差压到最小 |

### 关键代码速查

```python
import numpy as np
from sklearn.linear_model import LinearRegression
import matplotlib.pyplot as plt

area  = np.array([50, 70, 80, 100, 120, 130, 150]).reshape(-1, 1)  # X 要二维
price = np.array([45, 62, 70, 88, 105, 112, 130])

model = LinearRegression()
model.fit(area, price)
print("斜率 k =", model.coef_[0])      # 系数
print("截距 b =", model.intercept_)     # 截距

pred = model.predict([[95]])           # 预测 95 ㎡
manual = model.intercept_ + model.coef_[0] * 95   # ŷ = k·x + b 核对
print("predict =", pred[0], "  手写 =", manual)

xs = np.linspace(40, 160, 100)
ys = model.intercept_ + model.coef_[0] * xs
plt.scatter(area, price, color='blue', label='原始数据')
plt.plot(xs, ys, color='red', label='拟合线')
plt.legend(); plt.grid(True); plt.show()
```

> sklearn 要求 `X` 为二维：单特征用 `.reshape(-1, 1)`；系数多特征时在 `coef_[]`，单特征取 `coef_[0]`。
