## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| 单条件 if | 条件成立才执行缩进块 | 一条岔路 |
| 双条件 if-else | 二选一：if 不成立就走 else | 两条岔路 |
| 多条件 if-elif-else | 从上到下依次判断，命中即停 | 多条岔路 |
| elif | Python 的多分支连写（不是 else if） | 连起来的岔口 |
| elif 隐含条件 | 每个 elif 已隐含"前面都不成立" | 免费午餐 |
| 缩进 | Python 用缩进界定代码块（C 用 {}） | 亲疏集团 |
| 嵌套分支 | 外层抓大类，内层做细分 | 先分级再细分 |

### 关键语法速查

```python
if 条件:                # 单条件
    语句

if 条件:                # 双条件
    语句
else:
    语句

if 条件:                # 多条件
    语句
elif 条件:
    语句
else:
    语句

# 嵌套：外层抓大类，内层细分
if score >= 60:
    if score >= 90:
        grade = "优秀"
    else:
        grade = "及格"
else:
    grade = "不及格"
```

> 梭进统一 4 空格，勿混 Tab；`elif` 判断的是本层条件，勿重复写前置条件。
