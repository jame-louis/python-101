## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| 类（class） | 描述一类事物共有属性的行为的模板 | 模具 / 设计蓝图 |
| 实例（instance） | 用类冲压出的具体个体，数据各自不同 | 工件 / 一个个学生 |
| `__init__` | 创建对象时自动执行的构造函数 | 一出生就初始化 |
| `self` | 指向"正在调用方法的那个对象" | 我自己的本体 |
| 实例属性 | `__init__` 里 `self.x=`，每实例一份 | 个性 |
| 类属性 | 类体内直接写的，所有实例共享 | 共性 / 集体 |
| 公有/私有 | 公有直接访问；`__x` 名称修饰 + getter 读 | 正门 / 后门约定 |

### 关键语法速查

```python
class Student:
    school = "嘉庚学院"              # 类属性（共享）

    def __init__(self, name, age):   # 构造函数
        self.name = name             # 实例属性（个性）
        self.age = age

    def say_hello(self):             # 方法
        return f"我是{self.name}，来自{self.school}"

s = Student("小明", 20)     # 实例化
print(s.say_hello())         # 实例.方法()
print(s.name)                # 实例.属性
print(Student.school)        # 类名.类属性

class BankAccount:
    def __init__(self, initial):
        self.__balance = initial     # "私有"余额
    def get_balance(self):           # getter
        return self.__balance
```

> 方法第一参写 `self`；调用方法要 `s.method()` 别漏括号；"共性"放类里共享、"个性"放 `__init__` 里。

3. `__x` 是真正的私有吗？为什么用 getter 而不用 `obj.__x` 直接访问？（提示：名称修饰、封装与安全）
