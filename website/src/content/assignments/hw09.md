## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| lambda | 单表达式匿名函数，自动返回结果 | 不取名的快递员 |
| sorted | 排序返回新列表，`key=函数` 定规则 | 排队按谁的号 |
| map | 对每个元素变换，返回迭代器 | 逐个加工 |
| filter | 保留使函数为真的元素 | 逐一挑选 |
| 异常 | 程序运行中的错误对象，有类层次 | 崩溃前的警报 |
| try/except | 试探 + 代号接住异常 | 安全气囊 |
| else / finally | 无异常才走 / 无论如何都走 | 顺路登记 / 必定善后 |
| 多返回值 | `return a, b` 返回元组，一行解包 | 结论 + 置信度 |

### 关键语法速查

```python
add = lambda a, b: a + b              # 匿名函数

sorted(pairs, key=lambda t: t[1], reverse=True)   # 按第二元素降序
list(map(lambda x: x * x, nums))      # 逐个平方（迭代器要 list()）
list(filter(lambda x: x >= 18, a))    # 保留成年

def safe_div(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return "除数不能为 0"

def f(v):
    try:
        r = int(v)
    except ValueError:
        print("不是数字")
    else:
        print("转换成功，值为", r)
    finally:
        print("finally 总会执行")

def predict(score):
    return ("通过" if score >= 60 else "不通过"), min(score/100, 0.99) + 0.01
```

> 裸 `except:` 会吞掉 Ctrl+C 等系统级错误并掩盖 bug，能预判的应精准捕获子类。
