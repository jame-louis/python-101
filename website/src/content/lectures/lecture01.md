# Python

## Hydro 在线评测系统 · 学生使用教程

---

### 一、首次登录（必做）

1. 打开浏览器，访问老师发的 OJ 地址（如 `http://192.168.x.x:8080`），**推荐 Chrome / Edge**
2. 用老师下发的账号登录：
   - 用户名：学号（如 `stu2023001`）
   - 初始密码：见课程群通知（通常与学号相关）
3. **第一件事：改密码**
   - 右上角头像 → **设置** → 修改密码
   - 密码要求：至少 8 位，建议字母+数字组合，不要用 123456

⚠️ 账号无法自助找回——忘记密码请找老师重置，改完密码自己记好。

### 二、进入课程空间

登录后默认在公共域，**必须切到课程域**才能看到作业：

1. 看页面**顶栏的域切换下拉框**（写着「Hydro」的地方）
2. 选择老师创建的课程（如「Python 程序设计 2026 秋」）
3. 左侧菜单出现：**题库、作业、比赛、记录** 等

如果下拉框里**看不到课程**：说明账号没被加进该课程域，联系老师把你加入。

### 三、查看与提交作业

#### 3.1 找到作业

左侧 **作业** → 点击进入本次作业，能看到题目列表和**截止时间**。

- 灰色不可点 = 还没到开放时间
- 显示「已结束」= 不能再交，只能看题

#### 3.2 提交代码

1. 点进一道题，看清：**输入格式、输出格式、样例**
2. 页面下方是提交区：
   - **在线编辑器**：直接粘贴代码（适合小代码）
   - 或「选择文件」上传 `.py` 文件
3. **语言选 `Python 3`**（按课程要求，选错语言会编译错误）
4. 点 **提交** 按钮

#### 3.3 看评测结果（重点）

提交后几秒内出结果，鼠标移到题号上能看到每个测试点状态：

| 状态 | 含义 | 怎么办 |
|---|---|---|
| ✅ Accepted (AC) | 全部通过，满分 | 庆祝 🎉 |
| ❌ Wrong Answer (WA) | 答案错误 | 检查边界情况、输出格式（多空格/少换行最常见） |
| ⏱ Time Limit Exceeded (TLE) | 超时 | 算法太慢，换更优思路 |
| 💥 Runtime Error (RE) | 运行崩溃 | 数组越界、除零、递归爆栈、读入格式不对 |
| 🚫 Compile Error (CE) | 编译失败 | 语法错误，或语言选错（Python 看成 C++） |
| ⏳ Waiting / Judging | 排队/评测中 | 等几秒刷新即可 |

**关键习惯**：WA 时不要瞎改——先自己造几组输入，用"样例思维"手算对比你的输出和期望输出。最常见错误：
- 行末多了空格、少了换行
- 大小写不对（题目要求大写你输出小写）
- 边界情况：0、负数、空串、最大值

#### 3.4 多次提交

- 截止时间前可以**无限次提交**，系统按老师设定取最高分或最后一次
- 每道题下方有你的**提交历史**，可回看每次代码和结果

### 四、查成绩

- 作业列表页：看每题当前得分
- 左侧 **记录**：全站提交流水（只看自己的就在个人主页）
- 期中/期末总评：以老师导出并发布的为准（OJ 分数 ≠ 最终成绩，老师可能调整）

### 五、常见问题 FAQ

**Q1：登录提示"用户名或密码错误"？**
检查用户名是不是学号全称（含 `stu` 前缀）、有没有多空格。三次失败稍等再试。还不行找老师重置。

**Q2：提交按钮点了没反应 / 一直转圈？**
换 Chrome 浏览器；检查代码里有没有中文标点（复制别人的代码最容易带入中文引号、全角分号）；网络卡就多等几秒。

**Q3：本地跑对，交上去 WA？**
99% 是没读清题：检查输入是不是多组数据（直到 EOF）、输出格式（比如要求一行一个还是空格分隔）。本地只测了样例，没测边界。

**Q4：一直 Waiting/Judging？**
高峰期排队，正常 < 1 分钟。超过 5 分钟截图找老师。

**Q5：代码里有 `input("请输入")` 这类提示文字？**
**删掉所有提示语，评测机只看标准输出**，多余的输出全部判 WA。只需要 `x = input()`。

**Q6：能不能用 `numpy` / 第三方库？**
默认环境没有装第三方库，只用标准库。需要特殊库找老师确认（老师可在评测机预装）。

### 六、诚信提醒

- 系统有查重机制，相似度过高的代码双方都会被标记
- 可以讨论思路，但**代码必须自己写**
- 不要尝试攻击评测系统（读测试数据、扫端口等），一律按作弊处理并记录档案
