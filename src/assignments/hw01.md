## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| 解释器（Interpreter） | 逐行读取并执行 Python 代码的程序 | "翻译员边走边译" |
| 脚本模式 | 写 `.py` 文件后一次性运行 | 写完一封信再寄出 |
| 交互模式（REPL） | 命令行逐行输入，立即出结果 | 面对面一问一答 |
| pip | Python 的包管理工具，安装第三方库 | 应用商店 |

### 关键命令速查

```
python3 --version     # 查看 Python 版本
python3 --help        # 帮助
pip3 --version        # 查看 pip 版本
python3 文件名.py     # 运行脚本（macOS/Linux）
python 文件名.py      # 运行脚本（Windows）
```

## 三、实验任务

### 🔵 基础任务（必做，约 25 分钟）

**任务1：安装并配置 Python 开发环境**

1. 从官网（python.org）或系统包管理器安装 Python 3.10+
2. 安装 VSCode 并安装 Python 扩展
3. 在 VSCode 中确认选择了解释器（右下角显示版本号）
4. **验证：** 命令行运行 `python3 --version` 能输出版本号

**任务2：运行第一个 Python 程序**

1. 新建文件 `demo_01_first.py`
2. 输入 `print("Hello Python!")` 和 `print("Hello 未来工程师!")`
3. 运行成功，观察输出
4. **验证：** 控制台正确打印两行内容

---

### 🟡 进阶任务（选做，约 10 分钟）

**任务3：脚本模式 vs 交互模式**

1. 在命令行（终端/PowerShell）启动交互模式（输入 `python3` 回车）
2. 逐行输入几个表达式（如 `1+2`、`"AB"*3`），观察立即输出
3. 退出交互模式（`exit()`）
4. **分析要求：** 用自己的话写出——交互模式与脚本模式的区别与适用场景

---

### 🔴 挑战任务（选做，约 10 分钟）

**任务4：体验 pip 安装第三方库**

场景描述：为之后的图像处理学习打基础。

- 任务要求：用 pip 安装 `numpy`，用 `import numpy` 并打印其版本号
- 提示：`pip3 install numpy`，然后 `import numpy; print(numpy.__version__)`
