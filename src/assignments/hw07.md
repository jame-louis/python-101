## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| for 循环 | 遍历一个明确的"清单"，按顺序逐个处理每个元素 | 挨个点名 |
| while 循环 | 只要条件为真就反复执行，直到条件不成立 | 跑到条件为止 |
| range() | 生成整数序列：`range(停止)` / `range(起,止,步)` | 发号员 |
| break | 立即**跳出整个当前层**循环 | 急刹车 |
| continue | **跳过本次**剩余语句直接进入下一次 | 跳一圈 |
| 嵌套循环 | 外层执行一次、内层完整跑一整轮 | 表格行 × 列 |
| 死循环 | 条件恒真且无 break，无限执行占满资源 | 失控的机器 |

### 关键语法速查

```python
for i in range(1, 6):       # 遍历 1,2,3,4,5（差1缺尾）
for n in nums:              # 遍历列表的每个元素
total += i                  # 累加：total = total + i

while 条件:                 # 条件为真就不断执行
    循环体
while True:                 # 无限循环
    ... break               # 用 break 或标记值退出

break                       # 跳出当前层循环
continue                    # 跳过本次，进入下一次

for i in range(1, 5):       # 嵌套循环（下三角）
    for j in range(1, i + 1):
        print("*", end="")
    print()
```

### 🔵 基础任务（必做，约 30 分钟）

**P0701 for+range() 累加求和**

用 `for` + `range()` 计算**1 到 200 的所有整数之和**，以及其中**所有偶数之和**，各输出一行固定结果。验证：`1+2+…+200 = 20100`、偶数和 `= 10100`（可手算核对）。

**P0702 break/continue 控制流程**

用 `continue` 在 `for i in range(1,7)` 里**跳过 3**，输出 `1 2 4 5 6`；再用 `break` 在 `i==5` 时**提前终止**，输出 `1 2 3 4`。验证：`break` 整个循环停、`continue` 只是跳过一次。

**P0703 嵌套循环数字图案**

用嵌套循环打印一个数字下三角：第 1 行 1 个、第 2 行 2 个……

```
1
12
123
```

验证：先画变量追踪表，列数 = 当前行数（内层 `j` 从 1 到 `i`），再确认输出。

### 🟡 进阶任务（必做，约 15 分钟）

**P0704 while 读入统计**

用 `while True` 配合**标记值 -1**不断读入整数（带提示语），统计并输出**有效个数**（不含 -1）与**总和**。验证：输入 `5 10 -1` 得到"个数 2、总和 15"；不写 `break` 就会死循环。

**P0705 质数判断（循环 + 条件综合）**

读入一个正整数 `n`（带提示语），输出 `n` 以内（含）的**所有素数**及其**个数**。验证：`n=7` 输出 `2 3 5 7` 与"共 4 个"；用内层循环判断约数、配合 `break` 提前结束。这是"循环+条件"的挑战综合。
