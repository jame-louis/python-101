## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| 集合（set） | 无序、元素不重复、元素须可哈希，用 `{}` 或 `set()` | 只收不重复物品的收纳盒 |
| 去重（dedup） | 用集合自动去掉重复元素 | 重的自动丢弃 |
| 字典（dict） | 以"键→值"（key-value）方式存储，用 `{键:值}` | 姓名 → 信息的电话簿 |
| 键（key） | 字典中用于快速查找、须不可变唯一的索引 | 电话簿中的"姓名" |
| 值（value） | 键对应的数据，任意类型、可修改 | 电话簿中的"信息" |
| 键值对（item） | 一个键和它与配对的值组成的一项 | 一行电话记录 |

### 关键语法速查

```python
s = set()                # 空集合（注意 {} 是空字典）
s.add(x)                 # 增，重复不生效
s.discard(x)             # 删，不存在也不报错
A & B                    # 交集；也有方法 intersection()
A | B                    # 并集；也有方法 union()
A - B                    # 差集；也有方法 difference()

d = {"name": "Alice"}    # 字典字面量
d2 = dict(name="Bob")            # dict() 关键字参数
d3 = dict.fromkeys(["x","y"],0)  # 批量默认值
d4 = dict(zip(keys, values))     # 两组序列配对
d["age"]                 # 用键取值，键不存在报 KeyError
d.get("age", 默认值)      # 安全取值，找不到返回默认值
d["age"] = 21            # 增/改
del d["age"]             # 删
for k, v in d.items():   # 遍历键值对
```

### 🔵 基础任务（必做，约 30 分钟）

**任务1：集合去重清洗**

一段"用户点击日志"里有很多重复项，请用集合去重。

1. 定义 `raw = ["手机", "手机", "耳机", "平板", "耳机", "手机"]`
2. 用 `set()` 把列表转成集合，打印（观察重复被自动去掉）
3. 再用 `sorted(set(raw))` 得到排好序的唯一物品列表，打印
4. **验证：** 打印结果不再是重复的 6 项，而是唯一项；说明集合与列表在"是否允许重复"上的区别

**任务2：集合的交集、并集、差集**

两位用户各有兴趣标签，请找出他们的共同与各自独有兴趣。

1. 定义 `userA = {"电子", "游戏", "运动"}`、`userB = {"运动", "摄影", "电子"}`
2. 分别用 `&`、`|`、`-` 打印：共同兴趣、全部兴趣、用户A独有
3. 用 `len()` 打印每组元素个数
4. **验证：** 共同兴趣含 `运动` 与 `电子`；解释 `&` 为什么不等于 `|`

**任务3：字典的增删改查**

用一句话的键值对完成字典的完整生命周期。

1. 定义 `user = {"name": "Alice", "age": 20}`
2. 用键打印 `name`；把 `age` 改为 21；新增 `city` 为 `"Xiamen"`
3. 遍历：分别用 `for k in user`、`for v in user.values()`、`for k, v in user.items()` 打印键、值、键值对
4. 用 `user.get("email", "无邮箱")` 访问一个不存在的键，确认**不报错**并返回默认值；再用 `user["email"]` 访问，观察 `KeyError`
5. **验证：** 理解 `d[k]` 与 `d.get(k, 默认)` 的区别

### 🟡 进阶任务（必做，约 15 分钟）

**任务4：字典的多种构造方法**

用不同的方法构造内容相同的字典 `{"sport": 10, "tech": 20, "game": 30}`，对比并说明适用场景。

1. 用字面量 `{}` 构造
2. 用 `dict(sport=10, tech=20, game=30)` 关键字参数构造
3. 用 `dict.fromkeys(["sport", "tech", "game"], 0)` 构造"全 0 默认值"字典
4. 给定 `keys = ["sport", "tech", "game"]`、`values = [10, 20, 30]`，用 `dict(zip(keys, values))` 配对构造
5. **验证：** 四种方式打印结果一致；并对比第4.1题：为什么 `fromkeys` 常用于"批量默认值"、`zip` 适合"先存好两组数据再配对"

**任务5：词频统计 + AI 模型配置表**

结合 NLP 与工程场景，把字典用于"名称 → 数值"的映射。

部分一：**NLP 词频统计**

1. 定义 `words = "the apple the banana the apple".split()`
2. 用 `freq = {}` 配合 `freq[w] = freq.get(w, 0) + 1` 统计每个单词出现次数
3. 打印 `freq`，验证 `the` 出现 3 次、`apple` 2 次、`banana` 1 次
4. 思考：如果 `w` 换成列表（如 `{"apple", "apple"}` 里的元素换行），会出现 `unhashable` 报错吗？（提示：**见思考题1**）

部分二：**AI 模型配置参数映射表**

1. 构造一个字典 `config`，含键：`learning_rate=0.01`、`epochs=50`、`optimizer="adam"`、`device="cuda"`
2. 用键读取并打印 `optimizer` 与 `learning_rate`
3. 用 `config.get("scheduler", "未配置")` 安全读取不存在的键
4. 思考：用字典存配置相比用列表有什么好处？（按名称取、有序无关、键语义化）
