## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| 变量 | 存放数据、可重新赋值的名字，Python 动态类型（赋值即定义） | 贴了标签的盒子 |
| 常量 | 约定用全大写命名、意在不修改的值 | 不能换的"固定编号" |
| int / float / str | 整型 / 浮点（小数） / 字符串 三种基本类型 | 整数卡片 / 小数卡片 / 字条 |
| 类型转换（casting） | 用 `int()/float()/str()` 把一种类型转成另一种 | 把卡片"翻译"成另一种 |
| 分片（slicing） | 用 `s[start:stop:step]` 截取子串，含头不含尾 | 在长句中掐出一段 |

### 关键语法速查

```python
x = 10              # 变量：赋值即定义，无需声明类型
PI = 3.14159        # 常量：全大写命名（约定）

type(x)             # 查看变量类型
int(x) / float(x) / str(x)   # 显式类型转换

7 // 2              # 整除 → 3
7 % 2               # 取余 → 1
2 ** 10             # 幂 → 1024

s = "Python"
s[1:5]              # 正向分片（含头不含尾）
s[-1]               # 负索引：倒数第1个字符
s[::-1]             # 逆序分片（完整取反）
len(s)              # 字符串长度
```

## 三、实验任务

### 🔵 基础任务（必做，约 15 分钟）

**任务1：变量、常量与数值计算**

1. 定义变量 `age = 21`、`score = 88.5`，用 `type()` 打印它们各自的类型
2. 定义常量 `SPEED_OF_LIGHT = 299792458`（光速），打印它
3. 计算并打印 `7 // 2`、`7 % 2`、`2 ** 10`、`(3*4)+5`
4. **验证：** 在交互模式或脚本中逐一运行，核对每个表达式的结果

**任务2：类型转换**

1. 分别打印 `int(3.9)`、`float(5)`、`str(100)` 的值与类型
2. 把字符串 `"100"` 转成整数再加 1，观察结果
3. 把 `"我的年龄是"` 与数字 `21` 拼接，尝试直接 `+` 观察报错，再用 `str(21)` 正确拼接
4. **验证：** 理解"字符串与数字不能直接 `+`"

**任务3：字符串正向分片**

1. 定义 `s = "Python"`，分别打印 `s[0]`、`s[1:5]`、`s[:3]`、`s[3:]`
2. 用自己的话写出：分片"含头不含尾"是什么意思？
3. **验证：** 对照下标表核对每个输出的字符数
