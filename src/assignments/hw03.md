## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| 字符串方法 | `字符串.方法名(...)` 对字符串执行的操作 | 给字符串"做动作" |
| split() | 按分隔符把字符串**拆成**列表 | 把一句话切成词 |
| join() | 把列表**合成**一个字符串 | 把词粘成一句话 |
| strip() | 去掉字符串**两端**的空白 | 洗去灰尘 |
| input() | 从键盘读入一行文本，**总是返回字符串** | 收信箱收到的都是"信件(fig)" |
| 类型转换 | 用 int()/float() 把 str 转成数值 | "3" → 3 |

### 关键语法速查

```python
s.strip()          # 去两端空白
s.split(",")       # 按逗号拆成列表
" ".join(list)     # 用空格把列表合成字符串
s.replace(a, b)    # 把 a 替换成 b
s.find(x)          # 找 x，返回下标，找不到 -1
len(s)             # 字符串长度
x = int("3")       # 转整数
y = float("3.14")  # 转小数
f"值：{x}"         # f 字符串格式化
```

### 🔵 基础任务（必做，约 22 分钟）

**任务1：字符串方法清理文本**

有一段含噪声的文本，请用 Python 字符串方法把它变干净。

1. 定义 `raw = "  欢迎学习 Python 应用程序设计  \n"`
2. 用 `strip()` 去掉两端空白，打印结果
3. 把处理后的字符串转全大写（`upper()`）打印
4. 把其中的 `"Python"` 替换成 `"Python3"`（`replace`）
5. **验证：** 控制台依次输出去空白、全大写、替换后的三行结果

**任务2：输入类型转换 —— 求和与平均**

1. 用 `input()` 读入两个**数字**（用 `int()` 转换）
2. 计算它们的和与平均值，用 `print()` 输出
3. **验证：** 输入 `6` 和 `7`，正确输出 `和:13  平均:6.5`
4. 修改：第二个数改用 `float()` 转换（允许输入小数），再验证
