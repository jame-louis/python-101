## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| 继承 | `class B(A)`，子类自动获得父类属性与方法 | 孩子继承父母姓氏与技能 |
| 方法重写 | 子类用同名方法覆盖父类方法 | 青出于蓝 |
| `super()` | 指向父类的代理，调用父类构造器/方法 | 回头请父母帮忙 |
| 构造器继承 | 不写 `__init__` 直接用，或 `super().__init__()` 扩展 | 白用 / 补充 |
| 多态 | 同一接口（方法名）不同对象给出不同实现 | 一个 speak 各自动作 |
| 封装 | 对外稳定接口、对内自由演进 | 黑盒子 |

### 关键语法速查

```python
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        return f"{self.name} 发出叫声"

class Dog(Animal):              # 继承
    def speak(self):            # 重写
        return f"{self.name} 汪汪叫！"

class Point2D:
    def __init__(self, x, y):
        self.x, self.y = x, y

class Point3D(Point2D):
    def __init__(self, x, y, z):
        super().__init__(x, y)  # 补父类初始化
        self.z = z              # 再加自己

# 多态：同一接口不同实现
animals = [Dog("大黄"), Animal("普通")]
for a in animals:
    print(a.speak())
```

> 子类重写 `__init__` → 必须 `super().__init__()` 补父类；重写方法名要与父类一字不差。
