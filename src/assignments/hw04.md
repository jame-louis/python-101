## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| 列表（list） | 有序、可变的元素序列，用 `[]` | 一排可自由入座的座位 |
| 元组（tuple） | 有序、不可变的元素序列，用 `()` | 固定不动的贵宾席 |
| 追加（append） | 在列表末尾新增一个元素 | 队伍末尾加一个人 |
| 扩展（extend） | 把一个可迭代对象展开拼进列表 | 两队拼接成一批 |
| 插入（insert） | 在指定位置放入一个元素 | 插队到某位置 |
| 切片（slicing） | 按范围取列表的一段 | 剪下一段胶片 |
| 解包（unpacking） | 把元组/列表一次性拆给多个变量 | 拆一箱到多个格子 |

### 关键语法速查

```
lst.append(x)      # 末尾追加单个元素 x
lst.extend(it)     # 把可迭代对象 it 展开拼接进列表
lst.insert(i, x)   # 在位置 i 前插入 x
lst[i] = v         # 修改下标 i 的值
lst.remove(v)      # 删除第一个值为 v 的元素
lst.pop()          # 弹出并返回末尾元素
lst.sort()         # 原地升序排序
sorted(lst)        # 返回新的已排序列表
lst[a:b]           # 切片，含 a 不含 b
for x in lst:      # 遍历
t = (1, 2)         # 创建元组；单元素要写 (5,)
a, b = t           # 元组解包
```

## 三、实验任务

### 🔵 基础任务（必做，约 15 分钟）

**任务1：列表的增删改查与遍历**

1. 创建一个列表 `scores = [78, 88, 95, 66]`
2. 输出第 1 个元素、最后一个元素、列表长度
3. 把第 2 个元素改为 `99`；用 `append` 在末尾追加 `100`
4. **验证：** 屏幕按预期输出改变后的列表与遍历结果

**任务2：元组的创建与访问**

1. 创建元组 `t = (10, 20, 30)`
2. 用下标访问 `t[0]`；用 `len(t)` 取长度
3. 尝试 `t[0] = 99`，观察报错，理解"元组不可变"
4. **验证：** 说出为什么 `t[0] = 99` 会失败

### 🟡 进阶任务（选做，约 20 分钟）

**任务3：三种插入方法对比**

1. 用 `append(4)`、`extend([4, 5])`、`insert(1, 99)` 各对一个 `[1,2,3]` 操作
2. **分析要求：** 写出三者各自的结果，并用一句话说清它们分别做什么
3. 再试一次 `lst.append([4, 5])`，观察结果与 `extend` 的差别，说明原因
4. **验证：** 能写出三个方法各自的适用场景

**任务4：AI 数据场景（二选一）**

- 场景A（图像识别）：用 `append` 把 `img_001.jpg` ~ `img_005.jpg` 逐条加进 `dataset` 列表；再用 `insert` 在中间某个位置插入一个新样本。
- 场景B（训练损失）：创建一个损失值列表，用 `sort()` 升序排列后找出最低损失；再用 `sorted(reverse=True)` 观察降序结果，说明你从排序中能读出什么。

**任务5：元组解包**

1. 定义 `point = (3, 5)`，用 `x, y = point` 解包
2. 定义字典式的坐标对 `(x, y)` 列表，遍历解包每个点并打印

**任务6：NLP 文本批量处理**

1. 创建文本列表 `["Hello", "WORLD", "python"]`
2. 用循环 + `append` 生成每个词转小写的清洗结果列表
3. **验证：** 输出全为小写的新列表
