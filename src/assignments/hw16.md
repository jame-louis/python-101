## 二、背景知识

### 最小课程设计流水线（演示骨架）

```python
import numpy as np
from sklearn.neighbors import KNeighborsClassifier
from sklearn.model_selection import train_test_split

# 1. 读入并预处理特征矩阵 X、标签 y（numpy）
X = np.random.rand(50, 4)   # 示意：50 个样本，4 个特征
y = np.array([0, 1] * 25)   # 示意：两类标签

# 2. 拆分训练/测试
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.2)

# 3. 训练与评估
knn = KNeighborsClassifier(n_neighbors=3)
knn.fit(Xtr, ytr)           # 训练
print("准确率:", knn.score(Xte, yte))   # 评估
```

> 课程设计 = 把这个骨架换成"真实图像 + 你的主题 + 一个合适的模型"，并把它做完整。

### 算法速辨（选模型用）

| 问题 | 有无标签 | 预测目标 | 算法 |
|---|---|---|---|
| 图片分类 | 有 | 类别 | KNN / 决策树 |
| 连续值预测 | 有 | 数值 | 线性回归 |
| 无标签分组 | 无 | 组别 | k-means |
| 非线性关系 | 有 | 数值/类别 | 神经网络 BP |

> 两问辨算法：**有没有标签？要预测的是类别还是数值？**

- 🔵 应用型：图像边缘检测、灰度直方图均衡、图像去噪、亮度/对比度增强
