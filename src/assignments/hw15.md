## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| 神经网络 | 把许多简单"神经元"连起来，从数据学模式 | 搭积木 |
| 输入/隐藏/输出层 | 接特征 / 抽特征 / 出结果 | 进-加工-出 |
| 神经元 | 加权求和 + 偏置 + 激活函数 | 一扇加工窗口 |
| 权重 w / 偏置 b | 连接的重要程度 / 灵活性偏移量 | 音量 / 偏移 |
| 激活函数 | 引入非线性的变换（`tanh`/`ReLU`） | 让曲线能弯 |
| 前向传播 | 输入→逐层→预测→算损失 | 接力棒 |
| BP 反向传播 | 误差倒着传回去，谁错得多谁改得多 | 倒着追责 |
| 学习率 | 每次权重更新的步长 | 步幅 |

### 关键代码速查

```python
import numpy as np
u = np.linspace(-2, 2, 200)
y_true = 0.5*np.sin(2*u) + 0.3*u      # 非线性目标函数（曲线）

class MLP:  # 1 -> 16 -> 1
    def __init__(self, n_hidden=16, lr=0.001):
        self.w1 = np.random.randn(1, n_hidden)*np.sqrt(2.0)
        self.b1 = np.zeros((1, n_hidden))
        self.w2 = np.random.randn(n_hidden, 1)*np.sqrt(2.0/n_hidden)
        self.b2 = np.zeros((1, 1));  self.lr = lr
    def forward(self, X):
        z1 = X @ self.w1 + self.b1
        self.a1 = np.tanh(z1)                      # 激活函数
        return self.a1 @ self.w2 + self.b2
    def backward(self, X, y):
        y_pred = self.forward(X)
        dz2 = y_pred - y
        self.w2 -= self.lr * (self.a1.T @ dz2)     # 反传 + 更新
        self.b2 -= self.lr * dz2.sum(axis=0)
        dz1 = (dz2 @ self.w2.T) * (1 - self.a1**2)
        self.w1 -= self.lr * (X.T @ dz1)
        self.b1 -= self.lr * dz1.sum(axis=0)
        return y_pred

net = MLP()
for epoch in range(5000):                          # 训练 5000 轮
    y_pred = net.forward(u.reshape(-1,1))
    loss = ((y_pred - y_true.reshape(-1,1))**2).mean()
    net.backward(u.reshape(-1,1), y_true.reshape(-1,1))
```

> 学习率 0.01+ 容易发散成 `nan`，本讲统一用 `0.001`；**一次只调一个参数，控制变量**。
