## 二、导入与回顾（8 分钟）

第1讲，你的程序只会做一件事：`print` 显示固定文字。

**开场提问：**
> "如果我想让程序定义一个'年龄'，再把它算一下、显示出来，该怎么办？"

引出本讲核心：程序要能**存数据（变量）**、**认类型**、**做运算**。这三件事，就是今天的三条主线。

```python
age = 21            # 先把 21 存进变量 age
print(age + 1)      # 再把它拿来算 → 输出 22
```

> 一句话预告：**变量负责"存"，类型负责"认"，运算符负责"算"。**

## 三、环节一：变量与常量（12 分钟）

### Step 1 变量 = 贴了标签的盒子

变量是**存放数据的名字**，可以随时换内容。

```python
name = "小明"      # 把字符串"小明"装进变量 name
age = 21           # 把整数 21 装进变量 age
name = "小红"      # 重新赋值：盒子里换成了"小红"
print(name)        # 输出 小红（现在是新值）
```

**关键：Python 是"赋值即定义"** —— 你第一次给名字赋值，变量就被定义了，**不需要提前声明类型**（这就是它和 C 的一大区别）。

### Step 2 命名规范（写了就要养成习惯）

```python
student_name = "小明"     # ✅ 小写下划线（snake_case）—— Python 推荐
StudentName = "小红"      # ⚠️ 能用，但不规范（那是类名的写法）
studentName = "小刚"      # ⚠️ 能用，但英文一般不用驼峰
2name = "错"              # ❌ 不能以数字开头
class = "错"              # ❌ 不能用关键字（保留字）
```

**三条铁律**：
1. 由字母、数字、下划线组成，不能以数字开头
2. 不能是 Python 关键字（`if`、`for`、`class`……）
3. **见名知意**：`age` 比 `a` 好，`student_name` 比 `n` 好

### Step 3 常量：约定不改的值

Python 没有真正的"只读常量"，用**全大写命名**做约定：

```python
SPEED_OF_LIGHT = 299792458     # 光速（m/s）—— 全大写，约定不修改
PI = 3.14159
```

> 记忆：常量是"写死而且不会变的值"，全世界都约好用大写提醒自己别改它。

## 四、环节二：基本数据类型与 `type()`（15 分钟）

### Step 1 四种基本类型

Python 里每种数据都有**类型**，类型决定它能做什么运算：

| 类型 | 英文 | 示例 | 说明 |
|---|---|---|---|
| 整数 | `int` | `42`、`-7` | 没有小数点的数 |
| 浮点数 | `float` | `3.14`、`-0.5` | 带小数（"浮点"= 小数点可浮动） |
| 布尔 | `bool` | `True`、`False` | 逻辑真/假（首字母大写！） |
| 字符串 | `str` | `"hello"`、`'你好'` | 用引号括起来的文本 |

### Step 2 用 `type()` 查看类型（重点）

`type(数据)` 会告诉你它是什么类型：

```python
print(type(42))         # <class 'int'>
print(type(3.14))       # <class 'float'>
print(type(True))       # <class 'bool'>
print(type("hello"))    # <class 'str'>

# 看一个变量
x = 10
print(type(x))          # <class 'int'>

x = 3.14                # 重新赋值，类型也跟着变（动态类型）
print(type(x))          # <class 'float'>
```

**易错点**：`'123'`（字符串）和 `123`（整数）**完全不同**——一个是文本字条，一个是能算的数。用 `type()` 就能识破它们。

### Step 3 布尔值小贴士

```python
print(3 > 2)        # True（3 大于 2，成立）
print(3 < 2)        # False
print(True + True)  # 2 ？布尔参与运算时 True 当 1 —— 先知道即可，别这么写
```

> 布尔值现在是"认识一下"，真正的逻辑判断在第6讲 `if`。现在只要能说出 `type(True)` 是 `bool` 即可。

## 五、环节三：运算符与表达式（10 分钟）

### Step 1 算术运算符

| 运算符 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `+` | 加 | `7 + 3` | `10` |
| `-` | 减 | `7 - 3` | `4` |
| `*` | 乘 | `7 * 3` | `21` |
| `/` | 除（结果是小数） | `7 / 2` | `3.5` |
| `//` | 整除（丢掉小数） | `7 // 2` | `3` |
| `%` | 取余 | `7 % 2` | `1` |
| `**` | 幂 | `2 ** 10` | `1024` |

> 记忆口诀：**`//`去掉小数，`%`是除完剩的零头，`**`是几次方。**

### Step 2 表达式与优先级

把数字和运算符组成"表达式"，Python 会算出结果：

```python
print(3 + 4 * 5)      # 23 —— 先乘后加
print((3 + 4) * 5)    # 35 —— 括号优先
print(7 // 2, 7 % 2)  # 3 1 —— 整除与取余成对出现
```

- 优先级：`()` > `**` > `* / // %` > `+ -`（和数学一致，不确定就加括号）
- `%` 最常用场景：判断奇偶（`n % 2 == 0` 是偶数）、取个位数（`123 % 10 == 3`）

### Step 3 字符串与数字能不能 `+`？

```python
print("年龄是" + 21)      # ❌ TypeError: 字符串和整数不能相加
print("年龄是" + str(21))  # ✅ 先转成字符串："年龄是21"
```

> 记住这个报错——它是初学者第一个高频坑。解决办法就是下一个知识点：**类型转换**。

## 六、环节四：字符串索引与分片（20 分钟）⭐本讲重点难点

### Step 1 索引：给每个字符编下号（从 0 开始）

字符串由一个个字符组成，每个字符有个**下标**（索引）：

```python
s = "Python"
#    012345    正向索引（从0开始）
#  -6-5-4-3-2-1  负向索引（从右数）

print(s[0])     # P
print(s[3])     # h
print(s[-1])    # n  ← 负索引：倒数第1个（最常用）
print(s[-3])    # t  ← 倒数第3个
```

**两个最常背的下标：**
- `s[0]` —— 第一个字符
- `s[-1]` —— 最后一个字符

> 易错点：下标越界会报错。`"Python"` 长度是 6，最大正索引是 `s[5]`，`s[6]` 报 `IndexError`。

### Step 2 分片：掐出字符的一段（含头不含尾）

语法 `s[开始:结束]`，截取从`开始`到`结束`往左一个的**一段**：

```python
s = "Python"

print(s[1:4])     # yth   （下标1、2、3，不含4）
print(s[0:3])     # Pyt   （下标0、1、2）
print(s[:3])      # Pyt   （从头开始，可省略0）
print(s[3:])      # hon   （到末尾，可省略结束）
print(s[:])       # Python（全取）
```

> ⭐ 最重要的规则：**分片"含头不含尾"** —— `s[a:b]` 取下标 `a` 到 `b-1`。这是本讲必须刻进脑子的规则。

### Step 3 步长：隔几个取一个

第三个参数是**步长**，默认是 1：

```python
s = "Python"
print(s[::2])     # Pto   （隔一个取一个，下标0、2、4）
print(s[1::2])    # yhn   （从下标1开始隔一个取一个，取1、3、5）
```

### Step 4 逆序：`s[::-1]`（最经典用法）

**步长为负数，就倒着走**。`s[::-1]` 意义是"步长-1，倒着取全部"：

```python
s = "Python"
print(s[::-1])    # nohtyP   ← 字符串反转！高频考点
```

> 记忆：**想要逆序，就写 `[::-1]`**。它背下来就是"几秒钟反转一个字符串"。

用一个总表收口（写进笔记本）：

| 写法 | 结果（s="Python"） | 说明 |
|---|---|---|
| `s[0]` | `P` | 第一个字符 |
| `s[-1]` | `n` | 最后一个字符 |
| `s[1:4]` | `yth` | 含头不含尾 |
| `s[:3]` | `Pyt` | 从头开始 |
| `s[3:]` | `hon` | 到末尾 |
| `s[::2]` | `Pto` | 隔一个取一个 |
| `s[::-1]` | `nohtyP` | **逆序** |

## 七、环节五：类型转换 `int()/float()/str()`（并入随堂练习前快速带过）

上节 STEP 3 的报错靠它解决。三个"翻译官"：

```python
int("100")      # 100    字符串→整数
float(5)        # 5.0    整数→浮点数
str(100)        # "100"  数字→字符串
int(3.9)        # 3      ⚠️ 直接砍掉小数，不是四舍五入！

print("岁数" + str(21))   # 岁数21  拼接成功
print(int("100") + 1)     # 101     先转整数再算
```

> 注意：`int(3.9)` 得 `3` 而不是 `4`——`int()` 是**截断**小数部分；要四舍五入用 `round()`。`int("3.5")` 也会报错（字符串转整数不能带小数点）。
