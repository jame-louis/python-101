### 1. Python 是什么

Python 是一门**解释型、通用**的编程语言，由荷兰人 Guido van Rossum 于 1991 年发布。它的名字来自英国喜剧团体"Monty Python"，和蛇没有关系 🐍。

**为什么全世界都在学 Python？三个理由：**
1. **语法简单，贴近自然语言** —— 新手友好，读起来像英文句子
2. **生态强大** —— 人工智能、数据分析、Web 开发、自动化都有现成库
3. **应用极广** —— 下图是它的主要战场

| 领域 | 例子 |
|---|---|
| 人工智能/机器学习 | 人脸识别、ChatGPT 背后的模型训练 |
| 数据分析 | 处理表格、画图、统计 |
| 网络爬虫 | 自动采集网页数据 |
| Web 开发 | Django / Flask 搭建网站 |
| 自动化办公 | 批量重命名文件、生成报表 |

### 2. 解释型语言 vs 编译型语言（对比 C）

> 记住这个对比，它决定了你"写代码→运行"的方式。

| | 解释型（Python） | 编译型（C） |
|---|---|---|
| 运行方式 | 解释器**逐行**边翻译边执行 | 先整体编译成机器码，再运行 |
| 流程 | 写代码 → 直接运行 | 写代码 → 编译 → 运行 |
| 修改后 | 改一行立即重跑 | 需要重新编译 |
| 类比 | 翻译员"边走边译" | 整本书先翻好再读 |
| 上手难度 | 低 | 相对高 |

**一句话**：Python 让你"写完立刻看到结果"，非常适合学习和快速开发。

## 三、环节一：搭建开发环境（20 分钟）

> 目标：让 Python 在你自己的电脑上"跑"起来。**按步骤来，别跳步。**

### Step 1 安装 Python 解释器

1. 打开官网 <https://www.python.org>，进入 **Downloads**
2. 下载当前稳定版（Python 3.10+）
3. 安装时**务必勾选** "Add Python to PATH"（否则命令行找不到 python）
4. 完成安装

> 💡 若电脑是 macOS，通常系统自带 `python3`，可先跳过安装，直接验证（Step 3）；若提示没有，再用官网安装包。

### Step 2 安装 VSCode（编辑器）

1. 打开 <https://code.visualstudio.com>，下载并安装
2. 打开 VSCode，左侧扩展栏搜索 **Python**，安装微软官方扩展（发布者 microsoft）
3. 新建一个文件 `demo_01_first.py`（先建一个自己课程用的文件夹，如 `python101/`）

### Step 3 验证安装（关键一步）

打开终端（macOS 为"终端/Terminal"，Windows 为"命令提示符/PowerShell"），输入：

```
python3 --version      # macOS/Linux
python --version       # Windows
```

- 看到 `Python 3.x.x` → ✅ 环境 OK
- 提示"command not found" / 不是内部命令 → 回到 Step 1，检查 PATH

> 常见卡点：
> - 终端和 VSCode **都重开一次**，才生效安装的 PATH
> - Windows 上可能要选 `python`，macOS/Linux 上可能要用 `python3`

### Step 4 确认 VSCode 选中了解释器

1. 在 VSCode 打开 `.py` 文件
2. 看右下角是否显示版本号（如 `Python 3.11.5`）
3. 没显示 → 按 `⌘+Shift+P`（Mac）/ `Ctrl+Shift+P`（Win），输入 `Python: Select Interpreter`，选择你的解释器

## 四、环节二：编写并运行第一个 Python 程序（20 分钟）

### Step 1 认识 `print()` —— "喊话"函数

`print()` 是 Python 的**输出函数**：把括号里的内容"打印"到屏幕上。

```python
print("Hello, World!")        # 输出字符串
print("Hello Python!")
```

> 记忆：`print()` 就像一个"喇叭"，把里面的话喊出来。

### Step 2 运行程序（脚本模式）

把上面两行写进 `demo_01_first.py`，然后运行：

```
python3 demo_01_first.py      # macOS/Linux
python demo_01_first.py       # Windows
```

预期输出两行：

```
Hello, World!
Hello Python!
```

> ✅ 看到这两行，说明：环境装好了 + 程序写对了 + 你会运行了。

### Step 3 交互模式 vs 脚本模式（进阶认识）

在终端输入 `python3` 回车，进入**交互模式（REPL）**——逐行输入、立即出结果：

```python-repl
>>> 1 + 2
3
>>> "AB" * 3
'ABABAB'
>>> exit()        # 退出
```

| 模式 | 怎么用 | 适用场景 |
|---|---|---|
| 脚本模式 | 写 `.py` 文件，`python3 文件名.py` 运行 | 正式写程序 |
| 交互模式 | 终端输入 `python3`，逐行敲 | 快速试一行命令 |

> 实践建议：正式作业用**脚本模式**（可提交），平时试验一行命令用**交互模式**。

### Step 4 小实验：算一算

```python
print(1 + 2)          # 输出 3（数字直接算出结果）
print("AB" * 3)        # 输出 ABABAB（字符串可以重复）
print(7 / 2)           # 输出 3.5（除法）
print(7 // 2)          # 输出 3（整除，去掉小数）
print(2 ** 10)         # 输出 1024（2 的 10 次方）
```

对照注释，自己跑一遍，观察数字和字符串的"行为"差异——这为你下节课理解**数据类型**做铺垫。

### 4. 看懂评测结果（最重要）

| 状态 | 含义 | 怎么办 |
|---|---|---|
| 🔴 Accepted (AC) | 全部通过 | 庆祝 🎉 |
| ❌ Wrong Answer (WA) | 答案不对 | 检查输出格式（多空格/少换行最常见）、边界 |
| ⚡ Runtime Error (RE) | 运行崩溃 | 除零、下标越界、读入格式不对 |
| 🚫 Compile Error (CE) | 编译失败 | 语法错，或语言选错 |
| ⏳ Judging | 排队评测中 | 等几秒刷新 |

**WA 时别瞎改** —— 先自己造几组输入，用"样例思维"手算，对比你的输出和期望输出。

### 5. 一次必须避免的坑

> 本地演示前，删除 `input("请输入")` 之类所有**提示语**。评测机只看标准输出，多余输出全是 WA。

## 附录 · Hydro 使用 FAQ 速查（课上带过，课后查阅）

**Q1 登录提示"用户名或密码错误"？**
检查用户名是不是学号全称（含 `stu` 前缀）、有无多余空格。三次失败稍等再试，还不行找老师重置。

**Q2 提交没反应/一直转圈？**
换 Chrome；检查代码里有没有中文标点（复制代码最容易带入中文引号、全角分号）；网络卡就多等几秒。

**Q3 本地跑对，交上去 WA？**
99% 是没读清题：检查输入是不是多组数据（直到 EOF）、输出格式（一行一个 vs 空格分隔）；本地只测了样例，没测边界。

**Q4 一直 Waiting/Judging？**
高峰期排队，正常 < 1 分钟，超过 5 分钟截图找老师。

**Q5 能不能用 `numpy` / 第三方库？**
评测机默认只装标准库；特殊库需老师预先安装在评测机，请联系老师确认。

**诚信提醒**：系统有查重，相似度过高的代码双方都会被标记；可以讨论思路，但代码必须自己写；不要尝试攻击评测系统，按作弊处理并记录档案。
