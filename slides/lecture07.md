## 第一幕 · 遍历 for

<!-- 转场
讲者备注：【转场】幕卡,淡入切幕。一句话预告本幕:有一个明确的清单时,用 for 挨个过一遍。清单可以是列表、字符串,也可以是 range() 生成的整数序列。 -->

---

# 有个清单，就挨个过一遍

```python
nums = [3, 1, 4, 1, 5]
for n in nums:          # n 依次是 3,1,4,1,5
    print(n * n)        # 输出 9 1 16 1 25
```

> 遍历字符串也一样：`for ch in "Python": print(ch)`

<!-- 讲者备注：【特写】建立"for=逐个遍历"的直觉。变量 n 依次接住清单里的每个元素,循环体执行一遍。与 C 习惯对比:C 是按下标 i 一个个取,Python 是直接把元素捞出来。口诀:一个清单,for 挨个过;不需下标,要下标再说。 -->

---

# range()：点名后挨个发

```python
range(5)          # 0,1,2,3,4   （差1缺尾）
range(2, 9, 2)    # 2,4,6,8     （起始、终止不含、步长）

total = 0
for i in range(1, 101):   # 1 到 100
    total += i
print(total)              # 5050
```

<!-- 讲者备注：【特写】range() 是 for 的"发号员",批量生成整数序列。三个坑先钉死:差 1 缺尾(前闭后开)、起始/终止/步长三参、一定要 range(1,n+1) 才到 n。例题回到开场那个笨算题:一个 for 一秒钟交出 5050。 -->

## 第二幕 · 条件 while

<!-- 转场
讲者备注：【转场】幕卡,淡入切幕。一句话预告本幕:清单不明确、数据要一直读到结束时,用 while 这种"跑到条件为止"的循环。三大要素、break/continue、还有死循环这条安全线全在这幕。 -->

---

# 三个要素，缺一个就"卡死"

```python
while 条件:      # 只要条件为真就不断执行
    循环体
```

- **初值**：循环变量从哪出发
- **条件**：什么情况下继续
- **更新**：每圈结束后怎么改条件变量

<!-- 讲者备注：【全景】while 三要素扳手:初值、条件、更新。while 不是"遍历清楚",而是"跑到条件不成立"。三要素缺一即为死循环——条件恒真又不变,程序就永远卡在那。教学:先口头问"这段 while 会跑几遍?"再揭晓。 -->

---

# 读到结束标记为止

```python
total = 0
while True:                 # 无限循环
    x = int(input("输入整数(输入-1结束)："))
    if x == -1:             # 用标记值结束
        break
    total += x
print("总和 =", total)
```

> `while True + break`：不知道数据有几句时的标准读法

<!-- 讲者备注：【特写】现实中常"读到何时结束不知道",于是先 while True,再用标记值(如 -1)配合 break 主动跳出。这是"读数据直到结束"的标配。让同学注意:若不写 break,这程序就永远转下去——下一镜接着讲这有多危险。 -->

---

# ⚠️ 死循环，就是恶意代码

**死循环** = 条件恒真且无 `break`，无限执行、耗尽 CPU 卡死程序。

- **挖矿脚本**：挂机循环把 CPU 抽干
- **勒索程序 / 锁机木马**：无限循环拒绝服务
- **蜂拥攻击**：循环把资源层层拖垮

<!-- 讲者备注：【思政】从"受控"跳到"失控":同样一段循环,有明确终止就安全,失控就是攻击武器。类比恶意代码三连:挖矿、锁机、耗尽资源。落点一句:写出能正确终止的循环,就是最基础的信息安全防护。让同学讨论"控制权在人 vs 漏洞被滥用"。 -->

# break / continue：两个刹车手

```python
for i in range(1, 7):
    if i == 5:
        break            # 到 5 就停
    print(i, end=" ")    # 1 2 3 4

for i in range(1, 7):
    if i == 3:
        continue         # 跳过 3
    print(i, end=" ")    # 1 2 4 5 6
```

<v-clicks>

- `break`：**跳出整个当前层**循环 → 搜索"找到就停"
- `continue`：**跳过本次**剩余，直接进下一圈 → 过滤"不要的"

</v-clicks>

<!-- 讲者备注：【特写】两个刹车手分清就够:break 是急刹、整个循环停;continue 是跳一圈、还接着跑。v-click 逐条点:先讲 break"到 5 就停",再讲 continue"跳过 3"。多问一句:两个都只作用于"当前层",嵌套里别串台。 -->

---

# 🤖 AI 赋能：按"损失值"掌管训练节奏

模型训练的本质就是**迭代循环**，用 `break`/`continue`/条件动态进退：

```python
loss = 1.0
for epoch in range(1000):
    loss = train_one_epoch(epoch)   # 假想的一轮训练
    if loss < 0.001:                # 损失到阈值 → 提前收敛停训
        print("已收敛，提前停止")
        break
    if loss > 10:                   # 损失爆炸 → 跳过/调整再继续
        continue
```

<!-- 讲者备注：【特写】本课 AI 落点。训练是层层迭代,不是死板跑满 1000 圈:损失够了 break 提前收敛、损失爆了 continue 跳过重来。for 批量遍历数据、break/continue 按损失值动态调整——训练流程的可控,正是一圈圈循环交给我们的。 -->

## 第三幕 · 嵌套与追踪

<!-- 转场
讲者备注：【转场】幕卡,淡入切幕。一句话预告本幕:一个循环套另一个循环会发生什么?学会"变量追踪表",再复杂的嵌套输出都能一眼预判。 -->

---

# 嵌套循环：外层一次，内层一整轮

```python
for i in range(1, 5):          # 外层：行
    for j in range(1, i + 1):  # 内层：每行打印 i 个
        print("*", end="")
    print()                    # 内层结束后换行
```

输出：

```
*
**
***
****
```

<!-- 讲者备注：【特写】关键心智模型:外层每变一次,内层要完整跑一整遍。这里外层 i 定行、内层 j 定列且列数=i,构成下三角。别急着看结果,先建立"外层一次、内层一轮"这句话。 -->

---

# ❗难关：变量追踪表

外层变量每次一换，内层就重新走一遍。盯两件事：**外层一次、内层一轮**。

`for i in range(1,4):  for j in range(i):  print(i,j)`

| 外层 i | 内层 j 遍历 | 本轮输出 | 执行次数 |
|---|---|---|---|
| 1 | 0 | (1,0) | 1 次 |
| 2 | 0,1 | (2,0)(2,1) | 2 次 |
| 3 | 0,1,2 | (3,0)(3,1)(3,2) | 3 次 |

> 规律：外层改一次，内层完整跑一遍。**先画追踪表，再谈输出。**

<!-- 讲者备注：【难点】全讲最难的镜,务必逐行演算。外 i 换一次、内 j 从初值重走,输出的其实是 (i,j) 组合。表格按行 v-click:先填 i=1 一行,再 i=2、i=3。引导学生发现"每行长度=行号"。口诀:先画表,别嘴硬硬猜输出。 -->

---

# 终极援手：九九乘法表

```python
for i in range(1, 10):            # 外层：行
    for j in range(1, i + 1):     # 内层：列，只到 i
        print(f"{j}*{i}={i*j}", end="  ")
    print()                       # 每行结束换行
```

- 外层 `i` 控行、内层 `j` 控列，列数由当前行 `i+1` 决定
- 改边界 / 列范围，就能变出三角形、上三角等花样

<!-- 讲者备注：【特写】把变量追踪用到熟例上:外 i 行、内 j 列且到 i 停,构成下三角。让学生对照上一镜的追踪表,先口头预判第一行第二行分别打印什么,再揭晓。这是把"追踪"二字真正用熟。 -->

---

# 五个坑，踩一个算我输

| 想干嘛 | 坑 | 对的做法 |
|---|---|---|
| 循环到 n | `range(n)` 少一项 | `range(1, n+1)` |
| 程序卡死 | `while` 忘了更新条件 | 初值/条件/更新；`Ctrl+C` |
| 乘法表列数 | 分不清外层 i / 内层 j | 先画变量追踪表 |
| 只用 break 跳一层 | 嵌套循环只停当下层 | 只作用于当前层 |
| 想按下标取 | `for n in list` 拿到的是元素 | `range(len(list))` / `enumerate` |

<!-- 讲者备注：【全景】五个真实坑速查:range 差 1 缺尾、while 忘更新变死循环、嵌套里 break 只停一层、以及"拿了值却想要下标"。每个都能先抛错代码让学生猜,再给正解。它们是评论区报错的高发区。 -->

# 结课：循环，是批量处理的入场券

> 要清单遍历用 `for`，要跑到停在用 `while`，
> 要提前刹车 `break`，要跳圈继续 `continue`——
> 能写、能停、能停停进进，才算真会循环。
