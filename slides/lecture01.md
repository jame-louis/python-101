# 三个理由：为什么全世界都在学

1. **语法简单** —— 读起来像英文句子，新手友好
2. **生态强大** —— AI/数据分析/Web 都有现成库
3. **写完立刻能跑** —— 改一行，重跑就是

| 语言 | 运行方式 | 类比 |
|---|---|---|
| 解释型（Python） | 逐行边翻译边执行 | 翻译员边走边译 |
| 编译型（C） | 先整体编译再运行 | 整本书先翻好再读 |

# 四步装好：解释器 + 编辑器

```bash
# ① 装 Python 解释器  python.org → Downloads
#    ⚠️ 安装时务必勾选 "Add Python to PATH"

# ② 装 VSCode  code.visualstudio.com
#     扩展栏搜索 Python（微软官方版）

# ③ 验证（关键一步）：
python3 --version      # macOS/Linux
python --version       # Windows
```

- 看到 `Python 3.x.x` → ✅ 环境 OK
- "command not found" → 检查 PATH，重启终端再试

<!-- 讲者备注：【特写】按步骤 ①②③ 走。很多人卡在 PATH，重点强调"Add to PATH"和"重开终端"两件事。完成后一定要 `python3 --version` 自我验证，否则不进入下一幕。 -->

# 让 VSCode 认识你的 Python

1. VSCode 打开 `.py` 文件
2. 看右下角是否显示版本号（如 `Python 3.11.5`）
3. 没有 → `⌘+Shift+P` / `Ctrl+Shift+P`
   输入 `Python: Select Interpreter` 选解释器

> 先建一个自己的课程文件夹，比如 `python101/`，所有代码都放里面。

<!-- 讲者备注：【全景】选解释器是"编辑器能跑 Python"的前提，很多人忽略。一句话带过即可，但必须做，否则下一步 print 跑不起来。 -->

# 交互模式 vs 脚本模式

```python
>>> 1 + 2            # 交互模式里逐行输入、立即出结果
3
>>> "AB" * 3
'ABABAB'
>>> exit()           # 退出交互模式
```

| 模式 | 用法 | 适用 |
|---|---|---|
| 脚本模式 | 写 `.py` 文件 `python3 文件名.py` | 正式写程序、可提交 |
| 交互模式 | 终端 `python3` 逐行敲 | 快速试一行命令 |

<!-- 讲者备注：【全景】两种模式是初学者最常见的困惑。给一句口诀：# 正式作业用脚本，# 试单行命令用交互。# 都记住即可。 -->

---

# 小实验：算一算（为下节课铺路）

```python
print(1 + 2)          # 3     数字直接算出结果
print("AB" * 3)        # ABABAB 字符串可以重复
print(7 / 2)           # 3.5   除法
print(7 // 2)          # 3     整除，去掉小数
print(2 ** 10)         # 1024  2 的 10 次方
```

> 数字和字符串的"行为"不一样 → 这就是下节课的**数据类型**

<!-- 讲者备注：【特写】借运算拉出"数字 vs 字符串行为不同"，埋下"数据类型"的钩子，衔接第2讲。也是第一次让学生看"程序能算数"。 -->

<!-- 讲者备注：【全景】三个动作串成一条流水线。最关键两个坑：忘切课程域看不到作业；带提示语的 input 被判 WA。 -->

---

# 看懂评测结果

| 状态 | 含义 | 怎么办 |
|---|---|---|
| 🔴 AC | 全部通过 | 庆祝 🎉 |
| ❌ WA | 答案不对 | 查输出格式（多空格/少换行）、边界 |
| ⚡ RE | 运行崩溃 | 除零、下标越界、读入格式错 |
| 🚫 CE | 编译失败 | 语法错 或 语言选错 |
| ⏳ Judging | 排队中 | 等几秒刷新 |

> **WA 别瞎改**——先自己造几组输入，手算对比，再动手。

<!-- 讲者备注：【特写】把状态表讲成"诊断地图"。核心强调 WA 时的动作：造样例、手算、比对，而不是乱试。这决定后面 15 讲做作业的姿势。 -->
