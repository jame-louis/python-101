# 从单人座位，到一排座位

```python
score = 88                    # 单个变量
scores = [78, 88, 95, 66]     # 一个列表装多个分数
```

> "一整个班的名字，怎么办？" → 交给列表

<!-- 讲者备注：【全景】建立"为什么要列表"的直觉:变量=单人座位,一次只坐一个;列表=一排座位,坐一整个班。一个变量拎一个数,一个列表拎一袋。口号句:变量装一个,列表装一袋。 -->

# 下标从 0 开始，负数从右数

```python
nums  = [1, 2, 3, 4]        # 整数列表
names = ["Alice", "Bob"]    # 字符串列表
mix   = [1, "A", 3.14]      # 可混型列表
empty = []                  # 空列表

print(nums[0])     # 1       下标从 0 开始
print(names[-1])   # 'Bob'   负数下标从右数
print(len(nums))   # 4       元素个数
```

<!-- 讲者备注：【特写】列表三大基本功:下标从 0 起、负下标从右数、len 数个数(像数座位数)。教学提示:先让同学口猜 nums[-1] 和 len() 的输出,再运行揭晓。 -->

---

# 增删改齐了，列表才真的"活"

```python
scores = [78, 88, 95]
scores[1] = 99        # 改：把下标1换成99
scores.append(100)    # 增：末尾追加一个元素
scores.remove(78)     # 删：删除值78（第一个匹配）
popped = scores.pop() # 弹：弹出并返回末尾元素
print(scores)         # [99, 95]
```

<!-- 讲者备注：【特写】"活"= 能在原列表上动刀子:增 append、删 pop、改 下标赋值,全部原地生效、不用重新赋值。这正是"可变(mutable)"的第一现场。教学提示:口头强调这些操作不改变量名指向,对象本体被改。 -->

---

# ⭐ append / extend / insert：三种"塞进去"

```python
lst  = [1, 2, 3]
lst.append(4)          # 塞单个   → [1,2,3,4]
lst2 = [1, 2, 3]
lst2.extend([4, 5])    # 展平拼   → [1,2,3,4,5]
lst3 = [1, 2, 3]
lst3.insert(1, 99)     # 插中间   → [1,99,2,3]
```

<v-clicks>

- append 塞"一个"，extend 展平"一串"
- insert 找准"位置"，可插中间
- ⚠️ `lst.append([4,5])` 是塞"整体" → `[1,2,3,[4,5]]`

</v-clicks>

<!-- 讲者备注：【特写】全讲最难镜,务必逐条讲。一句口诀:append 塞一个、extend 展平拼一串、insert 找准位置插。⚠️ 易错:append([4,5]) 把整个列表当单个元素塞进去,变成 [1,2,3,[4,5]],不是展开。教学:逐条 v-click,讲一条点一条,先猜结果再揭晓。 -->

# 采样本：一个 append 一个样本

for i in range(1, 6):
    dataset.append(f"img_{i:03d}.jpg")

# 含头不含尾，一次记死

```python
nums  = [10, 20, 30, 40, 50]
print(nums[1:4])     # [20,30,40]   含头不含尾
print(nums[:3])      # [10,20,30]   从头到位置3
print(nums[::2])     # [10,30,50]   步长为2
print(nums[::-1])    # 反转整张列表
```


---

# for：最常用的批处理咒语

```python
for name in ["Alice", "Bob", "Cathy"]:
    print(name)

for i, name in enumerate(names):
    print(i, name)

squares = [x * x for x in range(1, 6)]
```

<!-- 讲者备注：【全景】三种批处理:直接遍历值、enumerate 带下标、列表推导式一键生成新列表。for x in list 是整个 Python 最常用的批处理方式,后面两幕的 AI 落地都靠它。 -->

---

# sort() 原地动手，sorted() 返回新表

```python
losses = [0.9, 0.4, 0.6, 0.2, 0.7]
losses.sort()                # 原地升序
print(losses)                # [0.2, ..., 0.9]

losses.sort(reverse=True)    # 原地降序
sorted(losses)               # 返回新列表,原表不动
```

<!-- 讲者备注：【特写】sort vs sorted 一字之差:sort 改原列表(sorted 也支持 reverse);sorted 不动原表、返回一份新的。节点:字符串按字母序。为什么在意?背后仍是可变/不可变那根线。 -->

---

# 把损失排一排，收敛一眼见

```python
epoch_losses = [1.2, 0.8, 0.6, 0.3, 0.2]
stable = sorted(epoch_losses)        # 不看顺序,看数值分布
print("最低损失:", stable[0])         # 0.2

epoch_losses.sort(reverse=True)      # 降序看收敛趋势
print(epoch_losses)
```

<!-- 讲者备注：【特写】训练日志的损失收成列表再排:最低值=stable[0];降序排列直观看到训练往低处收敛。为什么用 sorted 而非 sort?因为还要保留训练回合的原顺序表。应用思路:把"每轮损失"变列表 → 排序 → 快速看最低值与收敛趋势。 -->

## 第三幕 · 锁住不动的数据

<!-- 转场
讲者备注：【转场】幕卡,淡入切幕。一句话预告本幕:列表会动,但有些数据我们不想让它动——元组就是那把"锁"。 -->

---

# 不能改的，反而是最稳的

```python
t = (1, 2, 3)
t2 = ("apple",)       # 单个元素必须有逗号!
print(t[0])           # 1
a, b, c = t           # 元组解包,一次拆三份
```

<!-- 讲者备注：【特写】元组两大招牌:单元素要有逗号(t = (5,) 否则是普通 int);解包 a,b,c = t 一次拆三份。其余(下标/切片)和列表一样,唯一的区别是"不能改"。 -->

---

# 给数据上一把"锁"

```python
lst = [1, 2, 3]
lst[0] = 99          # ✅ 列表可以改
print(lst)           # [99, 2, 3]

t = (1, 2, 3)
t[0] = 99            # ❌ TypeError: 'tuple' object ...
```

> 需要保护、不许被意外改动的数据 → 交给元组

<!-- 讲者备注：【特写】"可不可以改"是全课灵魂。列表可变、可重新赋值;元组不可变,一改就炸 TypeError。别把它当缺陷:要防误改/当字典键/省内存的数据,元组更稳。口诀:想改用 list,想锁用 tuple。 -->

---

# 一边遍历，一边清洗

```python
raw_texts = ["Hello", "WORLD", "python"]
cleaned = []
for text in raw_texts:
    cleaned.append(text.lower())
print(cleaned)                   # ['hello','world','python']

nouns = ("cat", "dog", "bird")   # 只读常量表
```

<!-- 讲者备注：【特写】list 装"要改的原料"+ tuple 装"只读的词表",同一幕两种类型各司其职。遍历 + 转小写批量生成干净语料,是 NLP 预处理的常用动作。应用思路:一条条清洗文本,统一格式 → 干净语料。 -->

# 五个坑，踩一个算我输

| 想干嘛 | 坑 | 对的做法 |
|---|---|---|
| 列表想接 [4,5] | `append([4,5])` → `[1,2,3,[4,5]]` | 用 `extend([4,5])` |
| 改元组 | `t[0]=99` → TypeError | 改用列表，或元组只读 |
| 下标越界 | `nums[5]` 但只有 4 个 | 先看 `len`，或遍历 |
| 写单元素元组 | `t=(5)` 其实是 int | 写 `t=(5,)` |
| 保留原列表排序 | `sort()` 原地改掉了 | 用 `sorted()` |

<!-- 讲者备注：【全景】五个真实坑速查,评论区最常见的报错现场。每个坑都可以讲成小段子:先抛出错误代码让同学找错,再给正解。排序这栏呼应第二幕的 sort/sorted;元组这栏呼应第三幕的"锁"。 -->
