## 第一幕 · 取消重复

<!-- 转场
讲者备注：【转场】幕卡,淡入切幕。一句话预告本幕:一堆数据里全是重复,我们要先学会"一键去重",再学会集合之间的交并差运算。 -->

---

# 只收不重复的收纳盒

```python
tags = {"体育", "科技", "游戏", "体育", "科技"}
print(tags)          # {'体育', '科技', '游戏'}
                     # └─ 重复自动去掉、顺序不定
```

> 重复的，放一个就够

<!-- 讲者备注：【全景】建立"集合=收纳盒"的直觉:像只收独特物品的盒子,再塞重了自动丢。两大特征先立住——无序(没有先后、不能 s[0])、不重复(去重是本讲最大价值)。口诀:装盒子,一只一件,放重了自动丢。 -->

---

# 和列表、元组站一起比一比

| 类型 | 顺序 | 允许重复 | 可否下标 |
|---|---|---|---|
| list | 有 | 可以 | `l[0]` |
| tuple | 有 | 可以 | `t[0]` |
| **set** | **无** | **不可以** | **不可以** |

<!-- 讲者备注：【全景】一眼看三分:列表/元组按序存、可重复、有下标;集合全反过来——无序、不可重复、无下标。适用场景立刻分家:要顺序用 list,要固定只读用 tuple,要去重和交集用 set。 -->

---

# 增删改，外加四种"算账"

```python
s = set()              # 空集合 注意 {} 是空字典
s.add("a")             # 增,重复不生效
s.discard("b")         # 删,不存在也不报错

A = {"体育", "科技", "音乐"}
B = {"科技", "游戏"}
print(A & B)   # 交集  {科技}
print(A | B)   # 并集  {体育,科技,音乐,游戏}
print(A - B)   # 差集  {体育,音乐}
```

<!-- 讲者备注：【特写】集合基本功 + 三张"牌":&(交集=两边都有)、|(并集=合起来去重)、-(差集=只属于 A 的)。运算符直观,对应方法 intersection/union/difference 记住同名即可。教学:口头先问 A&B 是多少,再点运行揭晓。 -->

---

# 海量数据去重，一行见底

```python
raw = ["A", "B", "A", "C", "B", "A"]
unique = sorted(set(raw))
print(unique)          # ['A', 'B', 'C']

userA = {"电子", "游戏", "运动"}
userB = {"运动", "摄影", "电子"}
print(userA & userB)   # 共同兴趣 {运动, 电子}
```

<!-- 讲者备注：【特写】两处真落地:①清洗——所有日志塞进 set,重复自动蒸发,再 sorted 变回有序列表,推荐/统计立刻干净;②找共同兴趣——两群用户标签取交集,一条 & 把"两边都爱"捞出来。应用思路:set 是数据清洗时最快的那把整列刀。 -->

## 第二幕 · 按名算账

<!-- 转场
讲者备注：【转场】幕卡,淡入切幕。一句话预告本幕:去重学完了,现在给每一份数据配一个"名字",让取值能叫得上号——键→值。四种造法、安全取值都在这幕。 -->

---

# 像电话号码本：按"姓"找"人"

```python
user = {"name": "Alice", "age": 20}
print(user["name"])      # Alice   用键取值
user["age"] = 21         # 改值
user["city"] = "Xiamen"  # 新增键值对
print(user)
```

> 键必须不可变 · 值随便改

<!-- 讲者备注：【全景】字典=电话号码本思维:键(name/age)是"姓",值(Alice/20)是"人"。规则两条钉死:键必须不可变(数字/字符串/元组,列表不行)、键唯一;值可以是任意类型、随便改。口诀:按名取数,键不可改,值可换。 -->

---

# 要名还是要用下标？三条路

| 维度 | 列表 | 元组 | 字典 |
|---|---|---|---|
| 结构 | 有序序列 | 有序序列 | 无序键→值映射 |
| 访问 | `l[0]` | `t[0]` | `d["key"]` |
| 键类型 | 任意 | 任意 | **键须可哈希** |
| 用途 | 按序存一批 | 固定只读 | 按名称查询 |

<!-- 讲者备注：【全景】三种容器分家:列表/元组按下标"按顺序"存取;字典用语义化键"按姓名"查询。典型用途一句话——list 按序存数据、tuple 固定只读序列、dict 按名称映射/配置。这页是三段式决策的基础。 -->

---

# ⭐ 一种字典，四种造法

```python
d1 = dict(name="Alice", age=20)              # ① 关键字参数
d2 = {"name": "Bob", "age": 21}              # ② 字面量最直观
d3 = dict.fromkeys(["x", "y", "z"], 0)       # ③ 批量默认值
keys   = ["sport", "tech", "game"]
values = [10, 20, 30]
d4 = dict(zip(keys, values))                 # ④ 两串配对
```

<v-clicks>

- 字面量 / 关键字：手写最省事
- `fromkeys`：先给一堆键，统统抄一个默认值
- `zip`：先存好两组数据，再双排配对

</v-clicks>

<!-- 讲者备注：【特写】全讲最难镜,务必逐条讲。四招各一句:① dict(name=..) 键是标识符,② {键:值} 手写直接,③ fromkeys(键列表,默认值) 批量发默认值,④ zip(键表,值表) 把两条队伍按位置拼成键值对。教学:逐条 v-click,讲一条点一条;问同学 d3 里 x/y/z 都是几。 -->

---

# 取值得"安全"，遍历分三路

```python
d = {"sport": 10, "tech": 20}

print(d.get("sport"))               # 10
print(d.get("food", "免费默认"))     # 找不到也不报错

for k in d:                print(k)            # 键
for v in d.values():       print(v)            # 值
for k, v in d.items():     print(k, "->", v)   # 键值对
```

<!-- 讲者备注：【特写】两件宝:get 是安全取值,找不到给默认值、不抛 KeyError,是词频统计的地基;遍历三个视角——键(默认)、值 values()、键值对 items()。下一镜的词频统计全靠 d[k] = d.get(k,0) + 1 这一个惯用法。 -->

---

# 数一句台词，各归其位

```python
words = "the apple the banana the apple".split()
freq = {}
for w in words:
    freq[w] = freq.get(w, 0) + 1
print(freq)   # {'the':3,'apple':2,'banana':1}

config = {"learning_rate": 0.01, "epochs": 50,
          "optimizer": "adam", "device": "cuda"}
print(config["optimizer"])   # adam
```

<!-- 讲者备注：【特写】两处 AI 真落地:①词频统计——get 安全取数再 +1,一句惯用法扫描整篇文本,是 NLP 词频/N-gram 的起点;②模型配置——所有超参都塞进字典,用键名读取 config["optimizer"],清晰可扩展。应用思路:字典是"名称→数值"的标准映射,正是配置表的天生容器。 -->

## 第三幕 · 挑对容器

<!-- 转场
讲者备注：【转场】幕卡,淡入切幕。两幕都学完了,最后一幕做"选容器"的总决策:每个 AI 场景该掏哪个容器?顺手把最容易踩的坑一次排干。 -->

---

# 三个场景，三种答案

```python
# 去重清洗        →  集合 set
活动日志去重,只要唯一用户

# 词频统计        →  字典 dict
每个词 → 计数,按名 +1

# 模型配置        →  字典 dict
"learning_rate" → 0.01,按名读取
```

<!-- 讲者备注：【全景】一道"选容器"的决策放大:要唯一值、要交集并集 → set;要按名字推数值、要做映射/配置 → dict;要按顺序存一批 → list;只读固定 → tuple。这页把三幕总账打到一张表,是学会"选对容器,数据才流得顺"的关键收口。 -->

---

# 五个坑，踩一个算我输

| 想干嘛 | 坑 | 对的做法 |
|---|---|---|
| 建空集合 | `{}` 是空字典 | 空集合用 `set()` |
| 取集合元素 | `s[0]` 没下标 | 用 `for` 遍历 |
| 做键/元素 | 列表不可哈希 | 数字/字符串/元组 |
| 键重复 | 后面盖掉前面 | 键要唯一 |
| 取不存在的键 | 报 KeyError | 用 `d.get(k, 默认)` |

<!-- 讲者备注：【全景】五个真实坑速查:空集合陷阱、集合无下标、列表不可哈希(当键会炸)、键重复被覆盖、get 救急没 KeyError。每个都能先抛错代码让学生猜,再给正解。这些是评论区报错现场,值得逐条过。 -->

---

# 结课：选对容器，数据才流得顺

> 要唯一用 set，要映射用 dict，
> 要按序用 list，要只读用 tuple——
> 四口箱子，各装各的货。
