## 第一幕 · 定义与调用

<!-- 转场
讲者备注：【转场】幕卡,淡入切幕。一句话预告本幕:先立"黑盒子"的直觉,再亲手定义并调用第一个函数,最后用圆的面积把"三步走"走一遍。 -->

# 黑盒子：我要的只是"按键 → 结果"

> "你家的电饭煲，需要知道里面有几根发热管吗？"

- 我们要的只是 **输入 → 输出**
- 中间的实现，对我们是一个黑盒子

- **复用**：一段逻辑写一次，到处调用
- **隔离**：改内部实现，不影响调用方

<!-- 讲者备注：【全景】立黑盒子直觉 + 函数的三大理由:复用(一处写、到处调)、清晰(大问题拆小块)、隔离(改内部不影响调用方)。抛一个想一千遍的问题:算圆的面积会写 100 遍公式,还是写 1 个函数调 100 次?这个问题贯穿全课。 -->

---

# def 定义 · return 返回

```python
def 函数名(参数1, 参数2, ...):
    """可选：文档字符串"""
    函数体语句
    return 返回值     # 不写默认返回 None
```

```python
def greet(name):
    return "你好，" + name

msg = greet("小明")   # 调用：传入实参，接收返回值
print(msg)            # 你好，小明
```

<!-- 讲者备注：【特写】把骨架给足再给奶酪。与 C 对比:同样有名字/参数/返回值;不同在——无返回类型、无分号、缩进替代 {}、参数不写类型。一个函数就是一段"按输入产出"的小作坊。 -->

---

# Live Coding：三步走

```python
PI = 3.14159

def area(r):                # ① 定义
    return PI * r * r

a = area(2)                 # ② 调用
print(a)                    # ③ 打印 → 12.56636
print(area(5))              # 78.53975
```

> 同一个黑盒子，换不同的 r，反复用

<!-- 讲者备注：【特写】把"定义→调用→打印"走成三步。强调:函数体不立即执行,定义只是备好一个黑盒子;真正执行在调用那一刻。多次调用 = 黑盒子被反复使用,每次只需换个输入。 -->

## 第二幕 · 四种参数

<!-- 转场
讲者备注：【转场】幕卡,淡入切幕。一句话预告本幕:调用者怎么把"按键"递给函数?四种姿势——按顺序、指名道姓、缺省默认、可变长。越往后越省心,但坑也在变聪明。 -->

---

# 位置 / 关键字 / 默认

```python
def register(name, age, city="厦门", *hobbies, **extra):
    print(name, age, city)

register("小明", 20, "福州")        # ① 位置：按顺序
register("小红", 21, city="泉州")   # ② 关键字：指名道姓
register("小刚", 22, "厦门")        # ③ 默认：city 不传用 "厦门"
```

| 方式 | 写法 | 调用 | 收集 |
|---|---|---|---|
| 位置 | `f(a, b)` | `f(1, 2)` | 按顺序 |
| 关键字 | `f(a=1)` | `f(a=1, b=2)` | 指名道姓 |
| 默认 | `def f(a, b=0)` | `f(1)` | b 用默认值 |

<!-- 讲者备注：【特写】三种常规递参:位置按顺序、关键字指名道姓(顺序可乱)、默认给缺省值。一张速查表一眼看懂。教学:让同学说出 register 第三次调用 city 是多少(厦门),检验默认参数已记住。 -->

---

# *args 与 **kwargs：多出来的账

```python
register("小刚", 22, "厦门", "篮球", "编程")   # 多余的位置 → *hobbies
# 可变位置参数: ('篮球', '编程')   元组

register("小丽", 20, email="li@e.com", 班级="3班")  # 多余的关键字 → **extra
# 可变关键字参数: {'email': ..., '班级': '3班'}  字典
```

- `*args`：把所有多出来的**位置**实参收成一个**元组**
- `**kwargs`：把所有多出来的**关键字**实参收成一个**字典**

<!-- 讲者备注：【特写】可变长是本次最容易懵的镜。*args 兜住"多给的位置参数"变元组, **kwargs 兜住"多给的关键字参数"变字典。一句话:横锅接位置、竖锅接关键字。 -->

---

# ⚠️ 默认参数的老陷阱

```python
def bad(lst=[]):      # ❌ 默认写可变对象
    lst.append(1)
    return lst
print(bad())          # [1]
print(bad())          # [1, 1]  ← 记住了上一次！
```

- 默认参数**只创建一次**，可变对象会"记住"上次修改
- 正解：`def good(lst=None):`，函数内再判断给新列表

<!-- 讲者备注：【思政/特写】默认参数的经典坑。lst=[] 只在定义时求值一次,于是连续调用会累积变长。正确姿势是 None 哨兵。这页是"看似对实则坑"的典型,务必让学生亲手踩一次。 -->

## 第三幕 · 作用域与可变性

<!-- 转场
讲者备注：【转场】幕卡,淡入切幕。一句话预告本幕:参数递进函数后,关键在于"改的是哪一份"——局部还是全局?原件还是复印件?这两个问题是函数易错的高发地。 -->

---

# 随堂判断：g 变了没有？

```python
g = 10

def f():
    g = 99        # 没写 global！

f()
print(g)          # 10，不是 99
```

- 函数内**赋值**同名变量 → 新建**局部**变量，全局 g 不动
- 想改全局，必须声明 `global g`

<!-- 讲者备注：【特写】先抛错再揭晓:函数体里 g=99 没写 global,生成的是局部变量,全局 g 还是 10。口诀:声明在函数体外→全局;函数体内→局部(除非 global)。让学生先写答案再运行,加深'预测再运行'的习惯。 -->

---

# 可变 vs 不可变：原件 vs 复印件

```python
def add(n):            # 不可变 int
    n = n + 10
    return n
num = 5
print(num, add(num))   # 5 15 → num 不变（复印件）

def grow(lst):         # 可变 list
    lst.append(100)
data = [1, 2, 3]
grow(data)
print(data)            # [1,2,3,100] → 被改了（原件）
```

<!-- 讲者备注：【难点】传参本质是传对象引用。不可变(int/str/tuple)重新赋值只让形参指向新对象,原变量不动,像复印件;可变(list/dict/set)函数内直接改到同一份对象,外面跟着变,像原件。教学:先让同学猜 grow 后 data 是多少,再揭晓。 -->

---

# 为什么？看引用指向

```python
a = [1, 2, 3]
def grow(x):
    x.append(100)
grow(a)
```

- 形参 `x` 与实参 `a` **指向同一个 list**
- 函数里 `append` 改的是同一份 → 外面变
- 而 int 重新赋值 `n = n + 10` 只是让形参换个数字，原 num 不动

<!-- 讲者备注：【全景】把可变性的"为什么"落到引用上:a 和 x 指向同一份 list,所以 append 是原地修改;int 则是让形参指向新数字,原变量不沾手。这张图的记忆点:可变=同一份原件,不可变=复印件。 -->

---

# 结课：会封装，才谈得上分层

> 用 `def` 立黑盒子，用 `return` 吐结果，
> 位置关键字默认可变长，四种参数随便递，
> 局部全局记清楚，可变原件不可变复印件。
