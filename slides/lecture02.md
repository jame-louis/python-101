## 第一幕 · 存：变量与常量

<!-- 转场
讲者备注：【转场】幕卡。先解决"数据放在哪"。变量=贴了标签的盒子，常量=写死不换的盒子。 -->

---

# 变量 = 贴了标签的盒子

```python
name = "小明"      # 把字符串"小明"装进变量 name
age = 21           # 把整数 21 装进变量 age
name = "小红"      # 重新赋值：盒子里换成"小红"
print(name)        # 小红（现在是新值）
```

> 关键：Python **赋值即定义**，第一次赋值就定义变量，**不用先声明类型**。

<!-- 讲者备注：【特写】"盒子 + 标签"的直觉最重要。强调"可以随时换内容"。这里就埋下"为什么要认识类型"——因为类型决定它能做什么。 -->

---

# 三条命名铁律，写了就记住

```python
student_name = "小明"     # ✅ 小写下划线（snake_case）推荐
StudentName  = "小红"     # ⚠️ 不规范（那是类名写法）
studentName  = "小刚"     # ⚠️ 一般不用驼峰
2name         = "错"      # ❌ 不能以数字开头
class         = "错"      # ❌ 不能用关键字
```

1. 字母/数字/下划线，**不能以数字开头**
2. **不能是关键字**（`if`、`for`、`class`…）
3. **见名知意**：`age` 比 `a` 好、`student_name` 比 `n` 好

<!-- 讲者备注：【全景】命名规范是习惯，不是语法——但习惯越早越省事。三条铁律一次给全，重点第三条"见名知意"，很多人死在不爱写清晰名字。 -->

---

# 常量：约定不改的值

Python 没有真正的"只读常量"，用**全大写**做约定：

```python
SPEED_OF_LIGHT = 299792458     # 光速(m/s) 全大写，约定别改
PI = 3.14159
```

> 记忆：常量 = "写死而且不会变"的值，全世界约好用大写提醒自己别动它。

<!-- 讲者备注：【特写】常量一句话讲清楚：不是语法强制，是团队约定。触发点是脚本里到处出现的"魔法数字"，用大写常量名收口。 -->

## 第二幕 · 认：类型与 type()

<!-- 转场
讲者备注：【转场】幕卡。数据存好了，但它"是什么"决定了能干什么——引入四种基本类型。 -->

---

# 四种基本类型：int / float / bool / str

| 类型 | 英文 | 示例 | 说明 |
|---|---|---|---|
| 整数 | `int` | `42`、`-7` | 没有小数点 |
| 浮点数 | `float` | `3.14`、`-0.5` | 带小数 |
| 布尔 | `bool` | `True`、`False` | 逻辑真/假（首字母大写！） |
| 字符串 | `str` | `"hello"`、`'你好'` | 引号括起来的文本 |

<!-- 讲者备注：【全景】四张卡片一次给全。重点标三个坑：bool 首字母大写；str 必须加引号；int/float 都是数字但有没有小数点。 -->

---

# type()：一眼识破"它是什么"

```python
print(type(42))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type(True))      # <class 'bool'>
print(type("hello"))   # <class 'str'>

x = 10
print(type(x))         # <class 'int'>
x = 3.14               # 换个值，类型也跟着变（动态类型）
print(type(x))         # <class 'float'>
```

> 易错点：`'123'`（字符串）和 `123`（整数）**完全不同**——一个是字条，一个是能算的数。

<!-- 讲者备注：【特写】type() 是"睁眼看类型"的门票。用动态类型让学生看到：同一个变量 x 换个值，类型跟着变。点破 '123' vs 123，为后面的加号报错埋伏笔。 -->

---

# 布尔值，先认识，后用到

```python
print(3 > 2)        # True   3 大于 2，成立
print(3 < 2)        # False
print(True + True)  # 2？True 当 1 —— 知道即可，别这么写
```

> 现在只需知道 `type(True)` 是 `bool`；真正的逻辑判断在第6讲 `if`。

<!-- 讲者备注：【特写】布尔先"认识一下"，不展开。避免在第一讲就把比较表达式讲太深，留到条件结构。 -->

## 第三幕 · 算：运算符与表达式

<!-- 转场
讲者备注：【转场】幕卡。数据认得清了，现在让它们"动起来"。 -->

---

# 七个算术运算符，一次背完

| 运算符 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `+ - *` | 加减乘 | `7 + 3` | `10` |
| `/` | 除（结果带小数） | `7 / 2` | `3.5` |
| `//` | 整除（去掉小数） | `7 // 2` | `3` |
| `%` | 取余 | `7 % 2` | `1` |
| `**` | 幂 | `2 ** 10` | `1024` |

> 口诀：**`//` 去掉小数，`%` 是除完剩的零头，`**` 是几次方。**

<!-- 讲者备注：【全景】七张牌一次铺开。三行口诀收口：//去掉小数、%取零头、**几次方。重点讲 // 和 % 成对出现，这是后面判断奇偶、取位数的基本功。 -->

---

# 表达式与优先级：不确定就加括号

```python
print(3 + 4 * 5)      # 23   先乘后加
print((3 + 4) * 5)    # 35   括号优先
print(7 // 2, 7 % 2)  # 3 1  整除与取余成对
```

- 优先级：`()` > `**` > `* / // %` > `+ -`（和数学一致）
- `%` 最常用：判断奇偶 → `n % 2 == 0` 是偶数；取个位 → `123 % 10 == 3`

<!-- 讲者备注：【特写】优先级不是背，是"不确定就加括号"。% 的两个经典用途给到：奇偶判断、取个位，直接对接后面的挑战题。 -->

---

# 字符串能不能和数字 `+`？—— 不行！

```python
print("年龄是" + 21)       # ❌ TypeError: 字符串和整数不能相加
print("年龄是" + str(21))   # ✅ 先转成字符串："年龄是21"
```

> 这是初学者第一个高频坑。怎么解决？→ 下一个知识点：**类型转换**。

<!-- 讲者备注：【特写】故意制造报错，让学生记住这个 TypeError。它就是通往"类型转换"的引线，第二幕的类型概念在这里第一次起作用。 -->

## 第四幕 · 掐：字符串索引与分片 ⭐

<!-- 转场
讲者备注：【转场】幕卡。全片重中之重。留足 20 分钟。分片规则（含头不含尾）是本讲必须刻进脑子的。 -->

---

# 索引：给每个字符编下号

```python
s = "Python"
#    012345         正向索引（从0开始）
#  -6-5-4-3-2-1     负向索引（从右数）

print(s[0])     # P   第一个字符
print(s[-1])    # n   最后一个字符（最常用！）
print(s[3])     # h
print(s[-3])    # t   倒数第 3 个
```

> 两个最常背的下标：`s[0]` 第一个、`s[-1]` 最后一个。
> 越界会报错：`"Python"` 最大正索引是 `s[5]`，`s[6]` 报 `IndexError`。

<!-- 讲者备注：【特写】下标从 0 起 + 负下标从右数。让学生先猜 s[-1] 是什么再揭晓。s[0] 和 s[-1] 是最常用的两个，务必背住。提醒越界报错。 -->

---

# 分片：含头不含尾 ⭐ 一条铁律

```python
s = "Python"
print(s[1:4])     # yth  下标1、2、3，不含4
print(s[:3])      # Pyt  从头开始（省略0）
print(s[3:])      # hon  到末尾（省略结束）
print(s[:])       # Python 全取
```

> ⭐ `s[a:b]` 取下标 `a` 到 `b-1` —— **含头不含尾**，本讲必须刻进脑子。

<!-- 讲者备注：【特写】铁律出场：含头不含尾。用 s[1:4]=yth 让学生对照下标数一遍（下标1、2、3，不含4）。三连问：s[:3]、s[3:]、s[:] 各是什么，答完自然掌握省略写法。 -->

---

# 步长 + 逆序：`s[::-1]` 最经典

```python
s = "Python"
print(s[::2])     # Pto   隔一个取一个（0、2、4）
print(s[1::2])    # yhn   从1开始隔一个（1、3、5）

print(s[::-1])    # nohtyP  ← 字符串反转！高频考点
```

> 记忆：**想要逆序，就写 `[::-1]`**——几秒钟反转一个字符串。

<!-- 讲者备注：【特写】负步长 = 倒着走。s[::-1] 是每个 Python 初学者都要背的高频写法。给一个收口总表（见下镜），让学生写进笔记。 -->

---

# 一张表，收口分片

| 写法 | 结果（s="Python"） | 说明 |
|---|---|---|
| `s[0]` | `P` | 第一个字符 |
| `s[-1]` | `n` | 最后一个字符 |
| `s[1:4]` | `yth` | 含头不含尾 |
| `s[:3]` | `Pyt` | 从头开始 |
| `s[3:]` | `hon` | 到末尾 |
| `s[::2]` | `Pto` | 隔一个取一个 |
| `s[::-1]` | `nohtyP` | **逆序** |

<!-- 讲者备注：【全景】分片的总表特写，让学生照抄进笔记本。这一页就是本讲分片部分的"答案纸"，HW02 的分片题全靠它。 -->

# 类型转换：三个"翻译官"

```python
int("100")      # 100     字符串→整数
float(5)        # 5.0     整数→浮点数
str(100)        # "100"   数字→字符串
int(3.9)        # 3       ⚠️ 砍掉小数，不是四舍五入！

print("岁数" + str(21))    # 岁数21
print(int("100") + 1)      # 101
```

> 注意：`int(3.9)` 得 `3` 不是 `4`——`int()` **截断**小数；要四舍五入用 `round()`。`int("3.5")` 报错（带小数点转不了）。

<!-- 讲者备注：【特写】翻译官比喻点题：解决倒下一镜的 TypeError。三个说法都给出，重点 int(3.9)=3 的截断行为 + int("3.5") 报错这两个易错点。 -->
