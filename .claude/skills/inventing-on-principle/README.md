# Inventing on Principle — Claude Skill

A Claude Skill inspired by Bret Victor's talk, "Inventing on Principle."

## Install
Copy the `inventing-on-principle` folder into your Claude skills directory, commonly:

- Personal: `~/.claude/skills/inventing-on-principle/`
- Project: `.claude/skills/inventing-on-principle/`

Keep `SKILL.md` at the skill root. The `references/` folder contains source notes.

## Use
Ask Claude to help identify a guiding principle, test whether it is actionable, find where it is violated, and design an experiment or invention that acts on it.

## Contents
- `SKILL.md` — skill instructions and workflow
- `references/inventing-on-principle-notes.md` — source and conceptual notes
